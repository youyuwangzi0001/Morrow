# Morrow 功能参考

本文按使用域列出 Morrow 当前（0.1.0 / r019）的入口、能力与边界。操作步骤见 [用户指南](USER-GUIDE.md)，实现细节见 [架构说明](ARCHITECTURE.md)。

## 1. 对话与任务

| 能力 | 入口 | 说明 |
|---|---|---|
| 聊天 | 输入框“聊天” | 只读：文件读取、搜索、提问、联网（已配置时）；禁止写文件、命令、记忆、集群 |
| 工作 | 输入框“工作” | 默认方式；完整工具链，受权限/审批和工作区边界约束 |
| 计划 | `/plan` | 只读探索，最多 2 步，提交计划；批准后转执行并生成 todo |
| 深度研究 | `/research` | 计划阶段无工具；批准后搜索/抓取；quick 2 轮/4 来源、standard 4/10、deep 6/20 |
| 长期目标 | `/goal` | 2–256 轮，跨轮续跑；完成需工作区内非空、mtime 晚于目标的证据文件 |
| 队列 | 运行中箭头 | 按会话隔离，最多 20 条、单条 20k 字、8 附件；正常结束后自动发送 |
| 插话 | 运行中闪电 | 先取消当前运行再发送；研究中的插话写入下一轮 |
| 侧聊 | `/btw` | 无工具、不写主会话/检查点、最多 8 并发；历史 12 条/12k 字，输出 4096 tokens |
| 集群 | `/swarm` 或工具 | 1–10 个成员并行；成员工具/权限/工作区/快照与主代理一致；不能嵌套集群 |
| 灵动岛 | 设置 → 外观 | 独立置顶窗；显示当前会话进度、todo、快速发送；跟随会话切换 |
| 会话管理 | 侧栏 | 新建、临时对话、搜索、置顶、归档、分叉、重命名、删除；最多 300 条 |

### 1.1 运行与恢复

- 同一会话同时只允许一个运行；普通运行可跨会话并行；目标循环全局串行。
- 每个用户轮次有检查点（最多 100 个），可回退代码/对话/两者；命令副作用不在通用回退范围。
- 写/编辑/删除前有快照；恢复校验会话根、清单哈希与当前文件哈希，冲突拒绝。
- 自动压缩默认阈值 0.8、保留最近 8 条（可配 0.5–0.98 / 2–50）；压缩失败退本地摘要；上下文溢出最多强制压缩重试 2 次。
- 连续 4 次完全相同工具调用判死循环；单轮步数默认无限。

## 2. 文件、编辑器与画布

| 能力 | 说明 |
|---|---|
| 文件树 | 工作区扫描、展开/收起、新建/重命名/删除、拖动、右键菜单、只读提示 |
| 编辑器 | CodeMirror；多标签、语法高亮、查找、撤销/重做、保存、另存为、版本历史、强制保存 |
| 只读 | 产物/只读文件锁定编辑，避免误写 |
| 画布 | HTML/Markdown/SVG/图片/PDF/Office/音视频/文本/代码预览；版本、导出、外部打开、文件夹显示 |
| 预览 | 图片缩放 50–300%；PDF/Word/Excel/PPT/压缩包；不支持时提供系统应用/文件夹入口 |
| 版本 | 文本成品最多 30 版、单版 8MB；diff、恢复、导出 |
| 导出 | 原文件、Markdown、网页、纯文本、PDF |
| 大文件 | 画布文本上限 8MB；超出提示截断 |

## 3. 模型、思考与上下文

| 能力 | 说明 |
|---|---|
| 内置 API | DeepSeek、Kimi、Qwen、GLM、MiniMax、MiMo、Anthropic、OpenAI、Gemini、Grok、Meta |
| 自定义 Provider | OpenAI 兼容 Base URL/Key/模型；本机/局域网可空 Key |
| 模型同步 | `/models` 读取上下文、输出、推理档位；最多 200 个；缺字段保留本地值 |
| 模型显示 | 只显示原始模型名，不加营销后缀 |
| 思考档位 | 只显示模型真实档位；不支持显示“不支持思考”；未知只有“自动” |
| 上下文档位 | 如 Qoder 200K/400K/1M；按模型元数据；会话级覆盖 |
| 订阅 | ChatGPT/Codex、Qoder、Kimi、GLM、MiniMax、Step、Command Code、Cline、Antigravity、OpenCode、第三方 plan |
| Qoder | 账号目录实时读取；无静态模型表；默认上下文以账号 `is_default` 为准 |
| 重试 | 408/409/425/429/5xx/网络错误最多 3 次，退避 800/2000/5000ms；仅未产出内容时重试 |
| 上下文覆盖 | OpenAI 兼容网关通过 `x-morrow-context-window`；Anthropic 不使用该头 |

详细模型表与修正依据见 [模型与思考档位](MODELS.md)。

## 4. 订阅账号

| 渠道 | 登录/导入 | 模型目录 | 额度 |
|---|---|---|---|
| ChatGPT/Codex | 本机 `auth.json` 只读导入；内置浏览器 OAuth（localhost:1455） | 内置 10 个（384K/272K） | `/backend-api/wham/usage` 5h/周/credits |
| Qoder | PAT、设备流 PKCE、本机 qodercli 只读导入 | 账号 `/model/list`：15 个 chat 模型、200K/400K/1M | `/api/v2/quota/usage` |
| Kimi Code | RFC 8628 设备码（中国/国际区） | 6 个，1M/256K | `/coding/v1/usages` 5h/周/月 |
| GLM Coding Plan | ZCode 浏览器轮询 → 专用 Key | 3 个，1M/200K | `/api/monitor/usage/quota/limit` |
| MiniMax Code | 设备码 + PKCE；本机 auth 导入 | 4 个，1M/200K | `coding_plan/remains` |
| Step Plan | 云端轮询、粘贴 Key、本机 auth | `/v1/models` 实时 | 仅账号/模型，无数字 |
| Command Code | 浏览器回调或手贴 Key | `/provider/v1/models`，失败回退预设 | `/alpha/billing/credits` |
| Cline Pass | WorkOS 设备码或静态 Key | 14 个预设，无思考档位 | `/users/me/plan/usage-limits` |
| Antigravity | Google OAuth PKCE（需环境 secret） | 9 个 | `retrieveUserQuotaSummary` |
| OpenCode | 本机 auth 只读导入或手贴 Key | 实时 `/models`，回退 5 个 | Zen 无公开额度接口 |

协议、代理与安全边界见 [订阅接入](SUBSCRIPTIONS.md)。

## 5. 终端、Git 与浏览器

| 能力 | 说明 |
|---|---|
| 终端 | 真实 PTY；默认 Git Bash；PowerShell 7 / WSL 可选；Windows PowerShell 5.1 与 CMD 已移除 |

| 后台任务 | 流式日志、stdin、停止/重启、400KB 环缓冲、最多 32 个 |
| Git | 变更/diff/暂存/提交/分支/历史/放弃；越界与仓库根保护 |
| 浏览器 | 多标签、地址栏、主页、前进/后退、真实页面；登录 session 独立导航白名单 |
| 滚动条 | 8px 轨道、6px 实色全圆角、无渐变；内容溢出才显示 |

## 6. 项目、记忆与自动化

| 能力 | 说明 |
|---|---|
| 项目 | 背景、说明/资料（≤20 个、单文件 ≤512KB）、项目内会话、当前文件夹范围 |
| 记忆 | 项目/全局长期记忆、任务经验、注入预览、自进化建议；临时对话不写 |
| 技能 | 内置 + 用户 + 工作区；Markdown/zip 安装；跳过脚本；安全限制 |
| MCP | stdio / Streamable HTTP / SSE；工具/资源/提示词/OAuth；工作区信任哈希 |
| 定时任务 | 一次/每天/每周；最多 50；5s tick；错过后补跑；30 分钟超时；无人值守拒绝审批 |
| 钩子 | user_prompt_submit / post_tool_use / run_finished；每事件最多 5；15s 超时 |
| 自定义命令 | 项目/用户 `.morrow/commands`；$ARGUMENTS/$1..$9；保留名不可覆盖 |
| 自定义角色 | 内置 + `~/.morrow/agents` + 工作区 `.morrow/agents`；单文件 32KB |
| 规则文件 | AGENTS.md / CLAUDE.md / MORROW.md；最多 6 层；默认 3000 tokens |

## 8. 设置与外观

| 分页 | 主要选项 |
|---|---|
| 模型 | Provider、Key、Base URL、模型同步、默认模型卡 |

| 多媒体 | 引擎、模型目录、ffmpeg、超时、输出目录 |
| 联网搜索 | builtin / Tavily / Brave / Serper / SearXNG；默认 5 条 |

| 回答 | 5 种风格、发送键、运行中发送、自动命名、完成通知 |
| 用量 | Token 活动、日/周/总计 |
| 归档 | 恢复、永久删除、清空 |
| 权限 | 三档、文件夹规则、审批日志、危险动作清单 |
| 自动化 | 自定义命令、集群成员、钩子 |
| 功能与工具 | 记忆/项目/定时/技能/MCP/搜索/浏览器/Git 入口 |
| 终端 | 默认 Shell、WSL 提示、重新检测 |
| 外观 | 主题、应用/代码字号、代码字体、减少动效、关闭行为 |
| 快捷键 | 内置快捷键一览 |

默认值：墨夜深色、应用字号 14、代码字号 12、JetBrains Mono、询问权限、Enter 发送、运行中排队、自动压缩开（0.8）、Token 计量开、侧栏 240、画布 420、关闭时询问、通知开、灵动岛开。

## 10. 边界与状态

- 聊天模式始终只读；计划批准前不写入；研究固定只读白名单。
- 运行中不能切换模式、压缩或切换文件夹；临时对话不能回退或生成成品版本。
- 无 Key 的 Provider 不出现在模型下拉；无视觉能力的模型不能进行视觉审看。
- 未安装 WSL 发行版时终端显示安装提示；Git Bash 在受限令牌环境可能不可用，切 PowerShell 7。
- 真实本地模型/ffmpeg/ComfyUI 未就绪时明确报错，不伪造生成或审看结果。
