# Morrow 功能参考

> 面向已经完成首次启动的用户。按「入口 → 能做什么 → 边界」组织，便于快速查找。
> 版本：0.1.0 · 平台：Windows 10/11 x64

## 1. 对话与任务

| 能力 | 入口 | 说明 |
|---|---|---|
| 聊天 / 工作 | 输入框左侧模式 | 聊天只讨论与只读分析；工作模式可读写文件、运行命令、推进计划。 |
| 计划模式 | 输入 `/plan 任务`，或模式菜单 | 先只读探索，给出步骤、风险与验收标准；批准后才执行。计划必须每步有完成的 todo 才算完成。 |
| 长期目标 | 输入 `/goal 目标`，或标题栏目标按钮 | 自动估算轮次预算，跨轮推进；完成必须有真实文件证据，阻塞会如实停止。 |
| 超频模式（常驻） | 底层提示词 | 不因思考强度档位降低交付标准；不因节省 token、时间或成本缩减范围或跳过验证；权限、安全与系统硬预算仍生效。 |
| 深度研究 | 输入 `/research [quick\|standard\|deep] 问题` | 先出可编辑研究计划，再多轮检索、交叉核对，交付带引用的报告；可中途补充要求。 |
| 集群 / Swarm | `/swarm`、`/agents`，或任务中的 `swarm` 工具 | 2–6 个独立子任务并行；每个成员有独立状态、工具轨迹与结论。 |
| 侧边聊天 | `/btw 问题` | 右侧只读抽屉，不写入主会话、不调用工具；可选择是否带主对话上下文。 |
| 队列与插话 | 运行中按发送键 | 可选择「插话」（停止当前运行并立即发送）或「排队」（本轮结束后发送）。 |
| 分支、重试、编辑重发 | 消息悬停菜单 | 从任意用户消息分叉；重新生成；编辑后重发；导出 Markdown / JSON。 |
| 临时对话 | 侧栏「临时对话」 | 只存在内存，不写会话文件、不注入记忆；退出即清理。 |
| 后台运行 | 运行中切换到其它会话 | 原会话继续运行；侧栏显示状态，运行中心可返回处理。 |

## 2. 文件、编辑器与预览

- **文件树**：新建文件/文件夹、重命名、移动、复制、删除、搜索；文件夹可展开；超过 2000 项显示 `2000+` 提示。
- **CodeMirror 编辑器**：多标签、查找替换、撤销重做、外部修改冲突提示、保存/另存、历史版本与恢复。
- **预览**：图片、PDF、Word、Excel、PPT、RTF / ODT / EPUB、ZIP 目录、CSV / TSV、音频、视频；扫描版 PDF 可用 Windows 本机 OCR 离线识别（每次最多 12 页，超出会提示分批）。
- **画布（Artifacts）**：HTML、Markdown、SVG、代码、文本内联渲染；图片/PDF/Office/音视频进入只读预览；支持版本快照、导出、系统打开。文本产物上限 8MB，超出请在文件树中打开。
- **文件安全**：所有路径先 realpath 再校验工作区边界；越界、危险命令、外部动作逐次审批；写入前快照，回退可恢复 Morrow 写过的文件。

## 3. 模型与订阅

### 3.1 模型服务

- 国内：DeepSeek、Kimi、通义千问、智谱 GLM、MiniMax、小米 MiMo。
- 国际：Anthropic Claude、OpenAI GPT、Google Gemini、xAI Grok、Meta Muse。
- 本地 / 自建：llama.cpp、Ollama、LM Studio、任意 OpenAI 兼容服务。
- 设置 → 模型：选择服务、填写 API Key、保存连接、测试连接、刷新可用模型；支持运行时同步 `/models` 元数据。
- 本机或局域网服务（`localhost`、`127.0.0.1`、`192.168.x`、`10.x`、`172.16–31.x`、`.local`）可以留空 API Key；公网服务仍需 Key。
- 思考强度：`auto / low / medium / high / xhigh / max`（模型支持时显示）。

### 3.2 模型订阅

设置 → 订阅，支持 10 条真实渠道：

- ChatGPT / Codex、Qoder、Kimi Code、GLM Coding Plan、MiniMax Code、Step Plan、Command Code、Cline Pass、Google Antigravity、OpenCode。
- 每条渠道有浏览器登录 / 设备码 / 本机凭据导入、加密存储、额度与账号状态、本地兼容代理。
- 第三方 coding plan 可填写名称、协议（OpenAI Chat Completions / Anthropic Messages）、接口地址、token 与模型 ID，保存后注册为 Provider。
- 登录态只保存在本机；Morrow 不代充、不共享账号、不绕过限流。第三方客户端使用订阅可能受服务商条款限制。

## 4. 本机多媒体

设置 → 多媒体是通用模型/引擎管理器，Morrow 不自带推理引擎或模型文件。

- **引擎**：检测、安装、启动、停止 ComfyUI、llama.cpp、Ollama、LM Studio 与自定义引擎。
- **模型**：列出本机模型、能力、安装状态、缺失文件与运行状态；可下载、卸载、启动。
- **应用内添加本机模型**：
  - llama.cpp / Ollama / LM Studio：填写名称、引擎、能力、模型文件 / 引擎内 ID，即可注册；llama.cpp 可一键「启动此模型」。
  - ComfyUI：粘贴「保存（API 格式）」导出的工作流 JSON，填写输出节点 ID、输出类型与可选提示词节点，即可注册。
  - 模型文件在引擎目录外时会自动复制进去，重名自动加序号。
- **Agent 工具**：`generate_image`、`edit_image`、`generate_video`、`generate_film`、`edit_media`、`inspect_media`、`describe_media`、`render_animation`、`run_local_model`。`describe_media` 优先使用当前对话模型自带的视觉能力，当前模型不支持或调用失败时才回退本机视觉模型。
- **剪辑**：ffmpeg 用于裁剪、变速、提取音频、转 GIF、视频封面与多段拼接；图片/视频生成不依赖 ffmpeg。
- **边界**：多媒体依赖本机 NVIDIA 显卡、ComfyUI、模型权重与 ffmpeg；高分辨率/长视频会明显变慢。详细清单见 [MEDIA-MODELS.md](MEDIA-MODELS.md)。

## 5. 工作台

- **终端**：PowerShell 7 / Windows PowerShell / CMD / Git Bash / WSL；WSL 需先在 Windows 安装发行版，可在设置 → 终端重新检测；多标签、后台任务、复制粘贴、拖动调高；使用真实 PTY。
- **Git 工作台**：查看差异、暂存/取消暂存、提交、切换/新建分支、浏览历史、配置仓库身份；仓库必须位于当前工作区内。
- **内置浏览器**：渲染层 chrome + 主进程 WebContentsView；网页区域是原生视图；支持多标签、前进/后退/刷新、下载确认、返回主页面并保留状态。
- **computer-use**：受控桌面操作（截图、点击、输入、按键），逐次审批，敏感窗口拒绝；仅 Windows。

## 6. 记忆、项目、搜索、定时、技能、MCP

- **记忆中心**：长期记忆（项目 / 全局）与任务经验（自动记录、按相关任务检索）；按 token 预算注入；可编辑、删除、导出。
- **项目**：每个工作区对应一个项目；名称、描述、用户指令、知识文件、置顶/启用；项目上下文按预算注入。
- **全局搜索**：跨对话、文件、成品搜索；支持当前文件夹范围；命中会话可跳转并高亮。
- **定时任务**：设置 → 自动化；按间隔或指定时间运行；无人值守时自动拒绝高风险操作、自动跳过提问；失败会标记错误。
- **技能**：内置技能 + 用户技能库；支持文件夹/zip 安装、启停、删除、查看资源；脚本与可执行文件会被跳过并提示，不会执行。
- **MCP / 外部工具**：内置目录、手动配置、OAuth；资源、提示词、工具调用；按权限档位审批。
- **自定义命令**：项目 `.morrow/commands/*.md` 或用户 `~/.morrow/commands/*.md`，输入 `/名字` 调用；支持 `$ARGUMENTS`。
- **运行钩子**：`user_prompt_submit` / `pre_tool_use` / `post_tool_use` 等事件；可拦截或注入上下文。
- **集群成员**：内置 6 个角色 + 项目 `.morrow/agents/*.md` 自定义成员。

## 7. 权限与审计

- **权限三档**：只读 / 询问 / 完全访问；默认询问。完全访问仅建议在隔离或可恢复任务中使用。
- **审批卡**：显示风险级别、人话说明、命令/路径/diff 预览；`Enter` 允许一次，`Esc` 拒绝；高风险 / 外部动作不提供「始终允许」。
- **持久规则**：设置 → 权限可查看和删除；命令前缀规则不会覆盖 shell 链式命令；工作区比较使用 realpath。
- **执行轨迹（Spine）**：工具调用、参数、结果、diff、耗时都在对话中可见；可按轮次跳转、回退。
- **检查点 / 回退**：每轮结束可一次性回退对话与 Morrow 写过的文件；回退会校验快照哈希。
- **隐私**：输出链路对邮箱、用户名、token 等已知敏感值做遮蔽；浏览器、MCP、computer-use 默认逐次审批。

## 8. 设置与外观

- 15 个设置页：模型、订阅、多媒体、联网搜索、上下文、回答、用量、归档、权限、自动化、功能与工具、终端、外观、快捷键、关于。
- 外观：深色墨夜 / 浅色素纸；应用字号 **12–15（默认 14）**；代码字号 **11–14（默认 12）**；代码字体默认 **JetBrains Mono**，可切 IBM Plex Mono / 系统等宽；减少动效；token 计量；桌面小伙伴；关闭窗口行为。
- 关于：版本、Electron/Chrome/Node、数据目录、日志、更改/恢复数据目录。
