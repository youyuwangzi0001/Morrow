# 安全与隐私

Morrow 是本地优先的桌面 Agent。默认不把工作区内容上传到 Morrow 服务器；模型请求直接发给你选择的模型服务。本文写清数据在哪、密钥怎么存、权限怎么生效、哪些边界仍然存在。

## 1. 本地优先

- 会话、快照、日志、作品、素材、密钥都在本机数据目录。
- 没有 Morrow 云端账号也能使用；模型可以是本机 Ollama/llama.cpp/LM Studio。
- 只有你主动配置的模型服务、订阅渠道、MCP、网页读取会联网。

## 2. 数据在哪里

| 位置 | 内容 |
|---|---|
| 便携版 `Morrow Data/` | 会话、设置、密钥、作品、素材、日志 |
| 安装版 `%APPDATA%\Morrow\` | 同上 |
| 工作区 `.morrow/` | 项目记忆、经验、技能、命令、角色、MCP 配置 |
| 数据目录 `logs/main.log` | JSON 行日志，5MB 轮转保留 3 份 |
| `permissions/approval-log.jsonl` | 审批记录 |
| `usage/token-activity.json` | Token Activity |
| `studio/` | 作品、素材、版本、回收站 |

数据目录可在「设置 → 关于」更改；迁移会重启。卸载默认保留用户数据。

## 3. 密钥与凭据

- API Key 使用 `safeStorage`/Windows DPAPI 加密后写入 `secrets.json`；加密不可用时拒绝保存。
- 渲染层只看到 `apiKeyStored`，拿不到明文。
- 旧版 `b64:` 只读兼容；不会回写明文。
- MCP 凭据在系统加密不可用时使用 `plain:` base64（明确标记，不作为安全存储）。
- 订阅凭据与模型 Key 分开管理；清除后需要重新填写。
- 不要把 Key 写进提示词、日志、截图或反馈；反馈前先脱敏。

## 4. 权限模型

三档：

- **只读**：拒绝写文件、跑命令、改记忆。
- **询问**：工作区内写文件/普通命令直接放行；危险命令、越界路径、外部副作用动作、终端 stdin 逐次询问；没有“始终允许”用于危险动作。
- **完全访问**：全部直接放行，包括危险命令、越界和外部动作。

“始终允许”= 工具 + 目标 + 参数哈希；落会话 grant 与工作区规则；deny 优先；每工作区最多 300 条。

聊天硬只读；研究只放行只读 + 网页白名单；计划只读 + `submit_plan`。

## 5. 文件与命令边界

- 文件路径 realpath 后必须落在已登记工作区内；工作区外只有显式附件可读，写操作拒绝。
- 危险命令（删除、格式化、提权、远程脚本等）在询问档逐次确认；完全访问档直接执行，风险由用户承担。
- 终端是真实 PTY；隐藏终端不结束进程，关闭标签才结束。
- 导入素材按内容哈希去重；作品导出只写到你选择的位置。

## 6. 网页、MCP 与桌面操作

- 网页只允许 http(s)；拒绝 `file://`、带凭据 URL、内网/本机地址（SSRF 防护）。
- 网页内容按不可信数据处理；不把网页里的“系统提示”当指令。
- MCP 连接前显示服务端信息；工具调用仍按当前权限档位审批。
- 浏览器禁用 webview；`window.open` 拒绝；登录窗口与普通浏览共用安全边界。
- 桌面操作/终端 stdin 在询问档逐次确认。

## 7. 网络与订阅

- 模型请求直接发往你配置的 Provider；Morrow 不中转、不记录请求正文到云端。
- 订阅回环只监听 `127.0.0.1` 随机端口，使用本地 Bearer；不暴露公网。
- 不内置第三方 OAuth secret；Antigravity 需要 `MORROW_ANTIGRAVITY_CLIENT_SECRET`。
- 不提供 Claude 登录；没有验证过的订阅渠道不显示“已连接”。

## 8. 日志与诊断

- `logs/main.log` JSON 行、5MB 轮转保留 3 份；记录事件/错误，不记录 API Key。
- 打包版本地崩溃转储；crashReporter 不上传。
- 反馈问题时附相关日志片段；不要附密钥、完整作品或隐私素材。

## 9. 已知边界

- Windows 10/11 x64 是唯一正式交付平台；其他平台未验证。
- 便携版/安装包未签名，SmartScreen 可能提示；以 SHA-256 校验为准。
- 完全访问档会直接执行危险/越界动作；只在信任任务时使用。
- 云端模型/订阅/网页读取受服务商隐私政策约束；Morrow 不能替服务商承诺数据不留存。
- 本机模型/ComfyUI/FFmpeg/TTS 的许可与数据由你选择的构建决定。
- 恶意网页、恶意 MCP、恶意技能仍可能诱导模型做危险动作；权限档位与审批是最后一道闸门。
