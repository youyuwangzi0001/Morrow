# 安全与隐私

Morrow 的默认目标是“本地优先、最小暴露”：工作区内容只在你选择的模型/引擎需要时离开本机；凭据不进入渲染层；文件、命令、浏览器与 MCP 都有明确边界。

## 1. 本地优先

- 应用本身不把工作区内容上传到 Morrow 服务器。
- 模型请求直接发往你选择的 Provider（API 服务、官方订阅代理或本机引擎）。
- 会话、快照、检查点、日志、记忆、项目、技能与 Token 账本都在本机数据目录。
- 不默认开启遥测、云同步或远程备份。

## 2. 数据在哪里

| 数据 | 默认位置 |
|---|---|
| 便携版数据 | `<exe 同级>/Morrow Data` |
| 安装版数据 | `%APPDATA%\Morrow` |
| 会话 | `<dataDir>/sessions/` |
| 设置/密钥 | `<dataDir>/settings.json`、`secrets.json` |
| 快照/检查点 | `<dataDir>/snapshots/`、`checkpoints/` |
| 日志 | `<dataDir>/logs/main.log` |
| 项目 | `<dataDir>/projects/` 与工作区 `.morrow/` |
| 记忆 | `<dataDir>/memories/` 与工作区 `.morrow/memories.json` |
| 媒体产物 | 工作区 `media/` |
| 创作台作品 | `<dataDir>/studio/projects/<id>/`（作品、素材、版本、导出） |
| 订阅凭据 | `<dataDir>/*-subscription.json`（加密） |

`deliver/Morrow Data` 是用户数据，发放包不包含它。迁移/备份时请关闭应用后复制整个数据目录。

## 3. 密钥与凭据

- API Key 使用 Electron safeStorage（Windows DPAPI）加密写入 `secrets.json`。
- 加密服务不可用时 Morrow **拒绝保存**，不会降级为明文或可逆 base64；旧 `b64:` 只读兼容并记录告警。
- 订阅 token 使用同类加密存储；刷新 token 先落盘再使用。
- 渲染层只得到 `apiKeyStored`/账号状态，永远拿不到明文。
- 日志、工具结果与可见回复经过敏感值脱敏；输出守卫会遮蔽邮箱、用户名与 token。
- Antigravity OAuth client secret 不写入源码或发布包，必须通过 `MORROW_ANTIGRAVITY_CLIENT_SECRET` 提供。
- MCP 密钥若系统加密不可用会使用 `plain:` base64 兼容（这是 MCP 的既有边界）；敏感环境建议确保系统加密可用。
- 创作台导出的 `.morrowcraft` 工程包、成书、成片、封面与交付文件夹**不包含** API Key、账号凭据或旧应用数据；导出前可在交付页核对文件清单。

## 4. 权限模型

| 档位 | 普通写/命令 | 危险命令 | 越界路径 | 外部副作用 |
|---|---|---|---|---|
| 只读 | 拒绝 | 拒绝 | 拒绝 | 拒绝 |
| 询问 | 工作区内放行 | 询问 | 询问 | 询问 |
| 完全访问 | 放行 | 询问 | 询问 | 询问 |

- 危险命令、越界路径、外部副作用动作始终逐次确认，不能“始终允许”。
- “始终允许”按工具 + 目标 + 参数哈希生成会话 grant，并落为工作区规则。
- deny 规则优先；审批日志在 `permissions/approval-log.jsonl`。
- 无人值守运行/定时任务自动拒绝审批和提问，不会挂起。
- 聊天模式、计划批准前、研究检索阶段有额外的工具白名单/只读限制。

## 5. 文件与命令边界

- IPC 文件路径必须 realpath 后位于最近工作区/会话工作区。
- 终端 cwd 必须在已登记工作区；stdin 写入按高风险逐次确认。
- 命令工具不提供任意 shell 字符串给未授权场景；危险命令、外部副作用命令有专门检测。
- 快照恢复前校验会话根、清单哈希与当前文件哈希；冲突拒绝。
- 回退只覆盖 Morrow 通过写文件工具修改的文件；命令直接生成的文件不在范围内。

## 6. 网页、MCP 与桌面操作

- 外部 URL 仅允许 http(s)；`window.open` 拒绝；`<webview>` 禁止。
- 浏览器页面、MCP 资源、搜索结果都视为不可信数据，不能作为系统指令。
- 打包版启用 CSP；画布 HTML 走独立 `morrow-artifact` 协议和独立 CSP（允许内联脚本/https，禁止 frame/表单/本机 connect）。
- MCP 工作区配置需要 `mcp-trust.json` 哈希登记后才启动；stdio/HTTP/SSE 都有超时与结果大小上限。
- computer-use 操作属于高风险外部动作，必须审批。

## 7. 网络与订阅

- 订阅代理只监听 `127.0.0.1` 随机端口，要求随机本地 Bearer；上游 token 不进入渲染层。
- OAuth 回调校验 `state`；Command Code 还限制 CORS 与请求体大小。
- 官方接口失败时如实报错；不把未连接显示成已连接，不编造额度。
- 不代充、不共享账号、不绕过限流。
- 代理端口不对外网开放；防火墙/代理软件可能影响回调，需要放行本机回环。

## 8. 日志与诊断

- 主进程日志是 JSON 行，包含运行事件、错误与脱敏后的上下文。
- 打包版启用本地 crashReporter，崩溃转储保存在本机；不上传服务器。
- 主窗口渲染进程崩溃会自动 reload（60 秒内最多两次）；无响应事件记录。
- 反馈问题时可提供 `logs/main.log` 与复现步骤；不要附带 API Key、token 或完整私密文件。

## 9. 已知边界

- 未签名安装包可能触发 SmartScreen；请校验 SHA-256。
- 模型服务商可能记录请求内容；请阅读对应服务的隐私条款。
- 本地模型/引擎由第三方提供，安全性与许可由对应项目负责。
- 电脑被恶意软件控制、系统时间/证书被篡改等主机级风险不在应用防护范围内。
- 浏览器登录窗口使用持久 session；共用电脑上请在设置中断开订阅并清理数据目录。
- 创作台的本机语音与媒体引擎依赖系统/第三方组件；受限环境可能无法调用，界面会明确失败并提供导入路径，不会伪造素材。

## 10. 报告安全问题

见根目录 [SECURITY.md](../SECURITY.md)。请不要在公开 issue 中粘贴真实 token、账号、工作区内容或未修复漏洞细节。
