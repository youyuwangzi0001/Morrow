# 安全与隐私

> 这是面向用户的说明。漏洞报告流程见根目录 [SECURITY.md](../SECURITY.md)。

## 1. 本地优先

- Morrow 没有 Morrow 云服务，不发送遥测、崩溃上报或使用统计。
- 对话、设置、项目、记忆、技能、附件与生成产物默认保存在本机数据目录。
- 只有你主动使用模型、联网搜索、订阅、MCP、浏览器或外部命令时，才会产生网络请求。

## 2. 数据在哪里

| 数据 | 默认位置 |
|---|---|
| 设置、会话、项目、记忆、技能 | 安装版 `%APPDATA%\Morrow` / 便携版 `Morrow Data` |
| 浏览器缓存与登录态 | 数据目录下的 Chromium 缓存，不随数据目录迁移 |
| 日志 | 数据目录 `logs/` |
| 浏览器下载 | 数据目录 `downloads/` |
| 模型与媒体文件 | 你自己指定的引擎目录/工作区，不随包分发 |
| API Key / 订阅 token | 设置文件中的加密字段（Windows DPAPI） |

设置 → 关于可以查看实际数据目录、打开日志、更改或恢复数据目录。更改目录会复制对话、设置、项目、记忆与技能，不包含浏览器缓存/登录状态；恢复默认目录不会自动合并两边数据。

## 3. 密钥与凭据

- API Key、订阅 token 使用 Windows DPAPI（`safeStorage`）加密保存；解密只在主进程发生。
- 渲染层只拿到「是否已保存」的布尔值，不接触明文 Key。
- 本机凭据导入（Codex/Qoder/Step/OpenCode 等）只读，不改写官方客户端文件。
- 导出会话、日志、截图前请自行确认是否包含敏感信息；Morrow 会对已知格式的邮箱、用户名、token 做遮蔽，但不能保证覆盖所有自定义格式。

## 4. 权限模型

三档权限：

1. **只读**：只能查看与分析，不能写文件、运行命令或执行外部动作。
2. **询问**（默认）：写文件、运行命令、访问工作区外路径、浏览器、MCP、computer-use 等逐次审批。
3. **完全访问**：自动执行，仅建议在隔离或可恢复任务中使用。

审批卡会显示：

- 风险级别（低 / 中 / 高）与人话说明。
- 命令、路径、diff 或 JSON 预览。
- 「允许一次」「始终允许（本工作区）」「拒绝」；高风险/外部动作不提供持久允许。
- `Enter` 允许一次，`Esc` 拒绝；有弹窗盖在上面时不会误触。

持久规则在 设置 → 权限 中管理；命令前缀规则要求 token 边界，且不会覆盖 shell 链式命令。

## 5. 文件与命令边界

- 文件路径先 realpath，再校验是否位于已登记工作区内；符号链接/junction 越界会被拒绝。
- 工作区外访问、危险命令、外部动作需要逐次审批；策略在权限模块统一执行。
- 写文件前创建快照；回退会校验快照哈希；外部修改冲突整次拒绝。
- 终端命令与一次性命令使用同一套危险命令/越界路径检查；stdin 写入需要一次性高风险审批。
- 技能安装会拒绝 zip-slip、绝对路径、符号链接与超大文件；脚本/可执行文件会被跳过并提示，不会执行。

## 6. 网页、MCP 与桌面操作

- 浏览器网页由独立 WebContentsView 渲染；摄像头、麦克风、定位与通知默认关闭；下载逐次确认。
- 网页内容按不可信资料处理；页面里的指令不能覆盖 Morrow 的系统规则或权限。
- MCP 工具、资源、提示词在调用前按权限档位审批；OAuth token 按用户/工作区/端点隔离。
- computer-use 只做受控的截图、点击、输入与按键；敏感窗口拒绝，逐次审批，有速率与坐标/窗口边界限制。
- 内置浏览器只接受 `http(s)://`，拒绝 `file:`、`javascript:` 等协议。

## 7. 输出与日志

- 主进程输出链路对已出现的邮箱、用户名、token 做遮蔽；流式分片结束后再做一次兜底扫描。
- 日志默认写本机，不自动上传；分享日志前请检查是否包含路径、命令或账号信息。
- 会话导出（Markdown/JSON）超过 32MB 会被拒绝；大文件请改用工作区文件。

## 8. 已知边界

- 当前仅提供 Windows 10/11 x64；未签名构建可能触发 SmartScreen。
- 本机 OCR 依赖 Windows 语言包；非 Windows 会给出明确错误。
- computer-use 仅 Windows；其它平台会提示改用浏览器工具。
- 终端使用真实 PTY；应用退出时终端与后台任务会结束。
- 回退只覆盖 Morrow 通过写文件工具修改的文件；命令直接生成的文件不在范围内。
- 第三方服务、模型、MCP 服务器与网页自身的安全问题不在 Morrow 的控制范围内。

## 9. 报告安全问题

不要公开披露利用细节。请按 [SECURITY.md](../SECURITY.md) 的渠道私下报告，并附影响版本、复现步骤、影响范围与最小样例；不要附带真实 Key、用户文件或第三方隐私数据。
