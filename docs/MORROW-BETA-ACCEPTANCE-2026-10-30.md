# Morrow 最终功能验收与内测放行

验收日期：2026-10-30。版本：**0.2.0 / r056**。依据：[上一轮修复复审](MORROW-REPAIR-REAUDIT-2026-10-30.md)、当前生产源码及实际交付包。基准提交为 `684acd52423069377edc47277c75a6135e355da1`，验收包含当前工作区尚未提交的修复。

## 1. 项目决定

**批准 Morrow 0.2.0 r056 开启内测。上一轮 N01–N10 已全部闭环，本轮没有发现需要阻止内测的新功能断点。**

当前核心功能能够完成从操作入口、后台处理、保存到结果展示的链路；已检查页面的主要按钮、状态提示和冲突处理入口齐全，常规及窄窗口下未发现阻塞操作的遮挡或显示异常。此次结论基于独立重跑和截图复核，不仅依据修复方的说明。

本轮验收至此收口。后续以真实内测反馈决定修复优先级；文学质量、生成效果和尚未复现的边界推测不追加为本轮放行条件。

## 3. 核心链路与 UI / UX

本轮按现有产品范围验收，核心登记覆盖 **38 个功能域**，详细映射沿用 [测试说明](TESTING.md)。主要实际流程包括：

- **Agent 工作区：**会话及分支、附件、工具调用、权限允许与拒绝、聊天/工作/计划模式、目标暂停与继续、上下文压缩、项目、定时任务、记忆、研究、连接器与技能。
- **文件与开发工具：**文件预览、文件操作、编辑保存及保存期间继续输入、内置浏览器操作、真实 Git Bash、Git 初始化/差异/提交/分支/历史。
- **小说：**新建、蓝图、大纲、六章正文、候选稿、质检与审稿、Word/EPUB、工程包导出及导入后正文一致；长篇分批失败后继续。
- **漫剧：**超过 12 章的小说改编实际将全部 15 章正文送入模型请求；分镜局部重做与续作、冲突候选、画布编辑与保存、媒体/声音/时间线及检查、交付页面。

界面检查同时使用真实 Electron 操作、控件位置断言和人工看图。通过了 1280×800 写作台展开协作者、查找替换栏、时间线工具栏，以及 1360×960 画布、交付和检查页的布局检查。分镜候选在 1600×900 深色、1280×800 浅色下均能阅读和操作，候选区域横向溢出为 0。

留档截图：[写作与替换](verification/screens/beta-final-2026-10-30/writing-1280.png)、[时间线](verification/screens/beta-final-2026-10-30/timeline-1280.png)、[画布](verification/screens/beta-final-2026-10-30/canvas-1360.png)、[交付播放器](verification/screens/beta-final-2026-10-30/delivery-1360.png)、[审稿覆盖](verification/screens/beta-final-2026-10-30/review-coverage.png)、[浅色冲突候选](verification/screens/beta-final-2026-10-30/conflict-light-1280.png)、[便携包首屏](verification/screens/beta-final-2026-10-30/packaged-home.png)。
