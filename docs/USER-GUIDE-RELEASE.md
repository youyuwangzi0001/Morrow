# Morrow 使用说明

> 住在你电脑里的 AI 工作伙伴。你说话，它动手。
> 版本 1.0.0 · Windows 10/11 便携版 · 2026-10

![Morrow 欢迎页](screenshots/welcome.png)

---

## 一、5 分钟上手

### 1. 打开 Morrow

双击 `Morrow-1.0.0-portable.exe`。第一次启动会解压到临时目录，需要几秒钟。

> 便携版会把数据存在 exe 旁边的 `Morrow Data` 文件夹里。把 exe 和这个文件夹一起拷走，换台电脑也能接着用。

### 2. 先看一场演示（不需要 API Key）

首次引导里点 **「先看一场演示」**，或者欢迎页点 **「看一场演示」**。
大约 40 秒，Morrow 会真实地读取一份季度销售数据、发现数据问题、生成一份可以直接发给老板的 HTML 分析报告，并自动在右侧画布打开。

这是最快理解 Morrow 的方式：**你能看到它的每一步，而不是只看到一个转圈。**

### 3. 连接你的模型

Morrow 本身不含任何隐藏服务，需要你提供一个模型 API Key（数据从你的电脑直接发往模型提供方）。

1. 打开 **设置 → 模型连接**（左下角齿轮，或 `Ctrl + ,`）
2. 选择 **DeepSeek**（推荐，中文好、便宜、支持工具调用）
3. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key（`sk-` 开头）
4. 粘贴进 Morrow，点 **测试连接**，成功后保存
5. 回到主界面，选择模型 `DeepSeek V3.2 Chat` 或 `DeepSeek Reasoner`

也支持 Anthropic、OpenAI、Kimi（月之暗面），以及任何 **OpenAI 兼容** 的自建服务（填写 Base URL、模型名即可）。

> 你的 API Key 只保存在本机，使用 Windows DPAPI（safeStorage）加密，不会上传到任何地方，也不会出现在日志里。

### 4. 选择工作文件夹

工作文件夹是 Morrow 的「工作台边界」：它可以读写这个文件夹里的文件、在里面运行命令。不在这个文件夹里的文件，必须经过你批准才能访问。

点侧栏 **工作区 → 选择工作文件夹**，选一个你希望它干活的目录（例如桌面上的某个项目文件夹）。

### 5. 说出你想要的结果

在输入框里用日常语言描述目标，越具体越好：

- 「把 `下载` 文件夹里的发票按月份整理成表格，生成一个 Excel」
- 「读一下这三份 CSV，找出异常订单，写一份给老板看的分析报告」
- 「帮我把这个文件夹里的图片批量重命名，格式：日期_项目_序号」
- 「写一个单文件 HTML 小工具：输入体重身高算 BMI，离线可用」

按 `Enter` 发送，`Shift + Enter` 换行。Morrow 会先列计划，再一步一步执行。

## 二、你会看到什么

### 计划（Plan）

长任务会在输入框上方出现「计划」托盘，实时更新每一步状态。它不只是装饰——Morrow 真的按计划推进，你可以随时看它做到哪了。

### 行动轨迹（Spine）

对话流里的竖线 + 菱形节点，是 Morrow 的「行动轨迹」：每一次读文件、写文件、运行命令都会留下一行记录，带人类可读的说明和耗时。点开可以看到完整参数、命令输出和文件差异（diff）。

### 审批卡

默认「询问」权限模式下，写文件、运行命令前会弹出一张审批卡，告诉你它想做什么、影响哪个文件/目录：

- **允许一次**：只批准这一次
- **本次会话都允许**：同类操作在本对话内不再询问（谨慎使用）
- **拒绝**：Morrow 会换一种做法，或停下来问你

快捷键：`Enter` 允许一次，`Esc` 拒绝。

### 画布（Canvas）

生成的网页、报告、图表、代码会出现在右侧画布：HTML 实时预览、Markdown 渲染、代码高亮、SVG 预览。可以「在浏览器中打开」「在文件夹中显示」「另存为」。

### 上下文用量

顶栏会显示当前对话的上下文占用。接近上限时 Morrow 会自动压缩早前对话（摘要保留关键信息）；输入 `/compact` 可以随时手动压缩。压缩只会缩短「模型看到的上下文」，你的完整对话记录仍保留在本机。

### 撤销一次文件修改

如果 Morrow 改了某个文件，展开那次工具记录，点「撤销这次修改」，文件会恢复到修改前的内容（Morrow 在每次写入前都会自动备份）。

## 三、常用操作与快捷键

| 操作 | 方式 |
|---|---|
| 新建对话 | `Ctrl + N` |
| 搜索 / 命令面板 | `Ctrl + K` |
| 折叠 / 展开侧栏 | `Ctrl + B` |
| 设置 | `Ctrl + ,` |
| 发送消息 | `Enter` |
| 换行 | `Shift + Enter` |
| 停止生成 / 停止任务 | 输入框右侧停止按钮，或 `Esc` |

| 复制消息 | 鼠标悬停消息 → 复制 |

## 四、权限与安全

Morrow 默认使用 **询问** 权限模式，三个模式：

| 模式 | 读文件/搜索 | 写文件/运行命令 | 适合 |
|---|---|---|---|
| 只读 | 自动 | 拒绝 | 只想让它分析、不想让它改东西 |
| 询问（默认） | 自动 | 每次询问 | 大多数场景 |
| 自动 | 自动 | 工作区内自动，工作区外/高危命令仍询问 | 熟练用户、批量任务 |

安全设计：

- **工作区沙箱**：文件工具被限制在你选择的工作文件夹内；越界访问必须单独批准。
- **危险命令拦截**：格式化磁盘、删除系统目录、修改注册表、执行远程脚本等命令会被拦下或强制询问。
- **本地优先**：会话、设置、产物都在本机；只有对话内容会发送给你配置的模型服务商。
- **Key 加密存储**：Windows DPAPI 加密；日志不记录 Key、不记录文件内容。

## 五、数据在哪里

| 内容 | 位置 |
|---|---|
| 便携版数据 | exe 同级的 `Morrow Data/` |
| 安装版数据（如你自行打包安装版） | `%APPDATA%\Morrow` |
| 会话记录 | `Morrow Data/sessions/<id>.json` |
| 文件改动备份（用于撤销） | `Morrow Data/snapshots/<会话 id>/` |
| 设置与加密 Key | `Morrow Data/settings.json`、`secrets.json` |
| 运行日志 | `Morrow Data/logs/main.log` |

设置 → 关于 → 「打开数据目录 / 打开日志」可直接跳转。

## 六、常见问题

**Q：提示「还没有连接模型」怎么办？**
A：打开设置 → 模型连接，填好 API Key 并点「测试连接」。也可以先用演示模式体验全部功能。

**Q：连接测试失败？**
A：按提示排查：401/403 多为 Key 无效或复制不完整；404 多为 Base URL 不对（很多服务需要以 `/v1` 结尾）；超时检查网络/代理。DeepSeek 官方地址是 `https://api.deepseek.com/v1`。

**Q：它要运行一条命令，我该不该允许？**
A：看审批卡上的命令和影响路径。不确定就点「拒绝」，然后告诉它「换个安全的方式」，Morrow 会调整做法。

**Q：文件被改坏了怎么办？**
A：Morrow 在每次写文件前会备份原文件到 `Morrow Data/snapshots/`。展开写入记录点「撤销这次修改」，即可恢复。

**Q：可以离线用吗？**
A：演示模式完全离线（演示过程自动执行，不会打断你确认）。真实任务需要模型服务，因此需要网络（连接你的 API 服务商）。

**Q：支持 Claude / GPT 吗？**
A：支持。设置里选择 Anthropic 或 OpenAI，填入对应 Key 即可。

**Q：我的数据会被收集吗？**
A：不会。Morrow 没有遥测、没有账号体系、不向我们的服务器发送任何数据。

## 七、卸载

便携版：关闭 Morrow，删除 exe 与旁边的 `Morrow Data` 文件夹即可，不写注册表、不留系统残留。
