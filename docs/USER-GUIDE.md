# Morrow 用户指南

本指南按真实使用顺序编写：先安装和连接模型，再选择工作区，最后用对话、画布、终端和工作台完成任务。所有说明以当前 0.1.0（r019）实现为准。

## 1. 安装与首次启动

### 1.1 选择发布包

Morrow 提供两种 Windows x64 交付形态：

- **单文件便携版** `Morrow-0.1.0-portable.exe`：首次运行在 exe 同级解压 `.morrow-runtime-0.1.0-r019`，之后秒开；数据默认也在 exe 同级的 `Morrow Data`。
- **NSIS 安装包** `Morrow-0.1.0-setup.exe`：按当前用户安装，创建开始菜单/桌面快捷方式；数据默认在 `%APPDATA%\Morrow`。

当前构建未配置代码签名，首次运行可能弹出 SmartScreen：点“更多信息 → 仍要运行”。下载后建议用 `SHA256SUMS.txt` 核对文件完整性。

### 1.2 三步引导

首次启动会进入三步引导：

1. 认识 Morrow 的工作方式；
2. 连接一个模型（API Key、本机服务或订阅账号）；
3. 选择工作文件夹。

![首次启动](guide/screens/01-onboarding-dark.png)

引导可以被关闭，但建议至少完成模型连接与工作区选择，否则无法执行真实任务。

### 1.3 数据目录

可在「设置 → 关于」查看和迁移数据目录。迁移会重启应用，并复制会话、设置、记忆、项目、技能、快照与日志；不包含系统浏览器缓存/登录态。便携版的“数据目录跟随 exe”是默认行为，删除 exe 同级的 `Morrow Data` 等于删除本机数据，请先备份。

## 2. 界面地图

![主界面](guide/screens/02-chat-home-dark.png)

- **标题栏**：左侧侧栏开关与当前文件夹；中间会话标题（双击或 F2 重命名）；右侧浏览器、终端、画布开关与窗口控制。
- **侧栏**：新建对话、临时对话、搜索/命令、项目、定时任务、文件树、会话分组（临时/置顶/今天/昨天/更早）和底部设置。侧栏可拖动调宽（200–400px），也可收起为 64px 图标栏。
- **主区**：消息轨迹、计划、来源、运行中心、队列与输入框（Composer）。
- **右侧画布**：多标签文件/成品、编辑器、预览、版本历史与导出；宽度 320–960px。
- **底部终端**：真实 PTY、多标签、后台任务。
- **灵动岛**：独立置顶小窗，显示当前会话进度、todo 和快速发送入口；可跟随主窗口切换会话。

## 3. 选择工作区

Morrow 的所有文件工具、终端和媒体输入都要求路径位于已登记工作区内。选择一个文件夹后：

- 文件树会扫描该文件夹；
- 新建的对话会绑定该工作区；
- 项目可以引用同一个文件夹并保存项目背景/资料；
- 终端 cwd 默认进入工作区；
- 拖入/粘贴的附件会先进入附件目录，不会自动修改工作区文件。

临时对话不写入项目记忆，也不会持久化到会话列表；适合一次性问答或敏感内容试算。

## 4. 五种工作方式

输入框左下方可在“聊天 / 工作”之间切换；`/research` 进入深度研究；`/goal` 进入长期目标；`/plan` 进入计划模式。

| 方式 | 能做什么 | 不能做什么 |
|---|---|---|
| 聊天 | 只读文件、搜索、提问、联网（已配置时） | 写文件、执行命令、写记忆、启动集群 |
| 工作 | 读写文件、运行命令、终端、Git、媒体与完整工具链 | 仍受权限/审批与工作区边界约束 |
| 计划 | 只读探索，产出可审阅计划；批准后转执行 | 批准前不能写入或执行 |
| 深度研究 | 搜索/抓取、保留来源、生成报告、上画布 | 只读工具集合；固定自动权限但有研究白名单 |
| 目标 | 跨轮持续推进，直到完成或预算耗尽 | 完成必须提供工作区内、非空、晚于目标创建的证据文件 |

### 4.1 计划模式

计划模式只读探索，最多 2 步，最后用 `submit_plan` 提交计划。批准后 Morrow 会把计划转为执行任务和 todo。计划过程中不会写入文件，也不会执行命令。

### 4.2 深度研究

研究深度：

- `quick`：2 轮 / 4 个来源；
- `standard`：4 轮 / 10 个来源；
- `deep`：6 轮 / 20 个来源。

研究计划阶段不暴露工具，批准后才开始检索。报告带来源；来源面板可查看实际抓取的页面。研究中的插话只写入下一轮，不会强行打断当前工具。

### 4.3 长期目标

目标模式需要明确目标、验收标准和预算。默认 2–256 轮，预算包含工具调用、有效时间和连续无进展轮。完成声明必须附带工作区内证据文件；没有证据时目标会继续。同一时刻只允许一个目标循环；应用重启后运行中的目标会变为暂停。

## 5. 输入框（Composer）

### 5.1 模型、思考强度、上下文

- **模型**：只列出已启用且已保存 Key/登录态的 Provider；显示模型原始名称，不加营销后缀。
- **思考强度**：只显示模型真实支持的档位；不支持思考时显示“不支持思考”；未知模型只有“自动”。
- **上下文上限**：仅对声明了可调档位的模型显示（例如 Qoder 账号目录的 200K/400K/1M）。选择后会写入会话，右侧上下文环和请求都会使用该值。

DeepSeek 的 `off` 在请求层会映射为官方 `none`；Qoder 代理保留自己的 `off`。不需要手动改环境变量。

### 5.2 权限

输入框右侧的“只读 / 询问 / 完全访问”对应三档工作权限：

- **只读**：拒绝写文件、执行命令和写记忆；
- **询问**：普通写/命令按工作区放行；危险命令、越界路径、外部副作用动作逐次询问；
- **完全访问**：自动放行普通操作；危险/越界/外部动作仍不可“始终允许”。

### 5.3 附件与引用

- 最多 8 个附件；单张图片 ≤5MB，超过会压缩/转码到最长边 1568px；
- 图片会作为视觉输入附在当前消息里；纯文本附件会按 UTF-8/BOM/GB18030 解码；
- `@相对路径` 引用工作区文件；模型仍需用 `read_file` 读取正文；
- 只发附件不写字也可以发送。

### 5.4 斜杠命令

内置命令包括：

`/new`、`/temp`、`/demo`、`/plan`、`/research`、`/settings`、`/btw`、`/swarm`、`/goal`、`/init`、`/clear`、`/rewind`、`/export`、`/export-json`、`/git`、`/usage`、`/compact`。

工作区 `.morrow/commands/*.md` 和用户 `~/.morrow/commands/*.md` 可以定义自定义命令；支持 `description`、`argument-hint`、`$ARGUMENTS` 与 `$1..$9`。保留名不能被自定义命令覆盖。

### 5.5 运行中的操作

运行中输入框会切换为三种动作：

- **闪电**：先取消当前运行，再立即发送（steer）；
- **箭头**：加入队列，本轮结束后自动发送；
- **方块**：停止当前运行。

队列按会话隔离，最多 20 条、单条 20k 字、最多 8 个附件；取消/出错时队列保留，正常完成或达到步数上限后自动开始下一条。

## 6. 审批与权限

![审批卡](guide/screens/03-permission-card-dark.png)

审批卡会展示工具、目标、影响范围、风险标签和可展开的预览。常见按钮：

- **允许一次**：只对本次调用生效；
- **始终允许**：只对同一工具 + 目标 + 参数哈希生效，并落为工作区 allow 规则；
- **拒绝**：工具返回 denied，运行继续，模型需要自行调整。

危险命令、越界路径、外部副作用命令不提供“始终允许”。审批日志在 `permissions/approval-log.jsonl`，规则在 `permissions.json`。deny 规则优先；allow 不能越过危险/越界/外部动作限制。

## 7. 画布、文件与预览

![画布与编辑器](guide/screens/04-editor-canvas-dark.png)

- **多标签**：成品与打开的文件在同一画布栏；有脏标记与只读标记；页签为 24px 高、5px 微圆角。
- **编辑器**：CodeMirror，语法高亮、查找、撤销/重做、保存（Ctrl+S）、另存为、版本历史、强制保存；只读模式会锁定编辑。
- **预览**：HTML、Markdown、SVG、图片、PDF、Word、Excel、PPT、压缩包、音频、视频；不支持的格式可“系统应用打开 / 文件夹中显示 / 重新加载”。
- **版本历史**：每个文本成品最多 30 个版本，单版最多 8MB；可 diff、恢复、导出。
- **导出**：原文件、Markdown、网页、纯文本、PDF。
- **快照**：写/编辑/删除前自动备份；撤销前会校验当前文件哈希，冲突时拒绝覆盖。
- **检查点**：每个用户轮次最多 100 个，可回退代码、对话或两者；命令产生的副作用不在通用回退范围内。

## 8. 终端、Git 与浏览器

### 8.1 终端

![真实终端](guide/screens/10-terminal-dark.png)

- 终端面板使用真实 PTY（Windows ConPTY），默认 Shell 为 **Git Bash**；可在设置 → 终端选择 PowerShell 7 / WSL。
- 旧版 Windows PowerShell 5.1 与 CMD 选项已移除；保存的旧选择会自动回退到默认。
- 支持多标签、拖动调高、复制粘贴、后台任务、停止/重启；关闭面板后进程继续运行。
- 滚动条只在内容溢出时显示；轨道 8px、滑块 6px 实色全圆角、无渐变。
- 受限令牌/低完整性环境可能无法运行 Git Bash（MSYS 共享内存错误）；此时切 PowerShell 7。

### 8.2 Git 工作台

Git 面板提供：

- 变更、diff、暂存/取消暂存、提交；
- 新建/切换分支、历史记录、放弃改动；
- 未跟踪文件可丢弃，越界路径和非变更文件拒绝；
- 工作区位于更大仓库内部时拒绝操作，避免影响仓库根。

### 8.3 内置浏览器

![内置浏览器](guide/screens/09-browser-tabs-dark.png)

浏览器支持多标签、地址栏、主页、前进/后退和真实页面内容。登录窗口与普通浏览共用浏览器服务，但登录 session 有自己的 http(s) 导航白名单。网页内容视为不可信数据，不能当作 Agent 指令。

## 9. 项目、记忆、技能、MCP 与定时任务

### 9.1 项目

![项目主页](guide/screens/12-projects-dark.png)

项目保存背景、说明、资料文件、会话与当前文件夹范围。项目资料单文件 ≤512KB、最多 20 个；失效资料会被标记，仍可保存修改。项目页可以在当前文件夹范围新建会话，首句会自动注入项目说明与资料上下文。

### 9.2 记忆中心

![记忆中心](guide/screens/11-memory-center-dark.png)

- 项目记忆：跟随工作区，存于 `<workspace>/.morrow/memories.json`（兼容迁移 `MEMORY.md`）。
- 全局长期记忆：存于 `<dataDir>/memories/global.json`。
- 任务经验：项目内 `.morrow/episodes.json` 或全局 `episodes/global.json`。
- 记忆中心支持新增、启停、删除、注入预览和自进化建议；临时对话不写入记忆。

### 9.3 技能

- 内置技能：需求澄清、前端艺术方向、画布成品、文档交付、数据分析、调试、重构、测试、MCP、Web 研究、技能编写等。
- 用户技能：`~/.morrow/skills/`；工作区技能：`<workspace>/.morrow/skills/<name>/SKILL.md`。
- 安装 Markdown/zip 技能包时会跳过脚本可执行文件，并保留 zip-slip/大小/数量安全限制。
- 技能是参考资料，不是授权；不能扩大权限。

### 9.4 MCP

支持 stdio、Streamable HTTP、旧版 SSE。配置优先级：显式路径 → `MORROW_MCP_CONFIG` → `<dataDir>/mcp.json` → `<workspace>/.morrow/mcp.json`。工作区配置需要 `mcp-trust.json` 哈希登记后才会启动。OAuth token 存在 `mcp-oauth.json`；MCP 资源、提示词、工具结果都有大小上限。

### 9.5 定时任务

设置 → 功能与工具 → 定时任务。支持一次/每天/每周，最多 50 个；应用运行中每 5 秒检查，同一时刻只跑一个；错过后 1 小时内补跑，单次 30 分钟超时。无人值守任务自动拒绝审批和提问，不会挂起。

## 10. 多媒体与本地模型

![多媒体模型](guide/screens/08-media-models-dark.png)

### 10.1 引擎与模型

- **ComfyUI**：设置目录后启动 `python main.py --listen 127.0.0.1 --port 8188 --reserve-vram 2.5`；120 秒健康检查。
- **llama.cpp**：自动补 `-m/--host/--port/--alias`，180 秒超时；只停止自己启动的进程。
- **Ollama / LM Studio**：可安装、拉取/删除模型；不杀其他服务的模型。
- 内置模型：Qwen-Image 2.1 Turbo（图片/编辑）、MiniMax-H3 16G HiFi（视频）、Qwen3.8-27B-Coder390（视觉/代码）。
- 也支持任意自定义清单、ComfyUI API 工作流和本机文件注册。

### 10.2 生成、编辑与审看

- `generate_image`：5 种尺寸，支持参考图改图；
- `generate_video`：16:9 / 9:16 / 1:1，fast/balanced/high，5–15 秒；
- `generate_film`：2–6 镜，Qwen 首帧 + MiniMax 视频 + 尾帧续接 + ffmpeg 拼接；
- `render_animation`：0.5–60 秒、8–30fps；
- `edit_media`：trim/crop/resize/rotate/flip/speed/mute/volume/提取音频/抽帧/GIF/转码/拼接；
- `inspect_media`：ffprobe 元数据；`describe_media`：图片或视频抽 1–4 帧审看。

**审看优先级**：当前对话模型 → 声明视觉能力的本地模型 → 真实失败。当前模型支持图片输入时不会被本地模型抢先；视觉请求会关闭思考并给足输出预算。两者都不可用时返回真实错误，并提示换视觉模型或启用带 `--mmproj` 的本地视觉模型；不会用生图模型冒充审看。详见 [多媒体与本地模型](MEDIA-MODELS.md)。

订阅凭据加密保存，渲染层只显示“已连接”和额度；具体协议、模型目录与限制见 [订阅接入](SUBSCRIPTIONS.md)。

## 13. 常用任务配方

### 13.1 整理一个文件夹

1. 选择文件夹；
2. 输入“先扫描这个文件夹，列出重复/过期文件，给出一份整理方案，批准后再移动”；
3. 在计划模式审阅方案，批准后执行；
4. 在改动卡里检查文件列表与 diff，必要时撤销。

### 13.2 开发一个页面并验收

1. 工作模式，选择项目文件夹；
2. 输入目标、受众、视觉方向和验收标准；
3. 让 Morrow 先读现有 token/组件，再实现；
4. 用内置浏览器打开真实页面，检查交互与双主题；
5. 需要时用 `describe_media` 审看截图，最后用 `open_artifact` 放上画布。

### 13.3 研究一个主题

1. 输入 `/research`；
2. 选择 quick/standard/deep；
3. 审阅研究计划，批准后等待检索；
4. 在来源面板核对链接与摘要，导出报告。

### 13.4 生成并审看一张图

1. 设置 → 多媒体确认引擎/模型；
2. 输入具体画面描述，调用生成；
3. 生成后让 Morrow 用 `describe_media` 审看；
4. 根据建议重生成或 `edit_media`。

## 14. 常见问题

**为什么没有模型可选？** 需要先在设置 → 模型保存 Key/登录态，并启用 Provider。侧栏显示“未连接”时模型下拉会被过滤。

**为什么审批一直弹？** 检查当前权限档位与规则；危险命令、越界路径、外部动作始终逐次确认。可在设置 → 权限查看审批日志。

**为什么终端里 Git Bash 报 MSYS 错误？** 受限令牌/低完整性环境无法创建共享内存；在设置 → 终端切 PowerShell 7。默认值仍是 Git Bash。

**为什么模型不显示思考档位？** 当前模型没有声明思考能力；未知模型只保留“自动”。不要用其他模型的档位强行套用。

**为什么审看仍然失败？** 当前模型未返回文字且本机没有可用视觉模型；按错误提示换支持图片的模型，或启用带 `--mmproj` 的本地视觉模型。Morrow 不会用生图模型或纯文本模型伪造审看。

**数据在哪里？** 便携版在 exe 同级 `Morrow Data`；安装版在 `%APPDATA%\Morrow`。设置 → 关于可迁移。

更多问题见 [排障指南](TROUBLESHOOTING.md)。
