# Morrow 使用说明

> 住在你电脑里的 AI 工作伙伴。你说话，它动手：读文件、写代码、跑命令、做报告，把成品放到你面前。
> 版本：0.1.0 · Windows 10/11 x64 便携版 · 2026-10

---

## 文件、编辑器与工具

- **文件树**：左侧「文件夹」下展开；右键/键盘可新建、重命名、删除（二次确认）、复制路径、在资源管理器显示；只读模式禁用写操作；点击文件在右侧打开。
- **多格式预览**：文本/代码进编辑器；图片（含 SVG/ICO/AVIF/TIFF/HEIC）、PDF、Word（.docx）、Excel（.xlsx，可切工作表）、PowerPoint（.pptx）、RTF/ODT/ODS/ODP/EPUB、ZIP 目录、CSV/TSV 表格、音频、视频可在应用内查看；旧版 .doc/.xls/.ppt 与 7z/RAR/TAR 等回退系统应用打开。
- **扫描版 PDF**：PDF 里的文字层会直接抽取；没有文字层的扫描页会自动用 Windows 本机 OCR 识别（离线、不上传），每次最多 12 页，识别结果会标注“可能有错字，关键数字请对照原页复核”。本机缺少中文 OCR 语言包时会明确说明，并建议分批读取或发关键页截图。
- **深度研究**：把输入框旁的模式切到「研究」，选择快速/标准/深入后发送研究问题。Morrow 会先给出可编辑的研究计划（目标、范围、子问题、检索策略、报告结构、需要确认项），确认后才开始多轮联网搜索、读取来源与交叉核对；来源或报告不足时会自动补查（轮次、独立来源数与用时显示在研究条上），过程中可追加研究要求或随时停止，最终把带引用的 Markdown 报告放到画布。研究模式不修改文件、不运行命令，需要先在设置 → 联网搜索配置服务；来源不足或到轮次上限会如实说明，不会伪造报告。
- **附件**：可粘贴、拖入或选择最多 8 个文本/图片/文件；图片会本地缩放到视觉接口可用的大小。PDF/Word/Excel/PPT 会保留完整路径并授权本轮对话只读访问，即使文件在下载目录也能读取；扫描版 PDF 会自动调用本机 OCR 识别页面文字。单条消息文本附件合计最多发送 8 万字符、图片合计 20MB，超出的部分会截断或标记未发送；发送后图片和附件名称保留在历史消息中。
- **多对话运行**：一个任务运行时可以切到其他对话查看；侧栏金色圆点表示运行中、锈红圆点表示等待确认；输入框上方可「返回处理」或「停止」，待审批不会因切换对话而丢失。
- **临时对话**：侧栏「临时对话」或输入 `/temp`。只存在内存里，不写会话文件、不进入历史与搜索、不计入 token 统计，也不读取或写入长期记忆与项目说明；关闭应用后自动消失。临时对话不做整轮回退，但文件改动仍可在执行过程里逐个撤销。
- **全局回答风格**：设置 →「回答」选择平衡、简洁、讲解或正式，也可以写自己的偏好。选择会保存到本机，对之后所有对话、侧边聊天与定时任务生效；它只改变措辞和结构，不改变工具权限、安全规则、引用与核验要求，研究报告和计划等固定格式仍以任务要求为准。
- **编辑器**：语法高亮、多标签、查找替换、撤销重做、保存/另存、外部修改冲突、Markdown/HTML 预览、版本历史与恢复；超过 8MB 的文本只读预览开头，避免误改大文件。
- **成品版本与导出**：画布顶部的时钟图标查看成品版本（文本快照最多 30 个，可预览、确认后恢复）；分享图标可导出独立网页、Markdown、纯文本或 A4 PDF，文件只写入本机，不会上传。
- **对话附件**：点输入框的回形针或直接把文件拖进输入框，也可以只发附件不写字。文本按 UTF-8 / UTF-16 / GB18030 读取，BMP 与超大图片会先在本地转成 PNG/JPEG；单条最多 8 个附件，超长文本会截断并提示。输入 `@` 可引用文件夹文件，模型会先读取再回答。
- **功能与工具**：设置 →「功能与工具」集中打开技能、记忆、项目、定时任务、MCP 外部工具、全局搜索、浏览器、版本历史。终端使用顶栏入口（默认 Shell 在「设置 → 终端」里选）。顶栏不再单独放工作台；`Ctrl+K` 也可直接搜到这些入口。
- **全局搜索**：默认跨全部项目搜索对话、文件和生成结果，也可以切到「当前文件夹」缩小范围；点击对话结果会切到对应会话并滚动到原句，金色高亮提示位置。
- **内置浏览器**：Agent 与用户共用同一个可见页面，不会在隐藏窗口里偷偷操作；它操作时会显示金色「Morrow 操作中」，导航和错误都实时反映在面板里。网页下载统一在面板里由你确认。
- **版本历史（Git）**：`/git` 或设置 →「功能与工具」打开。查看已暂存与未暂存改动、逐行差异、暂存/取消暂存、放弃改动（二次确认）、提交（可先暂存全部）、切换/新建分支与浏览最近提交；只操作当前文件夹内仓库，推送/拉取请使用终端。
- **终端**：点顶栏终端按钮打开底部终端（默认高 240px，只占用对话与右侧栏下方），可在「设置 → 终端」选择 PowerShell 7、Windows PowerShell、命令提示符、Git Bash 或 WSL。支持标签页、交互式程序、复制粘贴（Ctrl+Shift+C / V）和拖动上沿调高度；收起后进程继续运行，关闭标签会结束对应进程。Morrow 也能读取和操作这些终端。
- **自定义命令**：在文件夹 `.morrow/commands/<名字>.md`（或用户级 `~/.morrow/commands`）放 Markdown 模板，支持 `$ARGUMENTS`/`$1..$9`；输入 `/` 从菜单选择并填写参数。内置命令名（如 `/new`、`/swarm`）保留，重名文件不会出现在菜单。设置 → 自动化 可查看已发现命令。
- **自动动作**：设置 → 自动化 添加命令，支持「发送消息前」（返回码 2 阻止）、「每次工具完成后」「每轮结束后」；每个时点最多启用 5 个。命令会以与 Morrow 相同的文件和网络权限运行，请只添加可信命令。
- **侧边聊天（/btw）**：点输入框旁的对话气泡按钮，或输入 `/btw 问题`，在右侧栏直接提问（与画布共用栏宽，不遮挡主输入框）；默认带上主对话最近内容作答，不写文件、不跑命令、不写入主对话，可随时停止；停止后保留已生成内容并标记「已停止」，模型输出被截断时会显示服务商提示。关闭后本次侧聊仍保留，切换主对话时自动清空。
- **集群（Agent Swarm）**：输入 `/swarm 目标` 或让模型用 swarm 工具，把 2–8 个独立子任务并行交给不同角色（探索者 / 规划者 / 审查者 / 验证者 / 文档写作者 / 通用执行者），最多 8 个同时推进。执行过程会实时显示每个子任务是等待、进行中还是完成，以及步数与结论；有失败项时不会当成全部完成。角色只限制工具与提示词，写入/命令/外部调用仍逐次审批；设置 → 自动化 可查看角色，或在 `.morrow/agents/*.md` 添加自定义角色。Kimi Work 也把同类能力称为「Agent 集群」，英文官方名是 Agent Swarm。
- **记忆与项目**：记忆可增删改/启停/导出；项目可以写长期说明、添加参考资料，启用后 Morrow 做任务时会参考。项目面板可在「全部项目 / 当前文件夹」之间切换；当前文件夹没有项目时可直接新建，说明与资料只用于这个文件夹里的对话。
- **外部工具（MCP）**：设置 →「外部工具（MCP）」→「工具目录」可一键安装 GitHub、Linear、文件系统、长期记忆、顺序思考、Notion、Playwright、Context7 等。在线服务用 Token 连接；本机服务会先检测 Node.js。安装会真实写入配置并加密保存密钥，可先测试再保存；也可以在列表里手动添加，或为需要 OAuth 的服务（如 Sentry）手动填写授权信息。每次调用外部工具都会先询问你。
- **技能**：内置 12 个任务技能（代码审查、缺陷排查、测试、文档、数据分析、联网调研、重构、发布说明、安全审计、界面打磨、交付报告、MCP 集成），首次启动自动安装，可在面板查看/启停/删除；修改过的内置技能不会被后续启动覆盖。也支持从本地文件夹或 .zip 安装自己的技能；只从本地安装，不联网、不执行代码。
- **全局搜索**：搜索对话、当前文件夹里的文件和生成结果（中文）；新建/删除对话会立即刷新索引，成品结果会切回所属对话打开。
- **computer-use**：Windows 截图/点击/输入，需逐次批准；只操作当前前台窗口，敏感窗口拒绝。
- **定时任务**：侧栏「定时任务」或设置 →「功能与工具」打开；支持一次/每天/每周，到点自动新建一段对话并执行。Morrow 需要保持运行（关闭窗口后请留在托盘）；重启时 1 小时内错过的任务会补跑一次。默认为只读，也可按任务允许修改文件；无人值守不提问，单次运行超过 30 分钟会自动停止，结果可在定时任务面板或对话里查看。

## 一、5 分钟上手

### 1. 打开 Morrow

**单文件便携版**。运行 `Morrow-0.1.0-portable.exe`。

1. 如果 exe 是从浏览器或聊天工具下载的，先右键 exe → 属性 → 勾选「解除锁定」→ 确定，再双击（去掉 Windows 的“来自 Internet”标记）。
2. 首次运行会把应用解压到 exe 同级的隐藏目录 `.morrow-runtime-0.1.0/`（不依赖系统临时目录，约 5–10 秒，带进度小窗），之后启动约 0.5 秒。
3. 如果 Windows 弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」——v0.1.0 还没有代码签名（`signed:false`），这不是病毒提示；解除下载锁定后通常不会再出现。配置受信任的代码签名证书重新打包后，提示才可能消失（新证书仍需积累下载信誉）。

数据默认存在 exe 同级的 `Morrow Data` 文件夹里。把 exe 和 `Morrow Data` 一起拷走，换台电脑也能接着用。交付包不包含任何用户数据、缓存或密钥。

也可以在「设置 → 关于 → 数据目录」点 **更改目录**，选择空文件夹并决定是否迁移现有数据；应用会重启，原目录保留。迁移包含对话、设置、项目、记忆与技能，不包含内置浏览器缓存/登录状态。想回到默认目录时点 **恢复默认目录**；恢复不会自动合并两边的数据。

如果双击没有反应（部分安全软件会拦截未签名程序），可以：
1. 确认已解除 exe 的下载锁定；
2. 把 exe 加入安全软件白名单；
3. 检查文件是否被隔离，必要时重新下载并核对 SHA-256。

<details>
<summary>为什么需要「兼容模式」？</summary>

部分 Windows 环境（受限启动器、特定安全策略或高权限对话）下，Chromium 的渲染沙箱会在初始化阶段
直接崩溃，表现为「双击后进程秒退、没有窗口」。启动器会自动加上 `--no-sandbox` 以兼容这类环境。
这只关闭浏览器的渲染沙箱；Morrow 的文件文件夹沙箱、工具权限审批、危险命令拦截仍然全部生效，
并且应用只渲染本地内容，不加载远程网页。

</details>

### 2. 界面里的几个好用操作

- **布局比例**：默认左侧栏 **240px**、右侧画布 **420px**（拖动时实时显示 px 读数），这是最协调的三栏比例；
  旧版本的 264/560 默认宽度会在升级后一次性迁移，自定义过的宽度保持不变。
- **侧栏宽度**：把鼠标移到侧栏右边缘，左右拖动即可调宽（200–400px）；拖动时有一条 1px 香槟金
  提示线跟随，松手后自动记住。双击边缘恢复 240px，也可以用方向键微调。
- **完全收起侧栏**：点顶栏左侧的侧栏按钮（或 Ctrl+B），侧栏会完全隐藏，写作区域占满窗口；
  再点一次恢复。
- **画布开关**：顶栏右侧的画布按钮（文件夹图标左边）可以随时展开/收起右侧画布。没有成品时
  会打开一个带有三步说明的空画布；有成品时自动显示最近一个。
- **画布宽度**：把鼠标移到画布左缘左右拖动即可调宽（320–960px），提示线与左侧栏完全一致；
  松手自动记住，双击恢复 420px。
- **上下文用量**：输入框右下角的 `3.4k/1.05M` 是当前对话真实 token 占用（点击可直接打开设置 →
  上下文）；顶栏的上下文圆环悬停可看精确数字与「API 精确/估算」。
- **自动压缩**：设置 → 上下文 可以开关自动压缩、拖动阈值（默认 80%），也可以随时「立即压缩」。
- **Token 活动**：设置 → 用量。始终是一天一格的热力图；「每天 / 每周 / 累计总量」只改变统计口径：单日用量、所在自然周合计、截至当天的历史累计，悬浮可见对应数值与请求次数。

### 3. 目标模式：让 Morrow 自己多轮推进长任务

在输入框左侧点 **Target 图标 → 建立目标**，写下你真正要的结果（例如「分三轮调研并产出竞品报告，
每轮推进一个阶段」）即可开始。轮次预算会按目标复杂度自动估算（无需手填，最高 200 轮），
同时有工具调用数、有效运行时间、连续无进展三类预算；之后 Morrow 会自动一轮接一轮推进：

- 每轮结束会调用 `update_goal` 记录「本轮摘要 + 下一步」；
- 目标条（输入框上方）显示状态、轮次、进度与下一步，可随时 **暂停 / 继续 / 结束目标**；
- **标记完成必须有真实证据**：`update_goal(completed)` 会核验文件夹内成品真实存在，否则拒绝完成；
- 手动「结束目标」记为 **已取消**，不会伪装成完成；暂停/重启后可从同一 Goal 继续，进度和预算不重置；
- 达到轮次/工具/时间/无进展任一预算、或确认阻塞后会诚实停止并说明原因；
- 目标运行期间输入框会锁定（暂停后可恢复输入），标题栏会显示目标状态与 `N/M` 轮次；
- 历史里的每轮续跑显示为金色的「目标续跑 · 第 N/M 轮」行，不会淹没成普通消息。

> 隐私保护：Morrow 会在主进程输出链路把工具结果中出现过的邮箱、token 等敏感值自动遮蔽为
> `[REDACTED]`，即使模型想复述原值也不会进入可见回复与持久对话。

### 4. 聊天 / 工作：只讨论，还是动手做

输入框右下角新增 **聊天 / 工作** 切换：

- **聊天**：只讨论与分析，工具层只开放只读能力（读文件、看目录、搜索、读文档），不会写文件、不跑命令、
  不写记忆、不推进目标；想让它动手时会提示你切到工作模式。
- **工作**：保留全部能力（文件、命令、计划、目标、小助手等），执行前按权限档位审批。
- 模式随对话保存，重启后保持；运行中不能切换（可停止后切换）。

### 5. 文档与技能

- 支持直接读取 **PDF / Word(.docx) / Excel(.xlsx) / PowerPoint(.pptx)**：Word 用 `read_docx`、PDF 用 `read_pdf`、
  Excel 用 `read_xlsx`、PPT 用 `read_pptx`；替换 Word 占位符用 `edit_docx`（写出新文件，原文件不变）；生成带公式的 Excel 用
  `write_xlsx`（字符串以 `=` 开头就是真公式，LibreOffice 可重算）。
- 从输入框附加的 PDF/Word/Excel/PPT 即使不在当前文件夹里，也会获得本条对话的只读访问权限；扫描版 PDF
  目前不能自动 OCR，把需要阅读的页面截图发进对话即可直接看图。
- 文件夹里有 `.morrow/skills/<name>/SKILL.md`（或 `skills/`）时，Morrow 会自动发现技能，先读
  `SKILL.md` 再按要求执行；技能文字只是资料，不是用户授权。

### 6. 外部工具（MCP / 网页）

- 需要核对网页证据时，Morrow 可用 `web_fetch`（只 GET、有 SSRF 防护、返回最终 URL/状态/清洗后正文）；
- 需要外部系统时，在「设置 → 功能与工具 → 外部工具（MCP）」添加 MCP server（本机程序 stdio、网络服务 HTTP、旧版 SSE），
  Morrow 会先 `mcp_list` 再 `mcp_call`；**每次外部调用都会询问你**（自动模式也一样），拒绝后不会换方式绕过；
- 外部工具密钥在系统加密存储中保存，面板只显示掩码；新建或改名到已存在的名称会被拒绝；`mcp.json` 或密钥文件损坏时会拒绝保存并提示先修复/备份，不会用空配置覆盖；
- 内置浏览器与 computer-use 可做网页/GUI 操作，同样受文件夹边界与逐次审批约束。

### 7. 图标与桌面快捷方式

- 应用图标是新的 2.5D 香槟金地平线徽记，已编入 exe（任务栏/窗口使用）；
- 桌面 **Morrow** 图标：右键 `Morrow-0.1.0-portable.exe` → 发送到 → 桌面快捷方式。这只是启动方式，不会改变未签名状态，安全软件仍可能拦截。
- 当前版本未签名（`Get-AuthenticodeSignature` = `NotSigned`）。首次运行可能遇到一次 SmartScreen，按「更多信息 → 仍要运行」处理；受信任的代码签名证书才能从根本上消除该提示。

### 8. 先看一场演示（不需要 API Key）

首次引导里点 **「先看一场演示」**，或者欢迎页点 **「看一场演示」**。
大约 40 秒，Morrow 会真实地读取一份季度销售数据、发现数据问题、生成一份可以直接发给老板的 HTML 分析报告，并自动在右侧画布打开。

演示只在自己的一次性演示文件夹里运行，不会成为默认模型，也不会写进你的真实文件夹。

这是最快理解 Morrow 的方式：**你能看到它的每一步，而不是只看到一个转圈。**

### 9. 连接你的模型

Morrow 本身不含任何隐藏服务，需要你提供一个模型 API Key（数据从你的电脑直接发往模型提供方）。

1. 打开 **设置 → 模型**（左下角齿轮，或 `Ctrl + ,`）
2. 选择 **DeepSeek**（推荐，中文好、便宜、支持工具调用）
3. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key（`sk-` 开头）
4. 粘贴进 Morrow，点 **测试连接**，成功后保存
5. 回到主界面，选择模型 `DeepSeek V4.1 Flash` 或 `DeepSeek V4 Pro`

也支持 Anthropic（含 Claude Fable 5.1）、OpenAI、Kimi、通义千问、智谱 GLM、MiniMax、小米 MiMo、Meta Muse、Gemini、Grok、OpenRouter，以及任何 **OpenAI 兼容** 的自建服务（填写服务地址、模型 ID 即可）。
本地运行 Ollama / LM Studio 时，在「模型」里选择对应本地服务，填好本地地址即可，**不需要 API Key**；点「刷新可用模型」可读取本机已安装的模型。

输入框下方的「推理强度」可选择 `auto` / `low` / `medium` / `high` / `xhigh` / `max`：越高越适合复杂任务，但更慢、更贵；`auto` 由模型自己决定。

> 你的 API Key 只保存在本机，使用 Windows DPAPI（safeStorage）加密，不会上传到任何地方，也不会出现在日志里。设置里可随时「清除密钥」（需二次确认），清除后该服务会标记为未连接。

### 4. 选择工作文件夹

工作文件夹是 Morrow 的「工作范围」：它可以读写这个文件夹里的文件、在里面运行命令。不在这个文件夹里的文件，必须经过你批准才能访问。

点侧栏 **文件夹 → 选择工作文件夹**，选一个你希望它干活的目录（例如桌面上的某个项目文件夹）。

### 5. 说出你想要的结果

在输入框里用日常语言描述目标，越具体越好：

- 「把 `下载` 文件夹里的发票按月份整理成表格，生成一个 Excel」
- 「读一下这三份 CSV，找出异常订单，写一份给老板看的分析报告」
- 「帮我把这个文件夹里的图片批量重命名，格式：日期_项目_序号」
- 「写一个单文件 HTML 小工具：输入体重身高算 BMI，离线可用」

按 `Enter` 发送，`Shift + Enter` 换行。Morrow 会先列计划，再一步一步执行。

## 二、你会看到什么

### 计划（Plan）

长任务会在输入框上方出现「计划」托盘，实时更新每一步状态。它不只是装饰——Morrow 真的按计划推进，你可以随时看它做到哪了。

### 执行过程（Spine）

对话流里的竖线 + 菱形节点，是 Morrow 的「执行过程」：每一次读文件、写文件、运行命令都会留下一行记录，带人类可读的说明和耗时。点开可以看到完整参数、命令输出和文件差异（diff）。

### 审批卡

默认「询问」权限模式下，写文件、运行命令前会弹出一张审批卡，告诉你它想做什么、影响哪个文件/目录：

- **允许一次**：只批准这一次
- **始终允许（本文件夹）**：同类操作在当前文件夹不再询问；规则可在「设置 → 权限」中随时删除（谨慎使用）
- **拒绝**：Morrow 会换一种做法，或停下来问你

快捷键：`Enter` 允许一次，`Esc` 拒绝。

### 画布（Canvas）

生成的网页、报告、图表、代码会出现在右侧画布：HTML 实时预览、Markdown 渲染、代码高亮、SVG 预览。只有内联内容的成品可以直接「保存到文件夹」，写入当前文件夹的 `artifacts/` 并回写路径；已有文件的成品可以「在浏览器中打开」「在文件夹中显示」。

- **版本历史**：点画布顶部的时钟图标。每次成品内容变化都会保存一份文本快照（初始版本、Morrow 修改、手动修改、恢复记录），最多保留 30 个；选中任一版本可预览原文并一键恢复，恢复前会再确认一次，当前内容不会被删掉，而是继续留在历史里。图片、PDF 等二进制成品不做文本快照。
- **导出成品**：点画布顶部的导出图标，可把成品导出为独立网页、Markdown、纯文本或 A4 PDF；导出前会打开系统保存框，文件只写入你选择的本地位置，不会上传。HTML 报告转 Markdown 会保留标题、列表、表格、代码块和链接；PDF 会带上报告里的本地图片。导出弹窗里也能直接把 Markdown、HTML 或纯文本复制到剪贴板。

### 上下文用量

顶栏会显示当前对话的上下文占用。接近上限时 Morrow 会自动压缩早前对话；输入 `/compact` 可以随时手动压缩。较早的消息会被折叠成一条「上下文已压缩」摘要（点开可查看），原文随之从对话记录中移除；需要留存的资料请先另存到文件夹。

### 撤销一次文件修改

如果 Morrow 改了某个文件，展开那次工具记录，点「撤销这次修改」，文件会恢复到修改前的内容（Morrow 在每次写入前都会自动备份）。

## 四、权限与安全

Morrow 默认使用 **询问** 权限模式，三个模式：

| 模式 | 读文件/搜索 | 写文件/运行命令 | 适合 |
|---|---|---|---|
| 只读 | 自动 | 拒绝 | 只想让它分析、不想让它改东西 |
| 询问（默认） | 自动 | 每次询问 | 大多数场景 |
| 自动 | 自动 | 文件夹内自动，文件夹外/高危命令仍询问 | 熟练用户、批量任务 |

安全设计：

- **文件夹沙箱**：文件工具被限制在你选择的工作文件夹内；越界访问必须单独批准。
- **危险命令拦截**：格式化磁盘、删除系统目录、修改注册表、执行远程脚本等命令会被拦下或强制询问。
- **本地优先**：对话、设置、成品都在本机；只有对话内容会发送给你配置的模型服务商。
- **扫描 OCR 在本机**：扫描版 PDF 的页面渲染与文字识别都调用 Windows 自带能力，离线完成，不上传原文件；只有识别出的文字会随对话发给模型。
- **Key 加密存储**：Windows DPAPI 加密；日志不记录 Key、不记录文件内容。

## 五、数据在哪里

| 内容 | 位置 |
|---|---|
| 便携版数据 | exe 同级的 `Morrow Data/` |
| 安装版数据（如你自行打包安装版） | `%APPDATA%\Morrow` |
| 对话记录 | `Morrow Data/sessions/<id>.json` |
| 文件改动备份（用于撤销） | `Morrow Data/snapshots/<对话 id>/` |
| 设置与加密 Key | `Morrow Data/settings.json`、`secrets.json` |
| 运行日志 | `Morrow Data/logs/main.log` |

设置 → 关于 → 「更改目录 / 打开数据目录 / 打开日志」可直接操作；自定义目录会显示「自定义」标记，并可通过「恢复默认目录」移除。

设置 → 归档 集中管理已归档的对话：可以恢复回侧栏，或只删除其中一条。页面底部的「清除全部对话」会删除所有对话（包括已归档的），以及它们的撤销快照、检查点、成品版本、token 用量和审批历史；文件夹里的文件、设置、记忆、项目和 API Key 不会被删除。删除操作确认后无法撤销。

## 六、常见问题

**Q：提示「还没有连接模型」怎么办？**
A：打开设置 → 模型，填好 API Key 并点「测试连接」。也可以先看演示了解工作方式；演示模型不能用于真实任务。

**Q：连接测试失败？**
A：按提示排查：401/403 多为 Key 无效或复制不完整；404 多为 Base URL 不对（很多服务需要以 `/v1` 结尾）；超时检查网络/代理。DeepSeek 官方地址是 `https://api.deepseek.com/v1`。

**Q：它要运行一条命令，我该不该允许？**
A：看审批卡上的命令和影响路径。不确定就点「拒绝」，然后告诉它「换个安全的方式」，Morrow 会调整做法。

**Q：文件被改坏了怎么办？**
A：Morrow 在每次写文件前会备份原文件到 `Morrow Data/snapshots/`。展开写入记录点「撤销这次修改」，即可恢复。

**Q：可以离线用吗？**
A：演示模式完全离线（演示过程自动执行，不会打断你确认）。真实任务需要模型服务，因此需要网络（连接你的 API 服务商）。

**Q：支持 Claude / GPT 吗？**
A：支持。设置里选择 Anthropic 或 OpenAI，填入对应 Key 即可。

**Q：我的数据会被收集吗？**
A：不会。Morrow 没有遥测、没有账号体系、不向我们的服务器发送任何数据。

## 七、卸载

便携版：关闭 Morrow，删除 exe 与旁边的 `Morrow Data` 文件夹即可，不写注册表、不留系统残留。如果改过数据目录，请先在「设置 → 关于」确认实际路径，再删除对应文件夹。
