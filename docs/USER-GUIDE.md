# Morrow 使用说明

> 住在你电脑里的 AI 工作伙伴。你说话，它动手：读文件、写代码、跑命令、做报告，把成品放到你面前。
> 版本：1.0.0 · Windows 10/11 x64 便携版 · 2026-10

---

## R10 工作台

- **文件树**：左侧「工作区」下展开；右键/键盘可新建、重命名、删除（二次确认）、复制路径、在资源管理器显示；只读模式禁用写操作；点击文件在右侧编辑器打开。
- **编辑器**：语法高亮、多标签、查找替换、撤销重做、保存/另存、外部修改冲突、Markdown/HTML 预览、版本历史与恢复。
- **工作台**：标题栏网格图标（Ctrl+Shift+W）→ 技能库 / 记忆中心 / 项目 / 连接器 / 全局搜索 / 内置浏览器。
- **记忆与项目**：记忆中心可增删改/启停/导出；项目可写指令、添加知识文件，启用后注入 Agent 上下文。
- **连接器**：管理 MCP 工具（本机或网络），密钥只在本机加密保存；所有外部调用逐次询问。
- **技能库**：本地安装/启停技能；只从本地安装，不联网、不执行代码。
- **全局搜索**：搜索聊天、文件内容和生成结果（中文）。
- **computer-use**：Windows 截图/点击/输入，需逐次批准；只操作当前前台窗口，敏感窗口拒绝。
- J 定时任务本轮不做。

## 一、5 分钟上手

### 1. 打开 Morrow

**推荐：文件夹便携版**。解压 `Morrow-1.0.0-portable-win64.zip`，进入文件夹，双击 **`启动 Morrow.cmd`**（会先清除下载标记、自动创建桌面快捷方式，再启动）。

> 为什么用 cmd：Windows 对未签名且带“来自 Internet”标记的 exe 会弹 SmartScreen；`启动 Morrow.cmd` 先清标记再启动，可避免这个弹窗。直接双击 `Morrow.exe` 在已解除标记的本机也可用；单文件 exe 首次直接双击仍可能被系统拦截，请用随包 `启动单文件版（清除安全标记）.cmd`。
> 如桌面快捷方式已存在，启动器不会覆盖；可运行 `创建桌面快捷方式.cmd` 重建。

> 文件夹里有两个 exe，不要删错：`Morrow.exe` 是启动器，`Morrow-app.exe` 是应用本体。
> 启动器会自动以兼容模式启动应用，因此双击一定能打开窗口。

数据会存在 exe 同级的 `Morrow Data` 文件夹里。把整个文件夹拷走，换台电脑也能接着用。

如果双击没有反应（部分安全软件会拦截未签名程序），可以：
1. 右键 `Morrow.exe` → 属性 → 勾选「解除锁定」；
2. 或运行同目录的 `启动 Morrow（兼容模式）.cmd`；
2. 或把整个文件夹加入安全软件白名单。

**备选：单文件 exe**。`Morrow-1.0.0-portable.exe` 内嵌完整应用，首次运行会解压到 exe 同级的
隐藏目录 `.morrow-runtime-1.0.0/`（不依赖系统临时目录，约 5–10 秒，带进度小窗），之后启动约 0.5 秒。

> 单文件 exe 未做代码签名，Windows 可能弹出「无法验证发布者」安全警告：
> 点「更多信息」→「仍要运行」即可。想跳过这个提示，请用上面的文件夹版。

<details>
<summary>为什么需要「兼容模式」？</summary>

部分 Windows 环境（受限启动器、特定安全策略或高权限会话）下，Chromium 的渲染沙箱会在初始化阶段
直接崩溃，表现为「双击后进程秒退、没有窗口」。启动器会自动加上 `--no-sandbox` 以兼容这类环境。
这只关闭浏览器的渲染沙箱；Morrow 的文件工作区沙箱、工具权限审批、危险命令拦截仍然全部生效，
并且应用只渲染本地内容，不加载远程网页。

</details>

### 2. 界面里的几个好用操作

- **布局比例**：默认左侧栏 **240px**、右侧画布 **420px**（拖动时实时显示 px 读数），这是最协调的三栏比例；
  旧版本的 264/560 默认宽度会在升级后一次性迁移，自定义过的宽度保持不变。
- **侧栏宽度**：把鼠标移到侧栏右边缘，左右拖动即可调宽（200–400px）；拖动时有一条 1px 香槟金
  提示线跟随，松手后自动记住。双击边缘恢复 240px，也可以用方向键微调。
- **完全收起侧栏**：点顶栏左侧的侧栏按钮（或 Ctrl+B），侧栏会完全隐藏，写作区域占满窗口；
  再点一次恢复。
- **画布开关**：顶栏右侧的画布按钮（文件夹图标左边）可以随时展开/收起右侧画布。没有成品时
  会打开一个带有三步说明的空画布；有成品时自动显示最近一个。
- **画布宽度**：把鼠标移到画布左缘左右拖动即可调宽（320–960px），提示线与左侧栏完全一致；
  松手自动记住，双击恢复 420px。
- **上下文用量**：输入框右下角的 `3.4k/1.05M` 是当前会话真实 token 占用（点击可直接打开设置 →
  上下文）；顶栏的上下文圆环悬停可看精确数字与「API 精确/估算」。
- **自动压缩**：设置 → 上下文 可以开关自动压缩、拖动阈值（默认 80%），也可以随时「立即压缩」。

### 3. 目标模式：让 Morrow 自己多轮推进长任务

在输入框左侧点 **Target 图标 → 建立目标**，写下你真正要的结果（例如「分三轮调研并产出竞品报告，
每轮推进一个阶段」）即可开始。轮次预算会按目标复杂度自动估算（无需手填，最高 200 轮），
同时有工具调用数、有效运行时间、连续无进展三类预算；之后 Morrow 会自动一轮接一轮推进：

- 每轮结束会调用 `update_goal` 记录「本轮摘要 + 下一步」；
- 目标条（输入框上方）显示状态、轮次、进度与下一步，可随时 **暂停 / 继续 / 结束目标**；
- **标记完成必须有真实证据**：`update_goal(completed)` 会核验工作区内产物真实存在，否则拒绝完成；
- 手动「结束目标」记为 **已取消**，不会伪装成完成；暂停/重启后可从同一 Goal 继续，进度和预算不重置；
- 达到轮次/工具/时间/无进展任一预算、或确认阻塞后会诚实停止并说明原因；
- 目标运行期间输入框会锁定（暂停后可恢复输入），标题栏会显示目标状态与 `N/M` 轮次；
- 历史里的每轮续跑显示为金色的「目标续跑 · 第 N/M 轮」行，不会淹没成普通消息。

> 隐私保护：Morrow 会在主进程输出链路把工具结果中出现过的邮箱、token 等敏感值自动遮蔽为
> `[REDACTED]`，即使模型想复述原值也不会进入可见回复与持久会话。

### 4. 聊天 / 工作：只讨论，还是动手做

输入框右下角新增 **聊天 / 工作** 切换：

- **聊天**：只讨论与分析，工具层只开放只读能力（读文件、看目录、搜索、读文档），不会写文件、不跑命令、
  不写记忆、不推进目标；想让它动手时会提示你切到工作模式。
- **工作**：保留全部能力（文件、命令、计划、目标、子代理等），执行前按权限档位审批。
- 模式随会话保存，重启后保持；运行中不能切换（可停止后切换）。

### 5. 文档与技能

- 支持直接读取 **PDF / Word(.docx) / Excel(.xlsx)**：Word 用 `read_docx`、PDF 用 `read_pdf`、
  Excel 用 `read_xlsx`；替换 Word 占位符用 `edit_docx`（写出新文件，原文件不变）；生成带公式的 Excel 用
  `write_xlsx`（字符串以 `=` 开头就是真公式，LibreOffice 可重算）。
- 工作区里有 `.morrow/skills/<name>/SKILL.md`（或 `skills/`）时，Morrow 会自动发现技能，先读
  `SKILL.md` 再按要求执行；技能文字只是资料，不是用户授权。

### 6. 外部工具（MCP / 网页）

- 需要核对网页证据时，Morrow 可用 `web_fetch`（只 GET、有 SSRF 防护、返回最终 URL/状态/清洗后正文）；
- 需要外部系统时，把 MCP server 配置写入用户数据目录 `mcp.json`（格式见 `docs/EXTERNAL-TOOLS.md`），
  Morrow 会先 `mcp_list` 再 `mcp_call`；**每次外部调用都会询问你**（自动模式也一样），拒绝后不会换方式绕过；
- 浏览器/GUI 自动化、MCP HTTP/SSE 本轮未支持，产品不会假装能做。

### 7. 图标与桌面快捷方式

- 应用图标是新的 2.5D 香槟金地平线徽记，已编入 exe（任务栏/窗口使用）；
- 想要桌面图标：运行便携文件夹里的 **`创建桌面快捷方式.cmd`**，会在桌面创建带该图标的 `Morrow.lnk`。

### 8. 先看一场演示（不需要 API Key）

首次引导里点 **「先看一场演示」**，或者欢迎页点 **「看一场演示」**。
大约 40 秒，Morrow 会真实地读取一份季度销售数据、发现数据问题、生成一份可以直接发给老板的 HTML 分析报告，并自动在右侧画布打开。

这是最快理解 Morrow 的方式：**你能看到它的每一步，而不是只看到一个转圈。**

### 9. 连接你的模型

Morrow 本身不含任何隐藏服务，需要你提供一个模型 API Key（数据从你的电脑直接发往模型提供方）。

1. 打开 **设置 → 模型连接**（左下角齿轮，或 `Ctrl + ,`）
2. 选择 **DeepSeek**（推荐，中文好、便宜、支持工具调用）
3. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key（`sk-` 开头）
4. 粘贴进 Morrow，点 **测试连接**，成功后保存
5. 回到主界面，选择模型 `DeepSeek V3.2 Chat` 或 `DeepSeek Reasoner`

也支持 Anthropic、OpenAI、Kimi（月之暗面），以及任何 **OpenAI 兼容** 的自建服务（填写 Base URL、模型名即可）。

> 你的 API Key 只保存在本机，使用 Windows DPAPI（safeStorage）加密，不会上传到任何地方，也不会出现在日志里。

### 4. 选择工作文件夹

工作文件夹是 Morrow 的「工作台边界」：它可以读写这个文件夹里的文件、在里面运行命令。不在这个文件夹里的文件，必须经过你批准才能访问。

点侧栏 **工作区 → 选择工作文件夹**，选一个你希望它干活的目录（例如桌面上的某个项目文件夹）。

### 5. 说出你想要的结果

在输入框里用日常语言描述目标，越具体越好：

- 「把 `下载` 文件夹里的发票按月份整理成表格，生成一个 Excel」
- 「读一下这三份 CSV，找出异常订单，写一份给老板看的分析报告」
- 「帮我把这个文件夹里的图片批量重命名，格式：日期_项目_序号」
- 「写一个单文件 HTML 小工具：输入体重身高算 BMI，离线可用」

按 `Enter` 发送，`Shift + Enter` 换行。Morrow 会先列计划，再一步一步执行。

## 二、你会看到什么

### 计划（Plan）

长任务会在输入框上方出现「计划」托盘，实时更新每一步状态。它不只是装饰——Morrow 真的按计划推进，你可以随时看它做到哪了。

### 行动轨迹（Spine）

对话流里的竖线 + 菱形节点，是 Morrow 的「行动轨迹」：每一次读文件、写文件、运行命令都会留下一行记录，带人类可读的说明和耗时。点开可以看到完整参数、命令输出和文件差异（diff）。

### 审批卡

默认「询问」权限模式下，写文件、运行命令前会弹出一张审批卡，告诉你它想做什么、影响哪个文件/目录：

- **允许一次**：只批准这一次
- **本次会话都允许**：同类操作在本对话内不再询问（谨慎使用）
- **拒绝**：Morrow 会换一种做法，或停下来问你

快捷键：`Enter` 允许一次，`Esc` 拒绝。

### 画布（Canvas）

生成的网页、报告、图表、代码会出现在右侧画布：HTML 实时预览、Markdown 渲染、代码高亮、SVG 预览。可以「在浏览器中打开」「在文件夹中显示」「另存为」。

### 上下文用量

顶栏会显示当前对话的上下文占用。接近上限时 Morrow 会自动压缩早前对话（摘要保留关键信息）；输入 `/compact` 可以随时手动压缩。压缩只会缩短「模型看到的上下文」，你的完整对话记录仍保留在本机。

### 撤销一次文件修改

如果 Morrow 改了某个文件，展开那次工具记录，点「撤销这次修改」，文件会恢复到修改前的内容（Morrow 在每次写入前都会自动备份）。

## 四、权限与安全

Morrow 默认使用 **询问** 权限模式，三个模式：

| 模式 | 读文件/搜索 | 写文件/运行命令 | 适合 |
|---|---|---|---|
| 只读 | 自动 | 拒绝 | 只想让它分析、不想让它改东西 |
| 询问（默认） | 自动 | 每次询问 | 大多数场景 |
| 自动 | 自动 | 工作区内自动，工作区外/高危命令仍询问 | 熟练用户、批量任务 |

安全设计：

- **工作区沙箱**：文件工具被限制在你选择的工作文件夹内；越界访问必须单独批准。
- **危险命令拦截**：格式化磁盘、删除系统目录、修改注册表、执行远程脚本等命令会被拦下或强制询问。
- **本地优先**：会话、设置、产物都在本机；只有对话内容会发送给你配置的模型服务商。
- **Key 加密存储**：Windows DPAPI 加密；日志不记录 Key、不记录文件内容。

## 六、常见问题

**Q：提示「还没有连接模型」怎么办？**
A：打开设置 → 模型连接，填好 API Key 并点「测试连接」。也可以先用演示模式体验全部功能。

**Q：连接测试失败？**
A：按提示排查：401/403 多为 Key 无效或复制不完整；404 多为 Base URL 不对（很多服务需要以 `/v1` 结尾）；超时检查网络/代理。DeepSeek 官方地址是 `https://api.deepseek.com/v1`。

**Q：它要运行一条命令，我该不该允许？**
A：看审批卡上的命令和影响路径。不确定就点「拒绝」，然后告诉它「换个安全的方式」，Morrow 会调整做法。

**Q：文件被改坏了怎么办？**
A：Morrow 在每次写文件前会备份原文件到 `Morrow Data/snapshots/`。展开写入记录点「撤销这次修改」，即可恢复。

**Q：可以离线用吗？**
A：演示模式完全离线（演示过程自动执行，不会打断你确认）。真实任务需要模型服务，因此需要网络（连接你的 API 服务商）。

**Q：支持 Claude / GPT 吗？**
A：支持。设置里选择 Anthropic 或 OpenAI，填入对应 Key 即可。

**Q：我的数据会被收集吗？**
A：不会。Morrow 没有遥测、没有账号体系、不向我们的服务器发送任何数据。

## 七、卸载

便携版：关闭 Morrow，删除 exe 与旁边的 `Morrow Data` 文件夹即可，不写注册表、不留系统残留。
