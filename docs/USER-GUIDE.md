# Morrow 用户指南

本指南按真实使用顺序编写：先安装和连接模型，再选择工作区，最后用对话、画布、终端和创作台完成任务。所有说明以当前 0.2.0（r036）实现为准。

## 1. 安装与首次启动

### 1.1 选择发布包

Morrow 提供两种 Windows x64 交付形态：

- **单文件便携版** `Morrow-0.2.0-portable.exe`：首次运行在 exe 同级解压 `.morrow-runtime-0.2.0-r036`，之后秒开；数据默认也在 exe 同级的 `Morrow Data`。
- **NSIS 安装包** `Morrow-0.2.0-setup.exe`：默认安装到 Program Files（需要管理员权限），创建开始菜单/桌面快捷方式；数据默认在 `%APPDATA%\Morrow`。

当前构建未配置代码签名，首次运行可能弹出 SmartScreen：点“更多信息 → 仍要运行”。下载后建议用 `SHA256SUMS.txt` 核对文件完整性。

### 1.2 三步引导

首次启动会进入三步引导：

1. 认识 Morrow 的工作方式；
2. 连接一个模型（API Key、本机服务或订阅账号）；
3. 选择工作文件夹。

![首次启动](guide/screens/01-onboarding-dark.png)

引导可以被关闭，但建议至少完成模型连接与工作区选择，否则无法执行真实任务。

### 1.3 数据目录

可在「设置 → 关于」查看和迁移数据目录。迁移会重启应用，并复制会话、设置、记忆、项目、技能、快照与日志；不包含系统浏览器缓存/登录态。便携版的“数据目录跟随 exe”是默认行为，删除 exe 同级的 `Morrow Data` 等于删除本机数据，请先备份。

## 2. 界面地图

![主界面](guide/screens/02-chat-home-dark.png)

- **标题栏**：左侧侧栏开关与当前文件夹；中间会话标题（双击或 F2 重命名）；右侧浏览器、终端、画布开关与窗口控制。
- **侧栏**：新建对话、临时对话、搜索/命令、项目、定时任务、文件树、会话分组（临时/置顶/今天/昨天/更早）和底部设置。侧栏可拖动调宽（200–400px），也可收起为 64px 图标栏。
- **主区**：消息轨迹、计划、来源、运行中心、队列与输入框（Composer）。
- **右侧画布**：多标签文件/成品、编辑器、预览、版本历史与导出；宽度 320–960px。
- **底部终端**：真实 PTY、多标签、后台任务；打开后从侧栏右缘铺满整个主区，画布或侧聊打开时也从其下方贯通。
- **灵动岛**：独立置顶小窗，显示当前会话进度、todo 和快速发送入口；可跟随主窗口切换会话。

### 2.1 进入创作台

- 标题栏右侧的「创作台」、欢迎页的创作卡或命令面板都能进入创作台；顶栏「回到 Agent」随时回到原来的对话。
- 创作台内没有产品标题和产品图标；作品库、当前作品和阶段菜单在界面内直接操作。生成的形象图标只在第一次进入时的使用指引出现。
- 创作台的左侧阶段栏与右侧协作栏都可拖动调宽：默认 240 / 420px，悬浮/拖动时只高亮面板自身的 1px 香槟金边框并显示像素读数，双击恢复默认；浅色与深色主题一致。页面次级按钮会变成带提示的图标，镜头详情和人物/事实抽屉不会盖住正文。
- 顶栏「设置」按模型与预算、配音与引擎、历史版本、数据与安全四页整合，排版与 Agent 设置一致；顶栏预算按钮直接落到预算区。作品库与新建作品是独立按钮。数据与安全 → 创作台数据可更换目录，迁移创作台作品与历史版本，Agent 设置不移动。
- 时间线的视频预览会随窗口放大，4K/超宽屏下不再挤在窄条里；窗口较矮时会自动收紧，字幕轨和标签仍然完整分开显示。

![创作台设置](guide/screens/28-studio-settings-dark.png)
- 第一次进入会出现三页使用指引（与首次启动引导同一种沉浸式排版）；之后可从作品库右上角的「使用指引」再次打开。「看演示」会驱动真实创作台依次走完一句话、蓝图、分镜、时间线与交付，可暂停、前后切换，关闭后回到原现场。
- 先写一句话、看一遍并确认蓝图，再进入写作或分镜；所有生成任务都能在界面里看到进度和失败原因。检查页的任务账本可以展开完整消息流，外部 ComfyUI 任务重启后会自动对账。
- 完整步骤见 [创作台](STUDIO.md)。

![创作台作品库](guide/screens/13-studio-home-dark.png)

## 3. 选择工作区

Morrow 的所有文件工具、终端和媒体输入都要求路径位于已登记工作区内。选择一个文件夹后：

- 文件树会扫描该文件夹；
- 新建的对话会绑定该工作区；
- 项目可以引用同一个文件夹并保存项目背景/资料；
- 终端 cwd 默认进入工作区；
- 拖入/粘贴的附件会先进入附件目录，不会自动修改工作区文件。

临时对话不写入项目记忆，也不会持久化到会话列表；适合一次性问答或敏感内容试算。

## 4. 五种工作方式

输入框左下方可在“聊天 / 工作”之间切换；`/research` 进入深度研究；`/goal` 进入长期目标；`/plan` 进入计划模式。

| 方式 | 能做什么 | 不能做什么 |
|---|---|---|
| 聊天 | 只读文件、搜索、提问、联网（已配置时） | 写文件、执行命令、写记忆、启动集群 |
| 工作 | 读写文件、运行命令、终端、Git、媒体与完整工具链 | 仍受权限/审批与工作区边界约束 |
| 计划 | 只读探索，产出可审阅计划；批准后转执行 | 批准前不能写入或执行 |
| 深度研究 | 搜索/抓取、保留来源、生成报告、上画布 | 只读工具集合；固定自动权限但有研究白名单 |
| 目标 | 跨轮持续推进，直到完成或预算耗尽 | 完成必须提供工作区内、非空、晚于目标创建的证据文件 |

### 4.1 计划模式

计划模式只读探索，最多 2 步，最后用 `submit_plan` 提交计划。批准后 Morrow 会把计划转为执行任务和 todo。计划过程中不会写入文件，也不会执行命令。

### 4.2 深度研究

研究深度：

- `quick`：2 轮 / 4 个来源；
- `standard`：4 轮 / 10 个来源；
- `deep`：6 轮 / 20 个来源。

研究计划阶段不暴露工具，批准后才开始检索。报告带来源；来源面板可查看实际抓取的页面。研究中的插话只写入下一轮，不会强行打断当前工具。

### 4.3 长期目标

目标模式需要明确目标、验收标准和预算。默认 2–256 轮，预算包含工具调用、有效时间和连续无进展轮。完成声明必须附带工作区内证据文件；没有证据时目标会继续。同一时刻只允许一个目标循环；应用重启后运行中的目标会变为暂停。

## 5. 输入框（Composer）

### 5.1 模型、思考强度、上下文

- **模型**：只列出已启用且已保存 Key/登录态的 Provider；显示模型原始名称，不加营销后缀。
- **思考强度**：只显示模型真实支持的档位；不支持思考时显示“不支持思考”；未知模型只有“自动”。
- **上下文上限**：仅对声明了可调档位的模型显示（例如 Qoder 账号目录的 200K/400K/1M）。选择后会写入会话，右侧上下文环和请求都会使用该值。

DeepSeek 的 `off` 在请求层会映射为官方 `none`；Qoder 代理保留自己的 `off`。不需要手动改环境变量。

### 5.2 权限

输入框右侧的“只读 / 询问 / 完全访问”对应三档工作权限：

- **只读**：拒绝写文件、执行命令和写记忆；
- **询问**：普通写/命令按工作区放行；危险命令、越界路径、外部副作用动作逐次询问；
- **完全访问**：自动放行普通操作；危险/越界/外部动作仍不可“始终允许”。

### 5.3 附件与引用

- 最多 8 个附件；单张图片 ≤5MB，超过会压缩/转码到最长边 1568px；
- 图片会作为视觉输入附在当前消息里；纯文本附件会按 UTF-8/BOM/GB18030 解码；
- `@相对路径` 引用工作区文件；模型仍需用 `read_file` 读取正文；
- 只发附件不写字也可以发送。

### 5.4 斜杠命令

内置命令包括：

`/new`、`/temp`、`/demo`、`/plan`、`/research`、`/settings`、`/btw`、`/swarm`、`/goal`、`/init`、`/clear`、`/rewind`、`/export`、`/export-json`、`/git`、`/usage`、`/compact`。

工作区 `.morrow/commands/*.md` 和用户 `~/.morrow/commands/*.md` 可以定义自定义命令；支持 `description`、`argument-hint`、`$ARGUMENTS` 与 `$1..$9`。保留名不能被自定义命令覆盖。

### 5.5 运行中的操作

运行中输入框会切换为三种动作：

- **闪电**：先取消当前运行，再立即发送（steer）；
- **箭头**：加入队列，本轮结束后自动发送；
- **方块**：停止当前运行。

队列按会话隔离，最多 20 条、单条 20k 字、最多 8 个附件；取消/出错时队列保留，正常完成或达到步数上限后自动开始下一条。

## 6. 审批与权限

![审批卡](guide/screens/03-permission-card-dark.png)

审批卡会展示工具、目标、影响范围、风险标签和可展开的预览。常见按钮：

- **允许一次**：只对本次调用生效；
- **始终允许**：只对同一工具 + 目标 + 参数哈希生效，并落为工作区 allow 规则；
- **拒绝**：工具返回 denied，运行继续，模型需要自行调整。

危险命令、越界路径、外部副作用命令不提供“始终允许”。审批日志在 `permissions/approval-log.jsonl`，规则在 `permissions.json`。deny 规则优先；allow 不能越过危险/越界/外部动作限制。

## 7. 画布、文件与预览

![画布与编辑器](guide/screens/04-editor-canvas-dark.png)

- **多标签**：成品与打开的文件在同一画布栏；有脏标记与只读标记；页签为 24px 高、5px 微圆角。
- **编辑器**：CodeMirror，语法高亮、查找、撤销/重做、保存（Ctrl+S）、另存为、版本历史、强制保存；只读模式会锁定编辑。
- **预览**：HTML、Markdown、SVG、图片、PDF、Word、Excel、PPT、压缩包、音频、视频；不支持的格式可“系统应用打开 / 文件夹中显示 / 重新加载”。
- **版本历史**：每个文本成品最多 30 个版本，单版最多 8MB；可 diff、恢复、导出。
- **导出**：原文件、Markdown、网页、纯文本、PDF。
- **快照**：写/编辑/删除前自动备份；撤销前会校验当前文件哈希，冲突时拒绝覆盖。
- **检查点**：每个用户轮次最多 100 个，可回退代码、对话或两者；命令产生的副作用不在通用回退范围内。

## 8. 终端、Git 与浏览器

### 8.1 终端

![真实终端](guide/screens/10-terminal-dark.png)

- 终端面板使用真实 PTY（Windows ConPTY），默认 Shell 为 **Git Bash**；可在设置 → 终端选择 PowerShell 7 / WSL。终端始终占满侧栏右侧的整个宽度，不会在大屏上缩到中间。
- 旧版 Windows PowerShell 5.1 与 CMD 选项已移除；保存的旧选择会自动回退到默认。
- 支持多标签、拖动调高、复制粘贴、后台任务、停止/重启；关闭面板后进程继续运行。
- 滚动条只在内容溢出时显示；轨道 8px、滑块 6px 实色全圆角、无渐变。
- 受限令牌/低完整性环境可能无法运行 Git Bash（MSYS 共享内存错误）；此时切 PowerShell 7。

### 8.2 Git 工作台

Git 面板提供：

- 变更、diff、暂存/取消暂存、提交；
- 新建/切换分支、历史记录、放弃改动；
- 未跟踪文件可丢弃，越界路径和非变更文件拒绝；
- 工作区位于更大仓库内部时拒绝操作，避免影响仓库根。

### 8.3 内置浏览器

![内置浏览器](guide/screens/09-browser-tabs-dark.png)

浏览器支持多标签、地址栏、主页、前进/后退和真实页面内容。登录窗口与普通浏览共用浏览器服务，但登录 session 有自己的 http(s) 导航白名单。网页内容视为不可信数据，不能当作 Agent 指令。

## 9. 项目、记忆、技能、MCP 与定时任务

### 9.1 项目

![项目主页](guide/screens/12-projects-dark.png)

项目保存背景、说明、资料文件、会话与当前文件夹范围。项目资料单文件 ≤512KB、最多 20 个；失效资料会被标记，仍可保存修改。项目页可以在当前文件夹范围新建会话，首句会自动注入项目说明与资料上下文。

### 9.2 记忆中心

![记忆中心](guide/screens/11-memory-center-dark.png)

- 项目记忆：跟随工作区，存于 `<workspace>/.morrow/memories.json`（兼容迁移 `MEMORY.md`）。
- 全局长期记忆：存于 `<dataDir>/memories/global.json`。
- 任务经验：项目内 `.morrow/episodes.json` 或全局 `episodes/global.json`。
- 记忆中心支持新增、启停、删除、注入预览和自进化建议；临时对话不写入记忆。

### 9.3 技能

- 内置技能：需求澄清、前端艺术方向、画布成品、文档交付、数据分析、调试、重构、测试、MCP、Web 研究、技能编写等。
- 用户技能：`~/.morrow/skills/`；工作区技能：`<workspace>/.morrow/skills/<name>/SKILL.md`。
- 安装 Markdown/zip 技能包时会跳过脚本可执行文件，并保留 zip-slip/大小/数量安全限制。
- 技能是参考资料，不是授权；不能扩大权限。

### 9.4 MCP

支持 stdio、Streamable HTTP、旧版 SSE。配置优先级：显式路径 → `MORROW_MCP_CONFIG` → `<dataDir>/mcp.json` → `<workspace>/.morrow/mcp.json`。工作区配置需要 `mcp-trust.json` 哈希登记后才会启动。OAuth token 存在 `mcp-oauth.json`；MCP 资源、提示词、工具结果都有大小上限。

### 9.5 定时任务

设置 → 功能与工具 → 定时任务。支持一次/每天/每周，最多 50 个；应用运行中每 5 秒检查，同一时刻只跑一个；错过后 1 小时内补跑，单次 30 分钟超时。无人值守任务自动拒绝审批和提问，不会挂起。

## 10. 多媒体与本地模型

![多媒体模型](guide/screens/08-media-models-dark.png)

### 10.1 引擎与模型

- **ComfyUI**：设置目录后启动 `python main.py --listen 127.0.0.1 --port 8188 --reserve-vram 2.5`；120 秒健康检查。
- **llama.cpp**：自动补 `-m/--host/--port/--alias`，180 秒超时；只停止自己启动的进程。
- **Ollama / LM Studio**：可安装、拉取/删除模型；不杀其他服务的模型。
- 内置模型：Qwen-Image 2.1 Turbo（图片/编辑）、MiniMax-H3 16G HiFi（视频）、Qwen3.8-27B-Coder390（视觉/代码）。
- 也支持任意自定义清单、ComfyUI API 工作流和本机文件注册。

### 10.2 生成、编辑与审看

- `generate_image`：5 种尺寸，支持参考图改图；
- `generate_video`：16:9 / 9:16 / 1:1，fast/balanced/high，5–15 秒；
- `generate_film`：2–6 镜，Qwen 首帧 + MiniMax 视频 + 尾帧续接 + ffmpeg 拼接；
- `render_animation`：0.5–60 秒、8–30fps；
- `edit_media`：trim/crop/resize/rotate/flip/speed/mute/volume/提取音频/抽帧/GIF/转码/拼接；
- `inspect_media`：ffprobe 元数据；`describe_media`：图片或视频抽 1–4 帧审看。

**审看优先级**：当前对话模型 → 声明视觉能力的本地模型 → 真实失败。当前模型支持图片输入时不会被本地模型抢先；视觉请求会关闭思考并给足输出预算。两者都不可用时返回真实错误，并提示换视觉模型或启用带 `--mmproj` 的本地视觉模型；不会用生图模型冒充审看。详见 [多媒体与本地模型](MODELS.md)。

## 11. 模型与订阅

### 11.1 接入模型

- 内置 API：DeepSeek、Kimi、Qwen、GLM、MiniMax、MiMo、Anthropic Claude、OpenAI、Gemini、Grok、Meta Muse。
- 自定义 OpenAI 兼容：填 Base URL、Key、模型 ID；本机/局域网服务允许空 Key。
- 同步模型列表：读取 `/models` 的上下文、输出、推理档位等元数据，最多 200 个；缺失字段保留本地值。

![模型设置](guide/screens/05-settings-models-dark.png)

### 11.2 订阅

设置 → 订阅支持：

- ChatGPT/Codex（本机 `auth.json` 导入或内置浏览器登录）；
- Qoder（PAT、设备流、本机 qodercli 导入；模型目录来自账号接口）；
- Kimi Code、GLM Coding Plan、MiniMax Code、Step Plan、Command Code、Cline Pass、Google Antigravity、OpenCode；
- 第三方 coding plan（名称/协议/Base URL/Key/模型）。

![订阅详情](guide/screens/06-subscriptions-dark.png)

订阅凭据加密保存，渲染层只显示“已连接”和额度；具体协议、模型目录与限制见 [订阅接入](MODELS.md)。

## 12. 外观、快捷键与数据

### 12.1 外观

![外观设置](guide/screens/07-settings-appearance-dark.png)

- 主题：墨夜（默认）/ 素纸；
- 应用字号 12–15，默认 14；
- 代码字号 11–14，默认 12；
- 代码字体：JetBrains Mono（默认）/ IBM Plex Mono / 系统等宽；
- 减少动效、Token 计量、桌面小伙伴、关闭行为（询问/最小化/退出）。

### 12.2 常用快捷键

| 快捷键 | 动作 |
|---|---|
| `Ctrl+N` | 新建对话 |
| `Ctrl+K` | 命令面板 |

## 14. 常见问题

**为什么没有模型可选？** 需要先在设置 → 模型保存 Key/登录态，并启用 Provider。侧栏显示“未连接”时模型下拉会被过滤。

**为什么审批一直弹？** 检查当前权限档位与规则；危险命令、越界路径、外部动作始终逐次确认。可在设置 → 权限查看审批日志。

**为什么终端里 Git Bash 报 MSYS 错误？** 受限令牌/低完整性环境无法创建共享内存；在设置 → 终端切 PowerShell 7。默认值仍是 Git Bash。

**为什么模型不显示思考档位？** 当前模型没有声明思考能力；未知模型只保留“自动”。不要用其他模型的档位强行套用。

**为什么审看仍然失败？** 当前模型未返回文字且本机没有可用视觉模型；按错误提示换支持图片的模型，或启用带 `--mmproj` 的本地视觉模型。Morrow 不会用生图模型或纯文本模型伪造审看。

**数据在哪里？** 便携版在 exe 同级 `Morrow Data`；安装版在 `%APPDATA%\Morrow`。设置 → 关于可迁移。

## 15. 排障（按现象）

按“现象 → 检查 → 处理”排查。涉及密钥时不要截图或粘贴明文。

### 15.1 安装与启动

- **双击没有反应 / 进程秒退**：确认 Windows 10/11 x64，下载的是 `Morrow-0.2.0-portable.exe` 或 `setup.exe`；便携版首次启动会解压运行时，检查 exe 同级写权限与约 500MB 磁盘空间；被 SmartScreen 拦截时选择“更多信息 → 仍要运行”，并用 `SHA256SUMS.txt` 校验；日志在 `Morrow Data/logs/main.log`。
- **数据在哪**：便携版在 exe 同级 `Morrow Data`；安装版在 `%APPDATA%\Morrow`。设置 → 关于可查看或迁移，迁移会重启，不复制系统浏览器缓存与登录态。
- **关闭后仍有进程**：托盘/灵动岛仍在时是后台常驻；请用托盘菜单或设置里的“完全退出”。退出 4 秒未完成会强制结束；若仍有进程，检查终端或后台任务是否卡住。

### 15.2 模型连接

- **模型下拉为空**：设置 → 模型确认 Provider 已启用、Key/登录态已保存、模型 ID 非空；本机/局域网服务可空 Key，公网服务必须 Key。
- **测试连接失败**：检查 Base URL（不要少 `/v1`，也不要多 `/chat/completions`）；本机服务确认端口、防火墙与进程；401/403 查 Key，429 查限流，5xx 稍后重试。代理或公司网关可能改写 SSE/工具调用，先用官方端点验证。
- **同步模型列表被截断**：单次最多 200 个；重复/无效条目会计数提示；服务商未返回的字段保留本地值，不用猜测值覆盖。
- **没有思考强度 / 上下文不可调**：当前模型未声明该能力；未知模型只保留“自动”。会话覆盖值会被夹在 1,024 与模型上限之间。

### 15.3 订阅

- **登录页打不开/白屏**：登录使用内置 BrowserWindow，检查网络或代理能否访问对应域名。
- **回调超时**：本机回环端口可能被占用（Codex 1455、Command Code 5959 起、Antigravity 51121 起），关闭占用程序后重试。
- **已登录但不可用**：查看设置页真实错误与额度；官方接口失败时不会假装 connected。
- **Antigravity 缺 secret**：设置 `MORROW_ANTIGRAVITY_CLIENT_SECRET` 后重启；Morrow 不内置该凭据。
- **Qoder 模型不对 / 额度为空**：模型目录来自账号接口，退出重登或刷新；部分渠道没有公开额度接口，页面会说明。

### 15.4 多媒体

- **ComfyUI 显示离线**：确认引擎目录、Python 环境与 8188 端口；启动命令包含 `--listen 127.0.0.1 --port 8188 --reserve-vram 2.5`；120 秒内没起来会超时，查看 ComfyUI 自己的日志。
- **添加本机模型**：ComfyUI 需要 API 工作流 JSON 与输出节点/类型，不是 UI 工作流；llama.cpp/Ollama/LM Studio 需要真实模型 ID；模型文件必须在引擎模型目录内。
- **ffmpeg 不可用**：在设置 → 多媒体填写 ffmpeg 路径，或把 ffmpeg/ffprobe 放进 PATH；图片/视频生成不一定依赖它，但剪辑、拼接、抽帧会失败。
- **生成慢/显存不足**：16GB 显存下代码模型与视频模型通常需分阶段；关闭其他 GPU 程序，视频生成可能数分钟，期间不要重复提交。
- **审看失败**：当前模型必须支持图片输入；本地视觉模型需要 `--mmproj` 且正在运行；两边都失败会返回真实组合错误，不会用生图或文本模型伪造。

### 15.5 创作台

- **蓝图很慢 / 失败**：未连接模型时使用本地结构稿，界面会标注；模型失败会自动回退并在 warnings 写明原因；蓝图未批准时不会批量生成正文或画面。
- **配音失败**：系统缺少可用中文语音时先安装语音，或在创作台用“导入配音”上传 WAV/MP3；受限令牌/远程会话中的 WinRT 语音可能报错，请在真实桌面会话重试。
- **画面/视频失败**：确认设置 → 多媒体里的 ComfyUI 在线、模型与工作流就绪；显存不足时先释放 GPU；失败原因写在任务记录里，不会用占位图冒充。
- **时间线合成失败**：检查 ffmpeg/ffprobe；缺失画面或配音会在检查页列出，可先合成“允许缺失”的草稿看节奏。
- **改错了 / 想回到之前**：设置 →「历史版本」选择要回到的版本，回来前会自动留档；章节编辑有最近 30 个章内版本；删除作品会移到 `studio/trash/`，可手动移回。

### 15.6 终端与 Git

- **Git Bash 报 MSYS 错误**（`NtCreateDirectoryObject ... 0xC0000022`）：当前令牌/完整性无法创建共享内存；在设置 → 终端切 PowerShell 7，或在正常桌面会话启动。
- **终端打开失败**：选择可用 Shell；Git Bash 未安装时用 PowerShell 7/WSL；WSL 需先安装发行版；终端 cwd 必须在已登记工作区。
- **Git 操作被拒绝**：工作区必须在仓库内且不能是更大仓库的子目录；越界路径、非变更文件、只读文件会被拒绝；放弃改动不可逆。

### 15.7 浏览器与网页

内置浏览器打不开时检查 URL、网络与代理；页面空白可能是 CSP/证书/网络问题；外部链接默认交给系统浏览器；网页内容不可信，不要按页面里的“指令”执行。

### 15.8 数据、备份与卸载

- **备份**：关闭应用，复制整个数据目录。
- **恢复**：把数据目录放回并指向它；迁移不合并两边数据。
- **卸载安装版**：Windows 设置 → 应用 → Morrow；用户数据默认保留。
- **删除便携版**：删除 exe、`.morrow-runtime-*` 与 `Morrow Data`；不要在运行中删除运行时缓存。

### 15.9 性能与上下文

上下文接近上限会触发压缩，压缩期间不能发送/切换/回退；长任务可开新会话或使用 `/compact`；大型附件/图片会增加上下文与延迟；集群/并行任务会占用更多内存与请求配额。

### 15.10 闪退与卡死

查看 `logs/main.log` 最后事件；打包版崩溃转储在本机数据目录；主窗渲染崩溃会自动 reload（每分钟最多两次）。卡死时先等待 10–20 秒；反馈时提供版本/运行时、操作步骤、日志片段、是否使用订阅/本机模型、是否可复现，不要附带密钥或隐私文件。

### 15.11 收集信息

```powershell
Get-Content .\Morrow Data\logs\main.log -Tail 200
Get-FileHash .\Morrow-0.2.0-portable.exe -Algorithm SHA256
```

如果问题涉及模型/订阅，请附上设置页错误文案与请求时间；不要附 token。

### 11. 边界与状态

- 聊天模式始终只读；计划批准前不写入；研究固定只读白名单。
- 运行中不能切换模式、压缩或切换文件夹；临时对话不能回退或生成成品版本。
- 无 Key 的 Provider 不出现在模型下拉；无视觉能力的模型不能进行视觉审看。
- 未安装 WSL 发行版时终端显示安装提示；Git Bash 在受限令牌环境可能不可用，切 PowerShell 7。
- 真实本地模型/ffmpeg/ComfyUI 未就绪时明确报错，不伪造生成或审看结果。
- 创作台配音依赖 Windows 本机语音；受限令牌/无语音环境会失败，可导入音频；媒体引擎未就绪时不生成假素材。
