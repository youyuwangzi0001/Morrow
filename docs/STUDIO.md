# Morrow 创作台

创作台是 Morrow 里从一句话走到可交付作品的全屏工作区。蓝图、大纲、分镜与正文只由真实文本模型生成；画面/视频走本机 ComfyUI，配乐走本机 ACE-Step，配音走 Windows 声线或云端 TTS。三份内置样例是随包冻结的完整作品，不依赖本地生成引擎，打开后可继续手改、导出或用模型续写。中短篇、长篇与漫剧共用同一个作品底座：同一份作品文件保存蓝图、章节、分镜、素材、剪辑表、任务和交付物，随时可以退出再继续。

## 1. 入口与界面约定

- **标题栏**右侧的「创作台」按钮，或命令面板的“打开创作台”都能进入；Agent 首页不再放重复的创作台入口卡片。
- 创作台内**没有产品标题**；品牌羽毛图标只出现在协作者头部与头像、空态和首次指引，使用深/浅两套 1024 原图与 256/96/48/32 切片（统一放在 `build/` 根目录）并随主题切换，不再使用代码画的 Lucide 羽毛。首页顶栏只保留作品库、设置、主题、窗口控制与「回到 Agent」；打开作品后才显示新建作品、当前作品、画布/改编与预算。
- 品牌图标不进入**顶栏、关于页、Agent 首页或命令面板**；只在协作者、空态和首次指引中使用。
- 「回到 Agent」回到进入前的对话、滚动位置和草稿。作品仍在后台保存在本机。
- 写作与时间线采用**上下文面板**，不把四栏同时铺开：写作时收起全局阶段栏；时间线片段详情默认收起，需要时点「片段」打开；分镜/时间线的详情打开时自动收起协作助手，把宽度让给主画面。

## 2. 首次进入与随时演示

- 第一次切换到创作台会打开三页使用指引，完全对齐应用首次启动的沉浸式规格：左侧菱形步骤轨、右侧无外框正文、金色主按钮与底部小字；不再使用宽面板或选项卡片。
- 指引只在第一次自动出现；之后可从作品库右上角「使用指引」再次打开。
- 「看演示」是一段 40 秒线性制作影片：一句话 → 蓝图 → 分镜 → 声音 → 剪辑 → 交付。用随包样例的真实 12 镜、角色参考、时间线与交付文件连续演绎，可暂停/继续、重播或关闭；不提供任意跳步，结尾可直接在创作台打开样例。
- 关于页只保留 Morrow 主应用信息。

## 2.1 内部创作提示词库

创作台内置一套**不暴露在 UI、也不注册为 Morrow skill** 的创作手法库，参考 Agent 阵法与超无穹创作资料中的结构、人物、对白/潜台词、节奏、分镜、画面提示词工程与小说润色规则重新编写，当前包含 29 组手法模块，覆盖故事核、一句话许愿六要素、人物弧光、世界规则、章节情绪曲线、开头钩子、场景发动机、章末钩子、信息滴漏、去 AI 腔、对白潜台词、台词经济、情绪链、公平反转、剧本格式、转场、电影分镜、漫剧节奏、画面提示词、连续镜头、配音意图、声音让位、连续性检查、长篇连续性账本、小说改编、漫画分格与受众承诺。

创作层与质检层已在 `prompt-library.ts` 融合：每次生成会同时带上任务基础提示、按意图调取的手法模块与 `quality.ts` 的七维门禁。完整框架、参考来源与阈值见 [QUALITY-FRAMEWORK.md](./QUALITY-FRAMEWORK.md)。

调取不是随机拼接：`selectCreativePrompts` 按作品形态、当前任务、阶段和用户原话中的关键词/触发词打分，取最相关的 1–6 组；蓝图、大纲、正文、助手回答、章节配图、分镜画面与图生视频提示词都走同一套调取。提示词只作为系统指令的增量，不改变 JSON 输出契约、人物事实与手改优先规则。

## 2.2 设置、面板、层级与紧凑布局

- 顶栏「设置」整合为五个子页：模型与预算、配音与引擎、历史版本、回收站、数据与安全；「作品库」与「新建作品」是独立按钮，不再混在作品下拉菜单里。原先内容过少的“预算”“配音”“引擎”入口按使用场景合并，顶栏预算按钮直达「模型与预算」的预算区。
- 「回收站」列出删除的作品，可恢复到作品库或彻底删除；删除后不再需要手工进数据目录。
- 「数据与安全 → 创作台数据」显示当前目录与来源（默认 / 自定义）；更换目录会迁移创作台作品、素材、历史版本与任务记录并重启应用，Agent 对话与设置不移动；恢复默认会把数据复制回默认目录，原自定义目录保留。
- 创作台设置与 Agent 设置共用同一套导航、页头与内边距令牌：148px 导航、34px 行高、`--text-page-title-*` / `--text-section-*` / `--text-hint-*` 语义字号；五个子页都有独立标题与说明，密钥仍由 Agent 设置保管。
- 作品下拉菜单只保留最近作品列表，字号与层级统一。

- 指引页只展示一枚创作台品牌图标（32px 显示、调用 96px 切片）；同一套深浅切片也用于协作者头部/头像与首页空态，避免小图标加载 1024 原图。
- 协作侧栏与左侧阶段栏都可拖动调宽：默认 240 / 420px，悬浮/拖动时只高亮面板自身的 1px 香槟金边框并显示像素读数；拖动时手柄在边界补一条同位置的金线，避免右侧重排时被相邻滚动条盖住；双击恢复默认，宽度按本机记忆；页面次级动作收为带 `title`/`aria-label` 的图标按钮；镜头详情与人物/事实抽屉会为正文预留空间，不再遮住纸页。
- 时间线监视器按视口取 `clamp(216px, min(42vh, 30vw), 860px)`：小屏收紧、中屏保持可读、4K/超宽屏放大到 860px；画面两侧用当前素材的模糊环境底填满，不再留下大片黑边。高度 ≤900px 时自动收紧页头与监视器，六条轨道（含字幕轨）仍完整可见。
- 字幕轨高度 48px，标签与正文分层显示：正文使用 11.5px 字号、底部留 4px，二者间距 ≥3px，不再贴边或重叠。
- 顶栏菜单抬到时间线之上；演示控制条改为按列对齐的网格；字幕标签只显示镜号，正文只在字幕层出现，逐句字幕时长按可用时长归一化，避免字幕重叠。
- 首页：去掉重复的左侧作品筛选与“刷新”按钮；顶栏在首页不再残留上一个作品的新建/画布/预算；作品切换、模板、搜索和“看演示/使用指引”保持原位。
- 画布右下角缩放/适应按钮独立于画布指针事件，按钮扩大到 28×26 并在 20/21 E2E 中用真实指针命中与点击验证。
- 灵动岛在创作台模式下的主按钮统一为实心微圆角矩形；「回到 Agent」会真正退出创作台并返回 Agent，主窗口不可用时在岛内显示错误而不是静默收起。
- 1280 宽度仍停靠侧栏，1120 以下才切成浮层抽屉；1280 / 2100 / 3840 三档在时间线、分镜、写作、交付、首页与设置页都有横向溢出与监视器占比断言。
- 协作者头部与上下文条显示当前模型的上下文窗口、看图/工具能力与本机或云端；每条回答记录本轮实际来源，可点击跳回章节、镜头或片段，来源失效会进入检查项。
- 交付页保留「合成」与常用格式：质量（草稿 / 成片）、画面比例、字幕（画面内字幕 / 单独字幕）、格式（MP4 / MOV / MKV / WebM）与清晰度（1080p / 4K），下方附格式用途说明和「推荐设置」。「导出预检」列出中文字体、FFmpeg 与 PDF/DOCX/EPUB 的实际可用状态；PDF 使用 Chromium Type3 字形嵌入，DOCX/EPUB 使用字体回退栈。
- 检查页「自动补齐并合成草稿」先展示步骤与预算，再按任务队列补齐缺失素材、自动装配时间线并合成草稿；最终成片导出仍保留人工确认。

## 3. 本轮新增的真实能力

- **连续写作**：只推进还没有正文的章节，可一次排队写 3 章；已有正文不会被覆盖。
- **章节配图**：为章节生成候选配图，采用时记录插入段落与来源；写作页直接显示；候选不覆盖正文；EPUB/DOCX/PDF 按段落位置嵌入配图。
- **真实视觉检查**：用视觉模型逐镜检查手、脸、动作方向、道具与连续性；没有视觉模型时记录“未检查”，不伪造结论。
- **一键补齐**：只补缺失的画面、配音、配乐或空章，所有花费仍逐任务经过预算闸门。
- **交付扩展**：成片可选 1080p/4K、MP4/MOV/MKV/WebM；可编辑工程可重新导入为作品。交付页还提供发布文件包、封面、字幕、四格漫画与单独音轨，每一项都写清了用途。
- **任务与状态**：正文/镜头/设定/时间线改动会标记下游过期；任务按输入哈希去重；助手回复与计划受预算限制。
- **灵动岛**：显示当前作品、任务进度和完成状态，可直接打开创作台或回到 Agent。
- **全应用禁用斜体**：`em/i/cite` 等一律使用正常字形，层级只靠字重、字号与颜色。
- **画布工作流**：Shift/框选多选、六向对齐、编组/解组、拖动组整体移动；镜头节点内直接生成画面/视频/配音并显示任务进度；PNG 快照进入交付记录。
- **任务消息流**：排队、执行、进度、完成/失败逐条持久化；检查页任务账本可展开消息、输出与外部任务号，并可按外部任务号取回 ComfyUI 结果。
- **长篇性能**：单章超过 1.8 万字自动分片落盘，读取时还原；候选对照超过 2 万字自动退到段落级，避免逐字 diff 卡住界面。
- **人物语气审稿**：从正文和分镜台词提取有明确说话人的句子，统计句长、问句/感叹比例、高频用语与称谓，提示“语气趋同”与主角缺席。
- **声音与预览**：FFmpeg 解码真实音频峰值；视频按需生成 540p 低清代理；内置原创配乐/音效素材库并标注授权；支持兼容 OpenAI 的云端 TTS。
- **模型路由**：local-first / cloud-first / local-only / cloud-only 会实际参与文本模型选择，设置页展示可用路由、本地/云端与参考单价；预算估算与生成使用同一条路由。
- **FFmpeg 工具包**：检测本机编码器并标识默认/增强包；Morrow 不内置 FFmpeg 二进制，许可见 [第三方许可](THIRD-PARTY-LICENSES.md)。

## 4. 三种形态

| 形态 | 默认规模 | 阶段 |
|---|---|---|
| 中短篇 | 3–8 万字 | 蓝图 → 大纲 → 写作 → 检查 → 交付 |
| 长篇 | 20–100 万字，可分卷 | 蓝图 → 大纲 → 写作 → 画面（封面/插图） → 检查 → 交付 |
| 漫剧 | 30–180 秒 | 蓝图 → 大纲 → 分镜 → 画面 → 配音 → 音乐 → 时间线 → 检查 → 交付 |

阶段栏可以随时回到任意阶段；离开时只隐藏与当前任务无关的面板，不丢数据。

## 5. 从一句话开始

1. 在作品库选择「中短篇 / 长篇 / 漫剧」，写一句话，选制作精细度、画面比例和补充要求。
2. 点「生成故事蓝图」。蓝图包含故事主线、情绪基调、给谁看、看点、结构、风格、人物、地点、章节/镜头安排与时间/费用区间。
3. **先看一遍再开始**：蓝图未确认时不会批量生成正文或画面。可以改人物、删章节/镜头、换节奏，再确认。
4. 确认后按阶段推进。蓝图、大纲、分镜、正文与小说改编都只调用真实文本模型；长篇的大纲按每批 12 章分批细化，避免一次输出过长被截断。未连接或调用失败时任务会明确停下并提示处理，不回退本地模板。
5. 所有生成动作进入任务队列；进度、失败原因和费用写在任务记录里，可取消或按输入快照重试；应用后的修改计划在没有后续修改时可整体撤销。

## 6. 小说链路

- **大纲**：蓝图确认后先进入“大纲”阶段；写作页左栏目录顶部有「生成章纲 / 重新细化章纲」，由文本模型细化章名、梗概与 3–5 个节拍。长篇按每批 12 章分批调用模型，任何一批失败都会明确报错；已有正文不会被改写。卷、章、节拍、目标字数与情绪曲线；长篇章目多时左栏单独滚动，正文纸页占主宽度。
- **写作**：纸页编辑、自动保存、章节切换、章内版本、候选稿与连续性提醒。
- **文档工具条**：撤销/重做、查找替换（Ctrl+F，上一个/下一个/单条替换/全部替换）、排版（字号/行距/页宽，只改视图不改正文）、字数统计（字数/字符/段落/阅读时间/目标进度）与「导出 Word」。按 Word/WPS 的文档操作习惯组织，但保留创作台的纸页与候选稿流程。
- **候选终不会覆盖你写的正文**：任何一章只要手动改过，后续模型候选只作为待选项，不会自动写回正文；用哪一版由你决定。对照弹窗可切换全部候选，支持逐字与段落两种对照。
- **分卷与拖拽**：新建/编辑/删除/排序分卷，章节可拖到别的卷或卷内某章之前；删除分卷时章节保留在“未分卷”。
- **世界与关系**：人物关系可编辑；势力、规则、关键道具在写作台「世界」面板 CRUD；真实关系图可点击人物继续编辑。
- **设定与连续性**：人物、地点、规则、道具与设定表可手动维护；检查页会指出前后冲突和缺失。
- **历史版本**：每章保留最近 30 个版本；整部作品的版本记录原因、版号和时间，恢复前会自动保存当前状态。

## 7. 漫剧链路

- **分镜**：由文本模型按已确认蓝图重新拆分场景与镜头，写入场次、镜头号、动作、景别、运镜、台词、说话人、时长、画面提示词、不要出现的东西和前后衔接；已有画面/配音时只改无素材镜头，不会打乱素材。分镜页的“按蓝图同步”只做本地字段同步，不计入模型分镜完成。
- **参考固定**：人物/地点/道具参考图可以固定，生成时优先保证同一张脸、同一件道具。
- **画面**：逐镜或批量生成分镜图；在分镜图上点“视频”可升级为动态镜头。支持导入本机素材替换旧画面。
- **配音**：为角色选择 Windows 本机语音，或切换兼容 `/audio/speech` 的云端配音；逐句生成并回填时间码；系统没有可用语音时，可直接导入已经录好的配音文件。
- **音乐与音效**：配乐由本机 ComfyUI 的 ACE-Step 1.5 按故事情绪生成纯器乐；雨声、伞、心跳等音效为 Morrow 原创合成。时间线显示真实峰值波形；也可导入外部音频，并在音频库中查看来源和授权。ACE-Step 未安装时会明确提示，不用程序化草稿冒充正式配乐；本地草稿会标“草稿”，不计入配乐阶段完成。
- **时间线**：画面、对白、音乐、音效、字幕五条轨道；拖中间改位置、拖两端改长短，可调速度、音量与转场/淡入淡出；字幕可改位置/字号/颜色/底板，音频可循环铺满。监视器播放当前时间线并可切换 540p 低清预览；片段详情默认收起，支持片段级独立撤销。
- **检查与交付**：检查前后衔接、缺失画面/配音、字幕与响度；长文会体检重复片段、超长段落与对白密度。通过后合成草稿或成片；可提取 WAV/MP3/AAC/FLAC 音轨，或把前四镜排成 2×2 四格漫画。

### 7.1 漫剧画布

画布是时间线之外的另一种组织方式，不替代时间线。镜头节点、画面、视频、音频与文本节点可以自由排布，右侧拉线记录“参考 → 生成 → 配音 → 合成”的关系。

- 空白处拖动框选，Shift/Ctrl 点选追加；选中多个节点可对齐、复制、编组。
- 编组后拖动组标题整体移动，按 G 解组；组名可直接改。
- 镜头节点详情里可直接生成画面、视频或配音，节点上显示任务进度。
- 「快照」把当前画布（含分组、连线、真实音频波形与图片）导出为 PNG，写入交付记录。
- 画布自动保存，支持撤销/重做（60 步）、缩放、平移与适应全部节点。

## 8. 协作助手与大白话修改

- 助手知道当前作品、阶段、选中对象和预算；回答与动作都以作品文件为准。
- 用自然语言提出修改，例如“镜 01 慢 20%，雨声压低一点，不要改脸”。助手先生成**修改计划卡**，列出影响范围、费用和预计耗时；点“应用”后才改时间线。
- 台词、剪辑与音量类动作应用到时间线快照；章节重写只生成候选，不直接覆盖正文。
- 无法理解或超出预算时明确提示，不执行猜测性修改。

## 9. 引擎与费用

- **文本**沿用 Morrow 当前模型；未连接模型时，蓝图、大纲与写作入口会提示先连接。
- **图片**默认走本机 ComfyUI 的 Qwen-Image 2.1 Turbo；**视频**可走本机 MiniMax H3 图生视频。
- **合成**使用 ffmpeg：草稿 16:9 为 960×540，成片 1920×1080；竖屏与方形按比例对应。输出 H.264/AAC，字幕可软挂或烧录。
- **配音**使用 Windows 本机语音（WinRT 优先，SAPI 回退）。受限环境或系统未装语音时会给出可读错误，并提供“导入配音”。
- **费用**：能可靠计价时显示人民币区间与已花费；无法可靠计价时显示“未知”，不编造数字。预算上限触发后会停下来再次确认。
- 作品工程包和交付物**不包含** API Key、账号信息或订阅凭据。

## 10. Agent 协作

创作台向 Agent 注册 11 个工具：`studio_project`、`studio_create`、`studio_blueprint`、`studio_write`、`studio_storyboard`、`studio_media`、`studio_timeline`、`studio_edit`、`studio_review`、`studio_render`、`studio_export`。

- 读操作（作品列表/摘要、检查结果）可直接执行；写操作仍经过原有权限与审批。
- 工具只调用主进程作品服务，不直接改文件；因此 Agent 与界面看到的是同一份作品状态。
- 集群成员可以使用创作工具处理互不重叠的子任务；同一作品同一时间仍只允许一个写入者。

## 11. 数据与恢复

```text
<数据目录>/studio/
  studio-index.json                 最近作品索引
  projects/<projectId>/
    project.json                    作品唯一事实源（原子写入）
    assets/                         按 SHA-256 指纹去重的素材
    versions/                       作品快照与 index.jsonl
    exports/                        成片、成书、封面、工程包
    tmp/                            渲染中间文件
  trash/                            删除的作品目录（可手动撤回）
```

- 作品文件损坏时先尝试恢复最近备份；失败时保留原文件并给出可读错误，不静默重建。
- 删除作品不执行 `rm -rf`：项目目录会移到 `studio/trash/<id>-<时间戳>`，需要时可由用户手动找回。
- 导出目录与数据目录都在本机；不上传到 Morrow 服务器。

## 13. 设计与验收

- 创作台与 Agent 共用 `src/renderer/styles.css` 的顶层令牌：布局、纸张、文档预览、字号、行高、字距与语义色都在这里维护。
- 深色主题的纸页、文档页与 PDF 预览使用深色底和暖色文字；浅色主题使用米白纸与深墨文字。两套主题都通过同一组语义令牌切换。
- `npm run audit:ui` 扫描所有 CSS/TSX 的裸排版值；文档预览 iframe 仅保留白名单。
- 主要证据：`tests/e2e/studio.spec.ts` 覆盖入口、作品库、时间线、分镜、交付、写作、候选、助手修改与撤销、首次指引、40 秒演示、灵动岛与回收站；`tests/unit/studio-runtime.test.ts` 与 `studio-store.test.ts` 等覆盖作品仓库、时间线、修改计划与工具注册。
- 截图见 `docs/guide/screens/13-studio-home-dark.png` 至 `28-studio-settings-dark.png`（深/浅主题，最新打包版真实窗口）。26 张指南图已压到最长边 1600px、PNG-8 256 色，约 4.7MB。

## 14. 已知边界

- Windows 10/11 x64 是唯一正式交付平台；本机语音与媒体引擎依赖系统能力。
- 视频生成依赖本机 GPU、ComfyUI 与模型是否就绪；未就绪时明确失败，不伪造生成结果。
- E2E 在受限令牌环境中无法调用系统语音；最终打包机需在真实桌面复核语音。配音可改用导入音频。
- 当前未内置第三方素材市场；所有素材来自本机生成、导入或样例。

## 快捷键与手势

适用于 Morrow 0.2.0。macOS 使用 `⌘` 代替 `Ctrl`。

### 全局

| 操作 | 快捷键 / 手势 |
|---|---|
| 关闭当前弹窗、取消选择或退出专注模式 | `Esc` |
| 在首页继续创作 | `Ctrl` + `Enter` |
| 返回 Agent | 顶栏「回到 Agent」 |

### 写作

| 操作 | 快捷键 |
|---|---|
| 立即保存当前章节 | `Ctrl` + `S` |
| 切换专注模式 | 写作页「专注」按钮 |

### 分镜与画布

| 操作 | 快捷键 / 手势 |
|---|---|
| 多选节点 | `Shift` / `Ctrl` + 点击，或在空白处拖出选框 |
| 全选节点 | `Ctrl` + `A` |
| 编组所选节点 | `G` |
| 解组 | 选中分组后按 `G` |
| 复制所选节点 | `Ctrl` + `D` |
| 撤销 / 重做 | `Ctrl` + `Z` / `Ctrl` + `Y` |
| 删除所选节点或连线 | `Delete` / `Backspace` |
| 平移画布 | 按住 `Space` 拖动，或按住 `Alt` / 鼠标中键拖动 |
| 缩放画布 | 鼠标滚轮，或右下角 `-` / `+` |
| 适应全部节点 | 工具栏「适应」 |

### 时间线

| 操作 | 快捷键 / 手势 |
|---|---|
| 播放 / 暂停 | `Space` |
| 倒放 / 暂停 / 快进档位 | `J` / `K` / `L` |
| 逐帧后退 / 前进 | `←` / `→` |
| 在播放头分割片段 | `S` |
| 删除所选片段 | `Delete` / `Backspace` |
| 撤销 / 重做 | `Ctrl` + `Z` / `Ctrl` + `Y` |
| 保存时间线 | `Ctrl` + `S` |
| 缩放时间线 | `Ctrl` + 滚轮，或工具栏 `-` / `+` |

### 指引与演示

| 操作 | 快捷键 |
|---|---|
| 上一步 / 下一步 | `←` / `→` |
| 关闭指引或演示 | `Esc` |

### 边界

- 快捷键在输入框、文本域与代码编辑器中不抢占文字输入。
- 片段级撤销在片段详情里独立保留最近 30 次修改，不影响其他片段。
- 画布撤销保留最近 60 个画布快照。
