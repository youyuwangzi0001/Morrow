# Morrow 设计系统

Morrow 的界面是“安静的桌面工作台”：信息密度高，但不靠装饰制造存在感。金色只用于关键动作/选中/焦点；分隔线是 1px；全应用禁用斜体；正文和按钮不小于 12px。

## 1. 审美判断

- **克制**：能用一个层级说清，不加第二个卡片/标题/说明。
- **具体**：按钮写“合成草稿”，不写“执行”；设置写“先用哪个模型”，不写“路由优先级”。
- **对齐**：同一行的控件基线对齐；页头、工具条、列表用统一的间距 token。
- **可读**：深色主题不用整页白底；浅色主题不用纯黑字压白；纸张/文档预览跟随主题。
- **一次确认**：能用计划卡一次确认的，不再叠第二层弹窗/提示。

## 2. 色彩 Token

### 2.1 墨夜（默认）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b0d10` | 页面底色 |
| `--surface` | `#141922` | 主面板 |
| `--surface-2` | 略亮 | 卡片/悬停 |
| `--text` | `#ede7da` | 主文字 |
| `--muted` | 降透明度 | 说明/元信息 |
| `--gold` | `#c8ae7d` | 关键动作/选中 |
| `--line` | `rgba(237,231,218,.075)` | 1px 分隔线 |

### 2.2 素纸（light）

| Token | 值 |
|---|---|
| `--bg` | `#f1ede4` |
| `--text` | `#1b1a17` |
| `--gold` | `#8a6a3c` |

### 2.3 状态色

成功/提醒/错误用低饱和语义色；不要用金色表示错误。状态 chip 只做小面积标记，不做整行底色。

### 2.4 纸张与文档预览

创作台纸页、DOCX/EPUB/RTF 页面与 PDF 预览都跟随主题；深色主题用深色纸页，不出现整页白底。纸张宽度 `data-paper-*` 只改视图，不改正文。

## 3. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| UI | Manrope Variable | 界面、按钮、表单 |
| Display | Newsreader Variable | 标题/品牌/少量强调 |
| Code | JetBrains Mono | 代码、路径、时间码 |
| 正文 | Noto Serif SC Variable | 创作台纸页/导出预览 |

语义字号：

| 角色 | 字号 |
|---|---|
| 正文 | 14px |
| 控件 | 13px |
| 说明 | 12px |
| 元信息 | 11.5px |
| 代码语义 | 13.5px |
| 页面标题 | 20–24px |

全应用禁用斜体；正文/按钮/表单 ≥12px；不用 10px 以下“小字装饰”。

## 4. 间距、圆角与控件

- 间距：4/8/12/16/24/32；页面两侧用 `--app-page-gutter`（1280 档 24px，2100 档 32px，3840 档 48px）。
- 圆角：4/5/7/9/12；按钮/输入框 7–9px，卡片 12px；不做胶囊化页签/开关/chip。
- 控件高度：28/34/36/40；同一工具条只用一种高度。
- 图标：Lucide 线性图标；品牌徽记只在协作者头部/空态/首次指引出现。

## 5. 布局

### 5.1 主界面

```text
TitleBar
├─ Sidebar（可收起）
├─ Transcript / Workbench
├─ Right Canvas / Preview（可拖宽）
└─ Terminal（可收起）
```

### 5.2 创作台

```text
Topbar（作品名 / 阶段 / 回到 Agent）
├─ StageRail（阶段 + 目录）
├─ Center（当前工作区）
└─ Assistant（协作者，可收起）
```

协作者在镜头详情、片段详情、人物面板、专注模式打开时自动收起；首页和画布不显示。

### 5.3 三档窗口

| 档位 | 视口 | 页面留白 |
|---|---|---|
| 紧凑 | 1280×720 | 24px |
| 标准 | 2100×1200 | 32px |
| 宽屏 | 3840×2160 | 48px |

实际最小窗口 1200×760。窄宽度下页头纵向排列，交付/大纲/剧本不出现竖排单字按钮；容器查询负责局部响应，不靠全局缩放。

![紧凑窗口](guide/screens/37-studio-timeline-compact.png)

### 5.4 1px 分隔线

- `--divider-size: 1px`；idle 金色、active 亮金、idle opacity .45、glow `0 0 7px rgba(200,174,125,.55)`。
- 拖动分栏时只亮一条线；面板边框在高亮时透明；悬停亮、离开后保持、释放后关闭。
- 侧栏、协作者、画布、创作台共用同一套分隔线；终端顶部是香槟金基线，悬停/拖动变亮。

## 6. 组件

### 6.1 页签

`Tab` 只用文字 + 底部 2px 线；不要胶囊。激活色用金色/主文字，不用整块底色。

### 6.2 开关

`Switch` 36×20 左右；开=金色轨道，关=中性轨道；禁用降透明度；不做大圆角胶囊。

### 6.3 状态标签

`Chip` 小面积、低饱和；错误用语义红、提醒用琥珀、成功用绿；文字 11.5–12px。

### 6.4 按钮

- 主按钮：金色底/深色字，只用于当前页唯一主动作。
- 次按钮：透明底/1px 线。
- 危险按钮：红色文字/线，只在确认后执行。
- 按钮高度 28/34/36/40；图标按钮 28×26 或 30×30，微圆角方形。

### 6.5 Composer

- 输入框与 Agent 主聊天框共用流金边框：1px 边框、9px 圆角、聚焦时金线展开。
- 底部工具条放模型、思考、权限、附件、发送；不重复放顶栏已有入口。

### 6.6 消息与轨迹

- 用户消息靠右/低对比底色；助手消息靠左；工具轨迹折叠，标题写“执行工具 N 次”。
- 计划卡是独立卡片：标题、影响列表、费用/耗时、取消/确认；不要同时弹 toast。

![协作者与计划卡](guide/screens/18-studio-assistant-dark.png)

### 6.7 权限卡

- 标题一句话说清动作；正文列目标/参数/影响；按钮“允许一次 / 拒绝 / 始终允许（安全动作）”。
- 危险动作不提供“始终允许”。

### 6.8 画布

- 节点微圆角方形；选中用金色 1px 线；连线低对比；缩放/适应窗口 28×26；不遮挡节点。
- 画布底部提示只写当前操作，不写功能广告。

### 6.9 设置

- 左侧分组 + 右侧内容；页头一行标题 + 一行说明；不堆重复说明。
- 保存按钮只在有改动时出现；数据目录/回收站即时读取。

### 6.10 灵动岛

- 透明、置顶、可拖拽；idle/running/waiting/done 四态；展开 396×520，收起 356×84。
- 底部一个金色“打开创作台”；不再放第二个重复按钮。

### 6.11 创作台品牌

- 创作台顶栏不出现产品标题/图标；协作者头部/头像、空态、首次指引使用品牌徽记。
- 首次指引三页；演示用真实工作台，不做假动画。

## 7. 动效

- 面板开合 160–220ms；分隔线高亮 120ms；按钮悬停 120ms。
- 不用大幅位移/弹跳；不因动效改变布局。
- 尊重 `prefers-reduced-motion`；减少动效时只保留透明度变化。

## 8. 可访问性

- 键盘可达：Tab 顺序、Esc 关闭、Enter 发送、Shift+Enter 换行。
- 焦点可见：金色 1px 线或 2px ring；不依赖颜色 alone。
- 对比度：正文/按钮达到可读对比；金色文字只用于深色底上的关键动作。
- 图标按钮有 `aria-label`/`title`；表单有 label。

## 9. 实现约定

- 颜色/字号/间距/圆角/分隔线必须用 token；新增裸值先加 token。
- `npm run audit:ui` 检查裸排版值；0 裸值才算通过。
- 主题切换用 `data-theme`；不要在组件里写死深色/浅色。
- 不引入第二套图标/字体；不把品牌图当功能图标。
- 新组件先看现有组件能否复用；重复卡片/按钮/说明直接删。
