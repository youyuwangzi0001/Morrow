# Morrow 设计系统

Morrow 的视觉母题是“夜桌与地平线”：深墨色工作台、暖纸色文字、克制的一线香槟金。金色只用于“明天”的暗示、关键动作与选中态，不用于大面积装饰。

## 1. 审美判断

与常见 AI 界面区分：

- 不做满屏渐变、霓虹发光或玻璃卡片堆叠；
- 层级靠 1px 线、色差与留白，而不是阴影；
- 展示字体（Newsreader）承担标题与品牌，UI 字体（Manrope）承担操作，代码字体（JetBrains Mono）承担可验证内容；
- 动效短、只服务反馈；减少动效时全部退化为即时状态；
- 所有页签、开关、状态标签使用同一套微圆角语言，不用胶囊化表达；
- 全应用不使用斜体：`em/i/cite/dfn/var/address` 统一 `font-style: normal`，层级只靠字重、字号与颜色。

### 2.2 素纸（light）

浅色主题把背景换为暖纸色（`#f1ede4` 系），文字反转为深墨；金色仍用于关键动作，但提高对比度。所有语义 token 不变，页面只通过 `data-theme="light"` 切换。

### 2.3 状态色

- 成功/完成：patina；
- 进行中/注意：amber；
- 危险/拒绝：rust；
- 信息/辅助：mauve；
- 选中/关键：gold。

状态色不能单独承载含义；必须同时有文字/图标/形状。

### 2.4 纸张与文档预览

创作台和 Agent 的文档预览共用顶层语义令牌，不再由组件各自维护纸色：

| 用途 | 使用的顶层 Token |
|---|---|
| 纸页/简报纸背景 | `--bg-elev`、`--surface` |
| 纸页外沿/凹陷区 | `--bg`、`--surface-inset` |
| 纸页正文/次要文字 | `--text`、`--text-2`、`--text-3` |
| 纸页分隔线/描边 | `--line`、`--line-strong`、`--line-gold` |
| DOCX/EPUB/RTF 页面与预览外框 | `--bg-elev`、`--surface-inset` |

- 深色主题下纸张、DOCX/EPUB/RTF 页面与 PDF 画布都必须保持深色；禁止在深色主题里出现整页白底。
- PDF 画布用 `invert(.94) hue-rotate(180deg) brightness(1.1) contrast(1.08)` 把白底页面转成深色，同时保留图表与印章的可读对比。
- 文档 iframe 的颜色通过 `document-theme.ts` 读取顶层 token，再注入到预览 HTML；组件不维护第二套文档主题。
- 创作台演示的 `--sd-*` 只是 `.studio-demo` 内部的别名，逐一指向 `--bg` / `--surface` / `--text` / `--gold` / `--patina` / `--rust` 等顶层令牌，不再新增顶层颜色。

## 3. 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| UI | `Manrope Variable` + Noto Sans SC / 雅黑 | 按钮、正文、表单 |
| Display | `Newsreader Variable` + Noto Serif SC | 品牌、页面标题、订阅详情标题 |
| Code | `JetBrains Mono`（默认）/ IBM Plex Mono / 系统等宽 | 代码、终端、diff、数字、快捷键 |

字号阶梯（`styles.css`）：`34 / 26 / 22 / 24 / 20 / 17 / 16 / 15 / 14 / 13.5 / 13 / 12.5 / 12 / 11.5 / 11 / 10.5 / 10 / 9.5 / 9`。

规则：

- 正文/按钮/表单不得低于 12px；9–11px 只用于元信息、快捷键、热力图等非阅读主体。
- 代码字号默认 12px；行号、`+/-`、diff 统计与代码同字号、同字重（400）、0 字距。
- 标题字距 `-0.01em`；标签/大写字母可到 `0.06em–0.14em`；正文不用夸张字距。

### 3.1 语义排版角色

| Token | 用途 | 值 |
|---|---|---|
| `--text-page-title-*` | 设置/页面标题 | 20px / 500 / 1.2 |
| `--text-section-*` | 分区标题 | 13px / 600 |
| `--text-body-size` | 正文 | 14px |
| `--text-ui-size` | 控件文字 | 13px |
| `--text-hint-size` | 说明 | 12px |
| `--text-meta-size` | 元信息 | 11.5px |
| `--text-code-size` | 代码 | 13.5px |

设置类弹窗（Agent 设置与创作台设置）共用一组顶层布局令牌：`--settings-nav-width: 148px`、`--settings-nav-item-height: 34px`、`--settings-nav-font-size: var(--fs-base-plus)`、`--settings-nav-icon-size: 15px`、`--settings-pane-pad`、`--settings-page-head-gap: 14px` 与 `--settings-body-height: min(calc(84vh - 200px), 620px)`。两边不再各自维护导航宽度、行高或页头间距。

### 3.3 创作台排版

创作台与 Agent 共用同一套字号、行高、字距与字重令牌，没有 Studio 专用字号阶梯：

| 场景 | 使用的顶层 Token |
|---|---|
| 作品库/指引首屏标题 | `--fs-display`、`--lh-title`、`--ls-tight` |
| 纸页标题/章节标题 | `--fs-h1` / `--fs-title` / `--fs-h2`、`--lh-title` |
| 纸页正文与阅读主体 | `--fs-body` / `--fs-body-lg`、`--lh-readable` / `--lh-copy` |
| 主区元信息/微标签 | `--fs-2xs` / `--fs-3xs`、`--ls-caps` / `--ls-wide` |
| Agent 侧聊 / 创作台右栏 | `--fs-panel-title` / `--fs-panel-body` / `--fs-panel-meta` |
| 演示影片的微缩界面 | 同一字号阶梯（最低 `--fs-3xs`），行高 `--lh-tight`–`--lh-loose` |

创作台的大标题只用于作品库的内容标题，不再重复产品名。纸页正文与 Agent 正文都属于阅读主体，不得低于 13.5px。长文纸页行距使用顶层阅读令牌：`--lh-reading-tight 1.78` / `--lh-reading 2.02` / `--lh-reading-loose 2.2`，写作台与文档预览共用。所有字号、字重、行高与字距由 `npm run audit:ui` 扫描，禁止在组件内写死；演示影片也不设审计豁免。Agent 侧聊与创作台右栏由 E2E 断言实际计算值（15px / 13.5px / 11.5px）。

### 3.2 权限卡排版

权限卡使用独立角色 token：

- 标题 14px / 600 / 1.35；
- 说明 12.5px / 450 / 1.72；
- 摘要 12px / 450 / 1.65；
- 风险 10px / 500；
- 命令预览 11.5px / 450 / 1.45；
- 按钮 12.5px / 500 / 34px。

这些值不从组件内写死，全部来自 `--text-permission-*`。

## 4. 间距、圆角与控件

- 间距：`4 8 12 16 20 24 32 40 56 72`（`--sp-1..10`）。
- 圆角：`--r-xs 4px`、`--r-sm 5px`、`--r-md 7px`、`--r-lg 9px`、`--r-xl 12px`、`--r-full 999px`；按钮/输入用 `--r-control`，卡片用 `--r-card`，弹窗用 `--r-modal`。
- 控件：`--control-xs 22`、`--control-sm 28`、`--control-md 34`、`--control-field 36`、`--control-lg 40`；图标 10/12/14/16/20px。
- 密集工具条：`--bar-height 34px`、`--bar-pad-x clamp(12px, 1.1vw, 20px)`、`--bar-gap 6px`、`--bar-control-h 24px`。工具条内按钮一律不收缩、不换行；时间线中栏 `<760px` 时切换为图标模式（文字标签隐藏，`aria-label` 保留），`<620px` 时收起交付页入口，避免文字换行压到时间线标尺。
- 阴影只用于浮层：`0 24px 80px -24px rgba(0,0,0,.72), 0 2px 10px rgba(0,0,0,.38)`；普通卡片靠线 + 色差。

## 5. 布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ 44px titlebar：侧栏开关 · 文件夹 · 会话标题 · 浏览器/终端/画布/窗控 │
├──────────────┬─────────────────────────────────────────────────────┤
│ sidebar 240  │ transcript 滚动（max 720 居中）                      │
│ 可收 64      │ plan / sources / run center / queue / composer      │
│              ├─────────────────────────────────────────────────────┤
│              │ canvas 420（多标签编辑器/预览）                      │
├──────────────┴─────────────────────────────────────────────────────┤
│ terminal dock 190–72vh（可选）                                      │
└────────────────────────────────────────────────────────────────────┘
```

- 侧栏 200–400px，默认 240；画布 320–960px，默认 420；≤1200px 为窄屏。
- 对话列 `--content-max: clamp(800px, 40vw, 1100px)`、输入区 `--composer-max: clamp(920px, 46vw, 1320px)`、欢迎页 `--welcome-max: clamp(1000px, 48vw, 1360px)`；1280 窗口下分别保持 800/920/1000 的阅读宽度，3840 下增长到各自上限。
- 默认 420px 的画布在 ≥1750px 视口自动放宽到 24vw（上限 720px）；用户手动调过的宽度不被覆盖。画布拖宽时始终为对话列保留 560px。
- 设置弹窗 880px 宽，左侧 148px 导航。
- 终端停靠侧栏右侧的整个主区底部：左缘贴侧栏、右缘到窗口，画布或侧边聊天打开时从其下方贯通；关闭面板后进程继续。

### 5.1 创作台布局

创作台共用同一套布局令牌：顶栏沿用 `--titlebar-h: 44px`；三栏宽度是 `.studio-root` 内的局部变量 `--studio-left: 240px` / `--studio-right: 420px`。左侧阶段栏与右侧协作栏都使用 Agent 同款拖拽手柄（200–360px / 340–640px）；悬浮/拖动时只高亮面板自身的 1px 香槟金边框并显示像素读数；拖动时手柄在边界补一条同位置的金线，避免右侧重排时被相邻滚动条盖住；双击恢复默认，宽度按本机记忆；三栏布局至少为主区保留 560px。画布素材/镜头节点、写作目录/人物设定与协作者共用 `--fs-panel-title` / `--fs-panel-body` / `--fs-panel-meta`（15 / 13.5 / 11.5px），纸页正文基础字号 17px（大 20px / 小 16px），行距走阅读令牌。它不另起一套“三栏标准”，而是根据任务切换为两栏或三栏：

- **作品库**：左侧作品库 + 主区；没有产品标题/图标，首屏用内容标题与一句话输入建立焦点；≥2100px 时内容列放宽到 1320px。
- **长篇写作**：收起全局阶段栏，只保留“卷章大纲 + 纸页 + 可选协作助手”。纸页是主空间，在 1280px 宽窗口下仍保持约 678–748px 的正文宽度；≥2100px 时纸页放宽到 960px（专注模式 1040px），阶段切换放入顶部「阶段」菜单。
- **时间线**：默认只显示监视器 + 多轨时间线 + 助手；片段详情收起，需要时点「片段」打开。详情打开时助手自动收起，监视器增宽。监视器高度 `clamp(216px, min(42vh, 30vw), 860px)`，画面两侧用当前素材的模糊环境底填充；≤900px 高的窗口自动收紧页头与监视器。
- **分镜**：镜头详情打开时助手自动收起；从剧本点镜头会先切到分镜板，再显示详情，避免出现空详情。
- 任何界面都不同时铺开四栏；上下文面板只保留与当前操作直接相关的那一栏。

### 5.3 三档窗口与共用 1px 分隔线

三档窗口固定为 **1280×720（最小）/ 2100×1200（默认）/ 3840×2160（最大）**，Agent 与创作台共用同一组顶层令牌（`src/renderer/styles.css`）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--app-viewport-min` / `--app-viewport-default` / `--app-viewport-max` | `1280px` / `2100px` / `3840px` | 三档契约与截图矩阵命名 |
| `--app-page-gutter` | 24px（≤1500）/ 32px（默认）/ 48px（≥2100） | Agent 对话列与创作台交付、检查页的左右留白 |
| `--app-content-gap` | 22px | 内容网格间距 |
| `--app-content-max` | 1440px | 宽屏内容最大宽度 |

1px 分隔线同样只保留一组顶层令牌，Agent 侧栏、侧聊、画布、Studio 左/右栏与终端顶边都引用它：

| 令牌 | 值 |
|---|---|
| `--divider-size` | `1px` |
| `--divider-idle` | `var(--gold)` |
| `--divider-active` | `var(--gold-bright)` |
| `--divider-idle-opacity` | `0.45` |
| `--divider-glow` | `0 0 7px rgba(200,174,125,.55)` |
| `--divider-transition` | `opacity / background-color / box-shadow var(--dur-fast)` |

规则不变：默认基准线/隐藏线，悬浮或按住时高亮，按住移开仍保持，松开并移开后熄灭；高亮时面板自身边框让位，只保留这一条线。

## 6. 组件规范

### 6.1 页签

- 高度 24px、圆角 5px、水平内边距 9px、关闭按钮 20px。
- 选中：`--surface` 底 + 1px 金色边框；不再使用顶部圆角或底部金色下划线。
- 浏览器、画布、终端、Git、项目、Office 工作表共用 `--tab-*` token。

### 6.2 开关

- 34×20px，轨道圆角 5px，滑钮 14×14px、圆角 4px；金色开启。
- 不再使用胶囊/全圆角。

### 6.3 状态标签（chip）

- 圆角 4px、水平内边距 7px、高 20px、字号 11px。
- 用于项目/Git/订阅/记忆/研究/定时/文件树/浏览器等状态；路径等长信息独占一行。

### 6.4 滚动条

- 轨道 8px；滑块 6px 实色（深色 `#8a6f42`，浅色 `#a8844f`），hover `#b18f58`，active `#e4ce9e`。
- 全圆角（999px）、最小长度 36px、无渐变/无箭头/无炫光。
- 主区域、画布、CodeMirror、终端、iframe 与内置浏览器共用同一套数值；终端使用 xterm 的 `visible/invisible` 类，只有内容溢出才显示。
- iframe/浏览器通过 `shared/scrollbar.ts` 注入 8px 轨道、1px 透明边框 + `background-clip: content-box` 形成 6px 滑块。

### 6.5 按钮

- 主按钮：金色底/深色字，34px 高；次按钮：surface + 1px line；ghost：透明底，hover 变 surface。
- 小按钮 28px / 12px；图标按钮 20–28px；危险操作使用 rust 边框/文字，不用大面积红底。
- 所有按钮必须有 hover、focus-visible、disabled 三态；focus 使用金色 outline，不依赖阴影。

### 6.6 Composer

- Agent 主输入、侧边聊天与协作者共用 `.chat-gold-frame`：1px `--line-strong` 边框、`--r-lg` 圆角、surface 底与柔和投影。
- 聚焦时边框转 `--line-gold`，顶部 1px 香槟金线从左展开（420ms），阴影抬升；深色与浅色主题结构一致。
- 模型/思考/上下文选择器紧贴输入区上浮，宽度/圆角/字号与模型菜单一致。
- 附件、模式、权限、发送键在同一行；窄屏自动换行，不重叠。

### 6.7 消息与轨迹

- 对话列使用 `--content-max`（默认 800px，宽屏最多 1100px）；用户气泡 `--user-bubble`，assistant 无气泡，靠 typography 与间距分层。
- 工具轨迹左侧 1px spine；工具行显示图标、标题、路径/摘要、耗时；展开看参数/结果。
- diff 卡：长路径单行省略，展开箭头固定同行；行号/符号/统计与代码同字体同字重。
- 思考块折叠，显示“思考了 N 秒”；进行中显示脉冲点。

### 6.8 权限卡

- 背景 surface + 1px line；左侧 2px amber 竖线；标题“Morrow 想运行/写入…”。
- 展示目标、影响范围、风险、可展开预览；按钮“允许一次 / 始终允许 / 拒绝”。
- 高风险/越界不显示“始终允许”。

### 6.9 画布

- 多标签、脏标记、只读标记；预览背景 `--bg`，内容纸张色卡片；HTML iframe 无边框、圆角 8px。
- 版本历史抽屉、导出对话框、另存为使用统一表单控件。

### 6.10 设置

- 页面标题 20px/500/1.2，说明 12px，分区 13px/600；正文 14px/450。Agent 设置与创作台设置共用 `--settings-*` 导航/面板令牌与同一套语义排版角色。
- 创作台设置使用 148px 导航、34px 行高、15px 图标；选中态为 `--surface-active` 底 + 2px 金色左标，与 Agent 设置一致。子页按内容量整合为“模型与预算 / 配音与引擎 / 历史版本 / 数据与安全”，避免只有一个设置组的空页。
- 订阅详情以 ChatGPT/Codex 为基准：标题 20px/500、说明 12.5px、连接项标题 13px、主按钮 34px/13px、小按钮 28px/12px。
- 所有分页标题只出现一次，不在内容区重复。

### 6.11 灵动岛

- 独立透明置顶窗；收起 356×84，展开 396×520；宠物形象 + 进度/待办 + 快速输入。
- 背景玻璃仅在浮层使用；不遮挡主窗交互。

### 6.12 创作台品牌、指引与演示

- **创作台内不出现产品标题和产品图标**。顶栏只保留“作品库 / 当前作品 / 回到 Agent / 窗口控制”等功能项。
- “创作台”三个字只出现在 Agent 的顶栏切换按钮、命令面板描述和关于页说明中。
- 生成的形象图标只在**首次进入创作台的使用指引**中出现一次；关于页、顶栏、Agent 首页与命令面板都不再使用它。
- 首次进入指引和「看演示」沿用应用首次启动的深色沉浸式规格；演示用真实样例数据播放五幕，不做假动画。
- 图标只作说明，不承担导航；所有导航使用文字或标准功能图标（lucide，`stroke-width: 1.5`）。

## 7. 动效

- 页面/浮层 180ms：opacity + scale .98→1 + blur 8px→0。
- 发送时 2px 金色光带从左到右 400ms，随后消息段落淡入。
- 金色地平线聚焦 280ms；滚动条 hover/active 100ms。
- 减少动效开启后全部即时切换，不保留装饰性循环动画。

## 8. 可访问性

- 所有交互元素有可读标签与 focus-visible；键盘可达。
- 颜色对比满足正文可读；状态不只靠颜色。
- 图标 `stroke-width: 1.5`，不单独承载关键动作；按钮带文字或 aria-label。
- 表单错误显示在字段附近，并关联 aria-describedby。
- 窄屏/4K 下不重叠、不溢出；长路径省略但 title 可查看全文。

## 9. 实现约定

- 新增页面必须引用 token，不允许写死字号/字重/行高/圆角/颜色。
- `npm run audit:ui` 会扫描 CSS/TSX 的裸排版值；文档预览 iframe 有白名单。
- 组件级 token 只用于语义角色（权限卡、订阅详情、页签、开关、chip、滚动条、创作台纸张/文档），不鼓励再造一套。
- 创作台与 Agent 共用 `src/renderer/styles.css` 的顶层令牌；新增创作台颜色/尺寸时先加顶层语义 token，再在组件引用。
- 文档预览 iframe 的主题从顶层 token 读取（`features/artifacts/document-theme.ts`），不在 Office/PDF 组件里维护白色背景常量。
- 改动视觉时同时检查深/浅主题与窄屏，并重新跑 `npm run audit:ui`。
