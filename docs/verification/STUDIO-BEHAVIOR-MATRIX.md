## 4. 失败与边界

- 未连接文本模型：蓝图/大纲/正文/分镜/模型审稿明确报错；协作者只给本地规则计划，不伪造正文改写。
- 未连接 ComfyUI：图片/视频/章节配图明确报错；不生成占位图。
- 未连接 ACE-Step：正式配乐明确报错；`local` 只算草稿。
- 未配置 FFmpeg：合成/导出明确报错。
- 本机 TTS 失败：可导入配音；不伪造已生成。
- 视觉模型缺失：视觉审稿记录“未检查”，不冒充通过。
- 订阅渠道未验证：不显示“已连接”，不伪造额度。

## 5. 验收用例

- 单元：`tests/unit/studio-intent.test.ts` 26 条（含章序/镜序、局部大纲、人物/镜头声线、全片重配、逐步上下文）。
- 真实 UI：`tests/e2e/studio.spec.ts` → `35-studio-collaborator`：
  - 声音页改配音 → 新声线写回镜头并排队重配；
  - 中短篇局部改大纲 → 标题与正文保留；
  - 长篇调章节顺序 → 正文随章节重排；
  - 原有：台词替换、整章重写、改名。
- 打包：便携 exe 启动/渲染/截图；安装包由 electron-builder 构建并做完整性标签。
