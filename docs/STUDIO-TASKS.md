# 创作台 · 56 项任务卡实现对照

对照来源：Morrow 创作台规划方案的 56 项 `TASKS`（F/K/U/N/D/T/M/A/Q 九组）。
状态口径：**已实现** = 有真实数据、用户路径和可核对结果；**部分** = 主路径可用，但仍有环境或分发层限制；**待完成** = 只有规划或占位。

本轮原则：**优先实现真实功能，不做不必要的安全兜底**。能用本机真实引擎与真实界面验证的内容，不以占位、说明文字或 mock 代替；无法在本机验证的外部账号与商业素材，明确标为边界。

## 本轮已落地的关键缺口

> 第 2–4 轮的部分口语化标签已在第 6 轮回退为行业常用说法；当前界面以第 6 轮的平衡版为准，下面保留当时的改造记录。

- **侧栏与聊天框（v0.2.0 体验轮 1）**：创作台左侧阶段栏与右侧协作栏接入 Agent 同款拖拽手柄，默认 240 / 420px，拖动时 1px 香槟金强调线与实时读数，支持方向键微调、双击恢复与按机记忆；协作栏打开时左侧不再收成 64px 图标轨，三栏为主区保留 560px；`ResizeHandle` 与浅色主题同步。Agent 主输入、侧边聊天与协作者统一为 `.chat-gold-frame`：1px 边框、9px 圆角、聚焦金线展开；E2E 21 验证拖拽与双向宽度，E2E 02/18 验证三种输入框的边框与聚焦态。
- **交付页（v0.2.0 体验轮 2）**：做视频改为“用途（先看一版/正式成片）—画面—字幕—文件—清晰度”，默认 MP4 并给出用途说明；新增“不知道怎么选？用推荐设置”；字幕、封面、可编辑工程、一键交付包等六种带走方式的说明改为可见；音频按钮补用途；导出预检更名为「导出前检查」，正文字体与视频合成工具改用白话；交付记录不再裸露哈希（保留校验码 title）；修正失效的“设置 → 多媒体”路径；修复 label 包裹 Segmented 导致单选项可访问名称被覆盖的问题。
- **数据目录、双线与字号（v0.2.0 轮 7）**：创作台数据目录可从设置 → 数据与安全更换，支持迁移作品/素材/历史版本/任务并重启，Agent 数据不移动；Studio 与 Agent 的侧栏/画布/侧聊拖拽改为只高亮面板自身 1px 边框，不再叠加第二条线；画布素材与镜头节点、写作目录与人物设定、正文纸张字号上调；全应用统一称“协作者”。
- **响应式、回收站与写作台（v0.2.0 轮 8）**：Agent 首页回退并删除“进入创作台”卡片，顶栏按钮成为唯一入口；创作台设置新增回收站，支持恢复到作品库与彻底删除；三档窗口统一为 1280×720 / 2100×1200 / 3840×2160，页面边距与 1px 分隔线提取到顶层令牌；交付页与大纲页在窄主区改为纵向排布，不再出现竖排按钮；写作台补齐撤销/重做、查找替换、字号/行距/页宽、字数统计与导出 Word。受影响 E2E 18/19/20/21/22/27/28/29 13/13。
- **设置页（v0.2.0 体验轮 3）**：子页“配音与引擎”改为“声音与工具”；“预算保护”改为“最多花多少”，把 0 值明确成「不设上限」并显示“不限”，保存后重开仍生效；模型策略改为“先用哪边（先本机/先云端/只本机/只云端）”；路线表显示“已连接/未连接、会看图、会用工具、参考价”；画面生成、视频合成、本机声音改用白话；版本操作改为“回到这一版”；新增当前作品文件夹 IPC，交付页与左栏不再误开总目录。
- **时间线（v0.2.0 体验轮 4）**：字段“开始位置 / 素材起点 / 开头·结尾”，选项“直接切换 / 两头都淡”；“播放头”改为“当前播放位置”，“分割”改为“剪开”，“逐帧”改为“前后一帧”，“变速”改为“倒放/暂停/快进”；计数改为“N 段 · N 条字幕”；底部常驻“拖中间改位置，拖两端改长短”；字幕开关改为“显示字幕”。

- 画布：Shift 多选、框选、六向对齐、编组/解组、拖动组整体移动、镜头节点内生成、PNG 快照进入交付记录。
- 任务：持久化消息流、外部任务号/目标映射、启动自动对账、手动取回外部结果、任务账本展开输出与远程号。
- 小说：超长章节分片落盘与版本恢复；超 2 万字候选自动段落级对照；人物语气专项审稿。
- 漫剧：真实音频峰值波形；540p 低清代理；片段级独立撤销；100 镜装配基准。
- 媒体：策略化文本路由与价格表；兼容 OpenAI 的云端 TTS；内置音频素材库与许可标注；FFmpeg 默认/增强包能力识别。
- 体验修复：指引图标缩小到 1.1KB 并预加载，移除重复 Lucide 图标，统一“创作台”文案；协作侧栏/镜头详情/设定抽屉不再挤压或遮挡主区；顶栏菜单层级、演示控制条对齐、字幕标签重复与逐句时长分配已修复。
