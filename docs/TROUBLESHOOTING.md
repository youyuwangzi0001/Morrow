# Morrow 排障指南

> 先看「常见现象」；每条都给出可执行的下一步。仍然无法解决时，按最后一节收集信息。

## 1. 安装与启动

### 双击没有反应 / 进程秒退

1. 确认用的是 `Morrow-0.1.0-portable.exe`（单文件）或安装包，不是只拷贝了 `Morrow.exe`。
2. 单文件版首次启动会在 exe 同级解压 `.morrow-runtime-0.1.0-r010`，约 5–10 秒；杀毒/索引软件可能拖慢或拦截，临时把 Morrow 目录加入信任。
3. 如果 exe 同级目录只读，启动器会回退到 `%LOCALAPPDATA%\Morrow\runtime-0.1.0`；两者都需要可写。
4. 仍失败时查看 `%APPDATA%\Morrow\logs`（安装版）或 `Morrow Data/logs`（便携版）的最新日志。

### SmartScreen / “Windows 已保护你的电脑”

当前构建未配置代码签名证书，首次运行可能提示。点「更多信息 → 仍要运行」。如果文件来自浏览器/聊天工具，先右键 → 属性 → 解除锁定。签名能力已内置于打包脚本；正式发布建议配置证书。

### 安装版与便携版数据在哪

- 安装版：`%APPDATA%\Morrow`。
- 便携版：exe 同级的 `Morrow Data`。
- 设置 → 关于可以更改数据目录；迁移会复制对话、设置、项目、记忆与技能，不包含浏览器缓存/登录状态；需要重启。

## 2. 模型连接

### 「还没有填写 API Key」

- 公网服务：到服务商官网创建 Key，粘贴到 设置 → 模型 → API Key，点「保存连接」。
- 本机 / 局域网（Ollama、LM Studio、llama.cpp、局域网网关）：Key 可以留空；Base URL 填实际地址，例如 `http://192.168.1.20:11434/v1`。
- 如果地址是公网但服务不需要 Key，仍会被拦下；这是为了避免把无鉴权服务误当成公网模型。可改用本机反向代理，或给服务加 Key。

### 「测试连接」失败

| 现象 | 优先检查 |
|---|---|
| 401 / 403 | Key 是否复制完整、是否过期、是否属于当前服务商。 |
| 404 | Base URL 是否多了/少了 `/v1`；服务商是否提供 `/models`。 |
| 超时 | 本机服务是否启动；代理/防火墙；局域网是否在同一网段。 |
| 返回非 JSON | Base URL 指向了网页而不是 API；用 `curl <base>/models` 验证。 |

### 同步模型列表被截断 / 跳过

设置页会显示「上次同步」、截断与跳过数量。单个服务最多保存 200 个模型；返回体上限 5MB；无效 ID 会被跳过。需要更多模型时，减少服务商返回的条目或在自定义服务里手动添加。

### 模型没有思考强度选择

只有声明支持推理的模型才显示。旧版本同步的模型如果缺少协议信息，Morrow 会按 provider 类型补齐；仍不显示时，删除该模型后重新「刷新可用模型」。

## 3. 订阅

- **登录窗口没有回调**：检查默认浏览器是否能打开；公司网络/代理可能拦截回环回调。可改用设备码或粘贴 API Key。
- **登录页没有自动打开 / Edge 提示权限提升**：Morrow 会直接调用已安装浏览器；以管理员运行时会交给 explorer 以普通权限打开。若 Edge 已被旧版本以管理员启动，按提示用普通权限重启一次，再点「重新打开登录页面」。
- **额度显示为空**：部分渠道没有公开额度接口，页面会说明「以控制台为准」，不是故障。
- **真实 Codex 导入**：需要本机 `~/.codex/auth.json`；Morrow 只读导入，不改写官方客户端文件。E2E 中该用例默认跳过（`MORROW_SUBSCRIPTION_REAL=1` 开启）。
- **第三方 coding plan**：确认协议选对（OpenAI Chat Completions / Anthropic Messages）、接口地址以 `http(s)://` 开头、模型 ID 每行一个。

## 4. 多媒体

### ComfyUI 显示离线

1. 设置 → 多媒体填写 ComfyUI 服务地址（默认 `http://127.0.0.1:8188`）和安装目录（含 `main.py`）。
2. 点「检查连接」；离线时点「打开 ComfyUI」或手动启动。
3. 确认已安装 `ComfyUI-GGUF`、`ComfyUI-sol-attn` 等所需节点；缺文件时按提示复制下载命令。
4. 远程 ComfyUI 只能手动启动；Morrow 的「打开 ComfyUI」只对本机回环地址生效。

### 添加本机模型

- **llama.cpp / Ollama / LM Studio**：设置 → 多媒体 → 添加本机模型，选择引擎、填写名称与能力；llama.cpp 选择 GGUF 文件，Ollama/LM Studio 填引擎内模型 ID。
- **ComfyUI**：需要 API 格式工作流 JSON。在 ComfyUI 里用「保存（API 格式）」导出，粘贴到表单，填写输出节点 ID（负责 SaveImage/SaveVideo 的节点）与输出类型；可选填写提示词节点与输入名。
- **模型文件不在引擎目录**：选择后会自动复制到引擎模型目录，重名自动加序号；大文件复制需要等待。
- **保存后列表没有**：点「刷新」；Ollama/LM Studio 还需要在引擎里拉取模型。

### ffmpeg 不可用

图片/视频生成不依赖 ffmpeg；只有剪辑、转 GIF、封面与拼接需要。设置 → 多媒体选择 ffmpeg 可执行文件（Windows 为 `.exe`，macOS/Linux 无扩展名），或用系统 PATH。Windows 可从 gyan.dev 下载 full build。

### 生成很慢 / 显存不足

16GB 显存下高分辨率图片、长视频、代码模型与视频模型同时加载会明显变慢。建议分阶段执行：先生成素材，停止 ComfyUI 释放显存，再启动代码/视觉模型审片。

## 5. 终端与 Git

- **终端打开失败**：设置 → 终端选择可用 shell；PowerShell 7 未安装时改用 Windows PowerShell / CMD / Git Bash。
- **WSL 显示灰色或找不到**：先安装 WSL 与 Linux 发行版（PowerShell 运行 `wsl --install`，重启后完成发行版初始化），再在设置 → 终端点「重新检测」。只有 `wsl.exe`、没有发行版时会保留灰色选项并显示说明。
- **命令中文乱码**：终端已统一 UTF-8；如果外部程序强制 GBK，请在命令里显式设置编码。
- **Git 面板提示不是仓库**：在 Git 面板点「初始化」，或确认工作区根目录包含 `.git`；Morrow 拒绝操作嵌套在更大仓库内的工作区。
- **提交失败**：先配置仓库身份（Git 面板 → 身份）；检查是否有未解决的冲突；大文件可能被 `.gitignore` 忽略。
- **回退不包含命令生成的文件**：检查点只覆盖 Morrow 通过写文件工具修改的文件；命令直接写出的文件不在快照内。

## 6. 浏览器与网页

- **页面打不开**：确认网址以 `http(s)://` 开头；内置浏览器拒绝 `file:`、`javascript:` 等危险协议。
- **登录/下载被拦**：下载需要逐次确认；摄像头、麦克风、定位与通知默认关闭。
- **原生网页区域遮挡浮层**：Morrow 会在下载确认/成功提示出现时给原生视图让出底部空间；如果仍被遮挡，缩小窗口或关闭下载提示。
- **返回主页面后网页还在**：这是预期行为，浏览器保持打开，可从标题栏或工作台切回。

## 7. 数据、备份与卸载

- 备份：退出 Morrow 后复制整个数据目录（安装版 `%APPDATA%\Morrow`，便携版 `Morrow Data`）。API Key 使用 Windows DPAPI 加密，换机器/换用户后需要重新填写。
- 清理：设置 → 归档可恢复/永久删除归档对话；设置 → 关于可打开日志与数据目录。
- 卸载：Windows 设置 → 应用 → Morrow；默认保留用户数据。彻底清理需手动删除数据目录。
- 缓存：单文件版的 `.morrow-runtime-*` 可以删除，下次启动会重新解压；不要在 Morrow 运行时删除。

## 8. 性能与上下文

- 长对话达到阈值会自动压缩；可在 设置 → 上下文 调整阈值或关闭自动压缩。
- 上下文快满时，Morrow 会提示；可以新建分支、清理附件、或让 Morrow 先总结再继续。
- 大量文件/大仓库搜索会占用内存；全局搜索默认索引最近 1000 个会话，单会话文本有预算上限。

## 9. 收集信息再反馈

请提供：

1. Morrow 版本（设置 → 关于）与 Windows 版本。
2. 复现步骤、预期结果、实际结果。
3. 最新日志（设置 → 关于 → 打开日志），以及相关截图。
4. 如果是模型/媒体问题，附服务商、Base URL（隐去 Key）、引擎版本与模型 ID。

不要在公开 Issue 中粘贴 API Key、邮箱、会话内容或用户文件。安全问题请按 [SECURITY.md](../SECURITY.md) 私下报告。
