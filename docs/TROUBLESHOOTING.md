## 安装与启动

| 现象 | 处理 |
|---|---|
| 双击没有反应或进程秒退 | 确认是 Windows 10/11 x64；换一个目录再解压或重装；查看 `logs/main.log` |
| SmartScreen 拦截 | 这是未签名构建的正常提示；选择“更多信息 → 仍要运行”，并先校验 `SHA256SUMS.txt` |
| 便携版首次启动慢 | 首次运行要在 exe 同级解压运行时缓存，之后启动会快很多 |
| 关闭窗口后仍有进程 | 托盘/灵动岛是独立窗口；从托盘退出，或在任务管理器结束 `Morrow-app.exe` |
| 数据在哪 | 安装版 `%APPDATA%\Morrow`；便携版 exe 同级 `Morrow Data`；可在“设置 → 关于”查看 |

## 模型与连接

| 现象 | 处理 |
|---|---|
| 模型下拉为空 | 先保存服务并测试连接；订阅模型在“订阅”页登录后才出现 |
| 401 / 403 | Key 复制不全或权限不足；重新生成后再粘贴 |
| 404 | Base URL 写错。点回默认，不要填浏览器里打开的网页地址 |
| 429 | 余额不足或请求过频。去服务商后台看余额与限流 |
| 测试连接转圈 / 超时 | 网络或代理问题；确认代理能访问该服务商 |
| 回复被截断 | 调大该模型的最大输出；订阅模型在订阅详情里改 |
| 只有思考没有正文 | 内核会自动重试；持续出现时换模型或检查服务商是否返回空内容 |
| 上下文显示不对 | 手动改过的长度会带编辑标记，刷新模型列表不会覆盖；本机服务不做家族猜测 |

更多设置见 [MODELS.md](MODELS.md)。

## 订阅

| 现象 | 处理 |
|---|---|
| 订阅显示未连接 | 重新登录或重新导入本机登录；未实测渠道不会显示“已连接” |
| 导入 Codex 登录失败 | 改用“浏览器登录 ChatGPT”，或改走 API Key |
| 登录后模型没有出现 | 点“刷新可用模型”，或在输入框重新选一次模型 |
| 额度显示为空 | 服务商没有返回用量，或该渠道不提供额度接口；Morrow 不伪造数字 |
| Antigravity 登录失败 | 需要设置 `MORROW_ANTIGRAVITY_CLIENT_SECRET`，不内置 OAuth secret |

## 多媒体

| 现象 | 处理 |
|---|---|
| ComfyUI 显示离线 | 在“设置 → 本地”填地址并确认 ComfyUI 已启动；缺少工作流或模型时任务会失败 |
| 云端服务不可用 | 确认已保存对应服务的 API Key；没有 Key 不会发起请求 |
| 生成很慢 / 显存不足 | 降低分辨率或批量；本机生成受显卡与工作流影响 |
| 配音没有声音 | 检查本机 TTS 路径、Windows SAPI 或云端 `/audio/speech` 配置 |
| FFmpeg 不可用 | 在“设置 → 本地”配置 FFmpeg；它不随包内置 |
| 审看失败 | 当前对话模型不支持看图时会回退本机视觉模型；两者都缺失时明确失败 |

更多服务与默认模型见 [MEDIA.md](MEDIA.md)。

## 终端与 Git

| 现象 | 处理 |
|---|---|
| 终端打不开 | “设置 → 终端”切换 Git Bash / PowerShell 7；确认系统已安装对应 Shell |
| Git Bash 报 MSYS 错误 | Morrow 会建立独立兼容前缀；仍失败时重开终端或检查本机 Git 安装 |
| Git 操作被拒绝 | 只读档会拒绝写操作并返回 `READ_ONLY`；切到询问或完全访问 |
| 大仓库状态很慢 | diff 超长会截断展示；可先缩小工作区或分批暂存 |
| 短路径报错 | 已统一展开 8.3 短名；仍出现时把完整路径与日志一起反馈 |

## 浏览器与电脑操作

| 现象 | 处理 |
|---|---|
| 网页打不开 | 只允许 http(s)；检查网络、代理与目标站点 |
| 浏览器被拒绝打开新窗口 | `window.open` 默认拒绝；改用地址栏或让 Agent 在当前标签导航 |
| 电脑操作点不到控件 | UI Automation 树可能不完整；会退回坐标点击，仍失败时换用文件/命令方式 |
| 敏感窗口被拒绝 | 密码、登录、验证码、支付、银行与系统设置一律拒绝，这是预期行为 |

## 数据、备份与卸载

- 会话、作品、记忆、密钥、日志与缓存都在数据目录；路径见 [REFERENCE.md](REFERENCE.md#数据路径)。
- 备份：退出 Morrow 后复制整个数据目录；密钥由 Windows DPAPI 加密，换机器后需要重新填写。
- 更改数据目录：“设置 → 关于”更改，应用会重启并迁移现有数据。
- 卸载：安装版从“设置 → 应用”卸载；`deleteAppDataOnUninstall=false`，用户数据默认保留。便携版直接删除 exe 与 `Morrow Data`、运行时缓存目录。

## 性能与上下文

- 长会话接近上下文上限时会自动压缩；压缩保留最近用户消息、关键事实、工具结果与任务约束。
- 感觉变慢时，先看输入框的上下文占用与状态栏；必要时新建会话或降低上下文档位。
- 大文件预览有截断保护，不会把整个文件读进内存。

## 收集信息

反馈问题前准备：

1. 版本号（“设置 → 关于”）、Windows 版本与安装方式（便携版/安装版）。
2. 复现步骤与预期结果。
3. `logs/main.log` 中对应时间段的日志；日志已脱敏，但仍请自行检查是否含敏感路径。
4. 涉及模型时附上服务商、模型 ID 与 HTTP 状态，不要附 API Key。

安全问题的报告方式见 [SECURITY.md](../SECURITY.md)。
