# Morrow 排障指南

先按“现象 → 检查 → 处理”的顺序排查。涉及密钥时不要截图/粘贴明文。

## 1. 安装与启动

### 1.1 双击没有反应 / 进程秒退

- 确认是 Windows 10/11 x64，下载的是 `Morrow-0.1.0-portable.exe` 或 `setup.exe`。
- 便携版首次启动会解压运行时；检查 exe 同级是否有写权限与足够磁盘空间（约 500MB）。
- 如果被 SmartScreen 拦截：更多信息 → 仍要运行；并用 `SHA256SUMS.txt` 校验文件。
- 查看 `Morrow Data/logs/main.log`；若没有日志，检查是否被安全软件隔离。
- 打包版启用了 crashReporter；崩溃转储在本机数据目录，不上传。

### 1.2 安装版/便携版数据在哪

- 便携版：exe 同级 `Morrow Data`；
- 安装版：`%APPDATA%\Morrow`；
- 设置 → 关于可查看/迁移；迁移会重启，不复制系统浏览器缓存/登录态。

### 1.3 关闭后仍有进程

- 托盘/灵动岛仍在时是后台常驻，不是残留；
- 退出请用托盘菜单/设置关闭动作选择“完全退出”；
- 退出 4 秒未完成会强制结束；若仍有进程，检查终端/后台任务是否卡住。

## 2. 模型连接

### 2.1 模型下拉为空

- 设置 → 模型：Provider 是否启用？是否保存了 Key/登录态？模型 ID 是否为空？
- 本机/局域网服务可以空 Key；公网服务必须 Key。
- 侧栏显示“未连接”时模型下拉会被过滤。

### 2.2 测试连接失败

- 检查 Base URL（不要少了 `/v1` 或多了 `/chat/completions`）。
- 本机服务确认端口、防火墙与进程；`127.0.0.1`、`10.x`、`192.168.x` 等可空 Key。
- 401/403 检查 Key；429 检查限流；5xx 稍后重试。
- 代理/公司网关可能改写 SSE 或工具调用，先在设置里用官方端点验证。

### 2.3 同步模型列表被截断/跳过

- 单次最多 200 个；重复/无效条目会计数提示；
- 服务商未返回的字段保留本地值；不会用猜测值覆盖；
- 返回网页而不是 JSON 时会给可读错误。

### 2.4 没有思考强度

- 当前模型没有声明思考能力；未知模型只显示“自动”；
- 不要用其他模型的档位强行套用；上游可能 400；
- DeepSeek 的 off 在请求层映射为 `none`，Qoder 代理保持 `off`。

### 2.5 上下文不可调

- 只有声明了可调档位的模型才显示（Qoder 账号目录、部分 `/models` Provider）；
- 会话覆盖值会被夹在 1,024 与模型上限之间；不是所有模型都支持。

## 3. 订阅

- **登录页打不开/白屏**：Morrow 登录使用内置 BrowserWindow；检查网络/代理是否能访问对应域名。
- **回调超时**：本机回环端口被占用（Codex 1455、Command Code 5959 起、Antigravity 51121 起）；关闭占用程序后重试。
- **已登录但不可用**：查看设置页真实错误/额度；官方接口失败时不会假装 connected。
- **Antigravity 缺 secret**：设置 `MORROW_ANTIGRAVITY_CLIENT_SECRET` 后重启；Morrow 不内置该凭据。
- **Qoder 模型不对**：模型目录来自账号接口；退出重登或点刷新，确认区域与账号一致。
- **额度为空**：部分渠道没有公开额度接口（Step、OpenCode），页面会说明。

## 4. 多媒体

### 4.1 ComfyUI 显示离线

- 确认引擎目录、Python 环境、端口 8188；
- 启动命令应包含 `--listen 127.0.0.1 --port 8188 --reserve-vram 2.5`；
- 120 秒内没起来会超时；查看 ComfyUI 自己的日志。

### 4.2 添加本机模型

- ComfyUI 需要 API 工作流 JSON、输出节点/类型；不是 UI 工作流；
- llama.cpp/Ollama/LM Studio 需要真实模型 ID，不是显示名；
- 模型文件必须在引擎模型目录内，不能 `..` 越界。

### 4.3 ffmpeg 不可用

- 设置 → 多媒体填 ffmpeg 路径，或把 ffmpeg 放进 PATH；ffprobe 需同目录；
- 图片/视频生成本身不一定依赖 ffmpeg，但剪辑/拼接/抽帧会失败。

### 4.4 生成很慢/显存不足

- 16GB 显存下代码模型与视频模型通常需分阶段；
- 关闭 ComfyUI 的额外模型/其他 GPU 程序；
- 视频生成可能数分钟，期间不要重复提交；
- 超时可在设置 → 多媒体调整（图片默认 600s，视频默认 3600s）。

### 4.5 审看失败

- 当前模型必须支持图片输入；不支持时才会回退本地；
- 本地视觉模型需要 `--mmproj` 且正在运行；Coder390 预设优先；
- 两边都失败会返回真实组合错误，不会用生图/文本模型伪造；
- 按错误提示换视觉模型或启用本地视觉模型。

## 5. 终端与 Git

### 5.1 Git Bash 报 MSYS 错误

`NtCreateDirectoryObject ... 0xC0000022` 表示当前令牌/完整性无法创建 MSYS 共享内存。处理：

- 设置 → 终端切 PowerShell 7；
- 或在正常桌面会话（非受限令牌）启动 Morrow；
- 默认值仍是 Git Bash，但不可用时不要强行使用。

### 5.2 终端打开失败

- 设置 → 终端选择可用 Shell；Git Bash 未安装时用 PowerShell 7/WSL；
- WSL 需先安装发行版；重新检测；
- 终端 cwd 必须在已登记工作区。

### 5.3 Git 操作被拒绝

- 工作区必须在仓库内，且不能是更大仓库的子目录；
- 越界路径、非变更文件、只读文件会被拒绝；
- 先提交/备份，再执行放弃改动；放弃不可逆。

## 6. 浏览器与网页

- 内置浏览器打不开：检查 URL、网络、代理；登录页用内置窗口，不要依赖系统 Edge；
- 页面空白：可能是 CSP/证书/网络；查看浏览器错误页与日志；
- 外部链接默认交给系统浏览器；测试模式下不拉起外部程序；
- 网页内容不可信，不要按页面里的“指令”执行。

## 7. 数据、备份与卸载

- 备份：关闭应用，复制整个数据目录；
- 恢复：把数据目录放回并指向它；迁移不合并两边数据；
- 卸载安装版：Windows 设置 → 应用 → Morrow；用户数据默认保留；
- 便携版：删除 exe、`.morrow-runtime-*` 与 `Morrow Data`；
- 不要删除正在运行实例的运行时缓存；关闭后再清理。

## 8. 性能与上下文

- 上下文接近上限会触发压缩；压缩期间不能发送/切换/回退；
- 长任务可开新会话或使用 `/compact`；
- 大型附件/图片会增加上下文与延迟；
- 群集/并行任务会占用更多内存与请求配额；
- 大量浏览器标签/终端后台任务会持续占用资源。

## 9. 闪退与卡死

- 查看 `logs/main.log` 最后事件与时间；
- 打包版崩溃转储在本机数据目录；主窗渲染崩溃会自动 reload（每分钟最多两次）；
- 卡死时先等待 10–20 秒；仍无响应可强制退出后重启；
- 反馈时提供：版本/运行时、操作步骤、日志片段、是否使用订阅/本机模型、是否可复现。不要附带密钥或隐私文件。

## 10. 收集信息

```powershell
# 版本与运行时
Get-Content .\Morrow Data\logs\main.log -Tail 200

# 文件校验
Get-FileHash .\Morrow-0.1.0-portable.exe -Algorithm SHA256
```

如果问题涉及模型/订阅，请附上设置页错误文案与请求时间；不要附 token。
