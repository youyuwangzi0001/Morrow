## 安装与启动

- 确认系统是 Windows 10/11 x64，文件是 `Morrow-0.1.0-portable.exe` 或 `Morrow-0.1.0-setup.exe`。
- 便携版首次启动会解压运行时，需要 exe 同级写权限与约 500MB 空间；运行中不要删除 `.morrow-runtime-*`。
- SmartScreen 拦截时核对 `SHA256SUMS.txt`，再选择“更多信息 → 仍要运行”。哈希不一致就重新下载。
- 查看 `<dataDir>/logs/main.log`；没有日志时检查安全软件是否隔离了文件。
- 打包版启用了本地 crashReporter，转储保存在本机数据目录，不上传。

## 模型连接

- **下拉为空**：设置 → 模型确认 Provider 已启用、已保存 Key 或登录态、模型 ID 非空。本机与局域网服务可以空 Key，公网服务必须 Key。
- **测试连接失败**：检查 Base URL（不要少 `/v1`，也不要多 `/chat/completions`）；本机服务确认端口、防火墙与进程；401/403 查 Key，429 查限流，5xx 稍后重试。
- **同步列表被截断**：单次最多 200 个；无效条目会计数提示；服务商没返回的字段保留本地值。
- **没有思考强度**：模型没有声明思考能力；未知模型只有“自动”。不要套用其他模型的档位，上游可能返回 400。
- **上下文不可调**：只有声明可调档位的模型才显示；覆盖值会被夹在 1,024 与模型上限之间。

## 订阅

- **登录页打不开或白屏**：登录使用内置窗口，检查网络与代理能否访问对应域名。
- **回调超时**：本机回环端口可能被占用（Codex 1455、Command Code 从 5959 起、Antigravity 从 51121 起）。关闭占用程序后重试。
- **已登录但不可用**：查看设置页的真实错误与额度；官方接口失败时不会假装 connected。
- **Antigravity 缺 secret**：设置 `MORROW_ANTIGRAVITY_CLIENT_SECRET` 后重启；应用不内置该凭据。
- **Qoder 模型不对**：目录来自账号接口，退出重登或点刷新，并确认区域与账号一致。
- **额度为空**：Step 与 OpenCode 没有公开额度接口，页面会说明，不显示数字。

## 多媒体

- **ComfyUI 显示离线**：确认引擎目录、Python 环境与端口 8188；启动命令应包含 `--listen 127.0.0.1 --port 8188 --reserve-vram 2.5`；120 秒内未就绪会超时，查看 ComfyUI 自己的日志。
- **添加本机模型失败**：ComfyUI 需要 API 工作流 JSON（不是 UI 工作流）与输出节点；llama.cpp / Ollama / LM Studio 需要真实模型 ID；模型文件必须在引擎模型目录内。
- **ffmpeg 不可用**：在设置 → 多媒体填写路径，或把 ffmpeg 放进入 `PATH`；ffprobe 需与它同目录。图片与视频生成不一定依赖 ffmpeg，但剪辑、拼接与抽帧会失败。
- **生成很慢或显存不足**：16GB 显存下代码模型与视频模型通常要分阶段；关闭其他 GPU 程序；视频生成可能数分钟，期间不要重复提交。
- **审看失败**：当前模型需要支持图片输入，本地视觉模型需要 `--mmproj` 且正在运行。两边都失败时返回真实组合错误，不会用生图或文本模型伪造。

## 终端与 Git

- **Git Bash 报 `0xC0000022`**：当前令牌或完整性级别无法创建 MSYS 共享内存。设置 → 终端切 PowerShell 7，或在正常桌面会话启动 Morrow。
- **终端打不开**：换一个可用 Shell；WSL 需先安装发行版；终端 cwd 必须在已登记工作区内。
- **Git 操作被拒绝**：工作区必须在仓库内，且不能是更大仓库的子目录；越界路径、非变更文件与只读文件会被拒绝。
- **放弃改动不可逆**：先提交或备份，再执行放弃。

## 浏览器与网页

- 内置浏览器打不开时检查 URL、网络与代理；登录页使用内置窗口，不依赖系统浏览器。
- 页面空白可能来自 CSP、证书或网络；查看错误页与日志。
- 外部链接默认交给系统浏览器；网页内容不可信，不要按页面里的“指令”执行。

## 数据、备份与卸载

- 备份：关闭应用后复制整个数据目录。便携版在 exe 同级 `Morrow Data`，安装版在 `%APPDATA%\Morrow`。
- 恢复：把数据目录放回并指向它；迁移不会合并两边数据。
- 卸载安装版：Windows 设置 → 应用 → Morrow；用户数据默认保留。
- 卸载便携版：删除 exe、`.morrow-runtime-*` 与 `Morrow Data`；先关闭应用。

## 性能与上下文

- 上下文接近上限会触发压缩；压缩期间不能发送、切换或回退。
- 长任务可以开新会话或使用 `/compact`。
- 大型附件与图片会增加上下文与延迟。
- 集群与并行任务会占用更多内存与请求配额；大量浏览器标签与终端后台任务会持续占用资源。

## 闪退与卡死

- 查看 `logs/main.log` 的最后事件与时间。
- 打包版崩溃转储在本机数据目录；主窗口渲染进程崩溃会自动 reload（60 秒内最多两次）。
- 卡死时先等待 10–20 秒；仍无响应再强制退出并重启。
- 已知情况：用户报告的闪退时刻没有对应 WER 记录，根因未确认；后续复现可保留日志与转储。

## 收集信息

```powershell
# 最近日志
Get-Content '.\Morrow Data\logs\main.log' -Tail 200

# 校验下载文件
Get-FileHash .\Morrow-0.1.0-portable.exe -Algorithm SHA256
```

反馈时提供版本、操作步骤、日志片段、是否使用订阅或本机模型、是否可复现。不要附带 API Key、订阅 token、完整私密文件或未修复漏洞细节。
