# 数据分析：从真实文件到可复核结论

## 何时使用

- 用户要求统计、对比、清洗、汇总 CSV/Excel 数据。
- 需要从数据中找趋势、异常、分组差异或业务结论。
- 要生成分析报告、图表、仪表盘或关键指标。
- 用户给了一份表格，问「说明了什么」「下一步怎么办」。

## 何时不要用

- 纯展示已有结论、不需要计算：document-deliverables。
- 数据文件打不开/格式未知：先检查文件与依赖，不要硬猜。
- 没有数据来源、只凭印象：先说明无法分析，或让用户提供数据。

## 第一原则

**数字必须来自真实文件与可重跑脚本。** 不手算、不编造、不把示例数据当真实结果。

**先定义口径，再算数字。** 同一个「活跃用户」「转化率」可能有多种定义；口径不清，结论一定争议。

## 流程

### 1. 明确问题与决策

- 这份分析要支持什么决定？给谁看？
- 指标定义：分子、分母、时间范围、去重规则、排除条件。
- 分组维度：按天/周/月、地区、渠道、用户类型。
- 缺失值/异常值怎么处理；是否需要对照/基线。
- 输出格式：结论、表格、图表、报告、仪表盘。

不明确且影响结论时，用 ask_user 问一个关键问题；其余做合理假设并写明。

### 2. 读取与体检

- CSV/TSV：用脚本读取（Python/pandas、Node 或项目已有工具）；小文件可直接 read_file 预览。
- Excel：先用 read_xlsx 看工作表、列名、行列数，再用脚本做完整计算；不要只读第一页。
- 检查：行数、列类型、重复、空值、异常值、单位、编码、日期格式、合计行/小计行。
- 把数据质量问题写进结论或附录，不要悄悄删掉异常值。

### 3. 清洗与转换

- 保留原始文件，不覆盖；清洗结果写到新文件。
- 规则要可复现：日期解析、单位换算、缺失值填充/剔除、异常值处理、去重键。
- 记录每一步的行数变化：原始 → 清洗后 → 分析样本。
- 对敏感字段脱敏；不要把真实用户数据写进示例或日志。

### 4. 计算

- 用可重跑脚本，保存脚本文件；不要只在对话里心算。
- 复杂指标拆成中间表/中间结果，便于复核。
- 交叉验证：抽查小样本、换一种聚合方式、检查分组之和是否等于总计。
- 对比基线：同比/环比/对照组；没有基线时说明只能描述不能归因。
- 区分相关与因果；不要把同时发生当成原因。

### 5. 可视化

- 图表选择匹配问题：
  - 时间趋势 → 折线；比较类别 → 条形；构成 → 堆叠条形/饼图（类别少时）；分布 → 直方图/箱线图；关系 → 散点。
- 坐标轴从零开始，除非有充分理由截断并明确标注；不要用面积/角度误导。
- 标题写结论，副标题写口径/时间范围；图例、单位、来源齐全。
- 颜色不超过必要数量；关键系列高亮，其余弱化；考虑色盲可读性。
- 图表数据与正文数字一致；四舍五入规则统一。

### 6. 输出

- 结论先行：一句话回答用户的问题。
- 关键发现 3–5 条，每条有数字和口径。
- 证据：表格/图表/样本；大表放附录或单独文件。
- 方法：数据来源、清洗规则、指标定义、时间范围。
- 限制：样本偏差、缺失值、无法验证的外部因素。
- 下一步：建议的行动或需要补充的数据。

### 7. 交付物

- 报告：Markdown/HTML，用 open_artifact 展示；必要时导出 PDF。
- 表格：write_xlsx，保留公式与格式；原始数据单独文件。
- 图表：HTML 内联 SVG/Canvas 或图片；确保离线可看。
- 脚本：保存在工作区（如 analysis/analyze.py），方便重跑。
- 仪表盘：如果用户需要持续查看，做单文件 HTML 或项目内页面；不要假装有后端。

## 数据质量检查

- 行数/列数是否符合预期？有没有重复表头/合计行被当成数据？
- 日期范围是否完整？时区是否一致？
- 金额/数量单位是否统一？百分比是 0–1 还是 0–100？
- 空值是缺失、未知还是 0？处理规则是否写明？
- 异常值是录入错误还是真实极端值？是否影响结论？
- 分组之和是否等于总计？抽样是否可复现？
- 关键数字是否至少用两种方式验证？

## 统计与表达

- 报告均值时同时考虑中位数/分布；异常值会拉偏均值。
- 小样本不要下强结论；给出样本量和置信区间（如适用）。
- 百分比变化说明基数：「增长 50%」是从 2 到 3，还是从 200 到 300。
- 不要用「显著」除非做了统计检验；不要用「导致」除非有因果设计。
- 图表截断坐标轴、双轴、3D 饼图等容易误导，谨慎使用并标注。

## 常见反模式

- 没有数据来源的百分比/趋势。
- 为了让图表好看而删除异常值，且不说明。
- 把 mock/示例数据当真实结果。
- 只算总数，不做分组/对照，结论泛泛。
- 用手算常量代替公式，数据一改就错。
- 图表与正文数字不一致。
- 只给结论，不给口径和限制，无法复核。
- 把相关当因果，或把样本偏差推广到全体。
